这里的 Go 不是 `go build`，而是 Yaegi 0.16.1 在浏览器里解释执行。每个示例都必须是完整的 `package main`，并且只使用解释器自带的标准库。

没有 `go get`、cgo 和网络。个别反射、泛型和 unsafe 的行为与官方编译器不同，复杂写法会标成只读。

```go run expect="你好" title="问候"
package main

import "fmt"

func main() {
	fmt.Println("你好")
}
```

```go norun title="不做的事"
package main

// 只读：不要在示例里访问网络。
// import "net/http"
```

```go run expect="42" title="运算"
package main

import "fmt"

func main() {
	fmt.Println(6 * 7)
}
```

这里的 Go 由 Yaegi 0.16 解释执行，不是 go build。每个可运行示例都要有 package main 和 func main。标准库里解释器自带的包可以用，go get、cgo 和网络都不行。没有使用的 import 会报错，写完记得删掉试过又不用的包。

Run 会把整段程序放进编辑器再执行。编辑器里如果少了 package main，即使函数写对了也不会有入口。教程因此不展示「只贴一个函数」的片段，除非它被标成只读。

Yaegi 和官方编译器在反射、部分泛型、自定义 error 接口上会不一样。那些差异在对应章节里标成只读，能跑的例子都避开了已知的 panic。你在本地用 go 命令可以试更全的写法，这里以能跑为准。

输出用 fmt.Println 或 Printf。Println 会换行，Print 不会。期望子串通常取第一行有意义的结果。多打印一行标题往往仍能通过，但会让终端难读，示例保持短。

Yaegi 报错时常把文件名显示成 /program。那就是你刚刚提交的这一份源码，行号从 package 那一行数起。先看行号，再看是缺包、没用到的导入，还是类型不对。

完整程序看起来比「一个函数」长，但这是解释器的入口规则。你把它复制到本地用 go run，同样需要 package main。教程不省略它，是为了复制出去仍能跑。

只读块用来放已知会 panic 或和官方编译器不一致的写法。不要为了凑运行按钮把它们改成可运行，除非你已经在这个环境里试过并且输出稳定。

Go 的示例由 Yaegi 解释，必须是完整的 package main。没有 go get，标准库里解释器支持的部分才能 import。导入了却不用，会直接失败，这和官方编译器一样。报错里的文件名常常是 /program，行号从 package 那一行数起。先看行号，再看是缺包、没用到的导入，还是类型不对。

和官方编译器有差异的主题改成只读，不放进自动测试。能跑的例子保持在已经验证过的子集里：基本类型、控制流、切片、map、简单方法和简单泛型。自定义 error 放进接口再调用方法，在这个版本上会 panic，那一类写法只出现在只读块里。

每次运行都是新的解释过程。上一段 main 里的变量不会留到下一段。示例因此从 package 写起，而不是从某一行片段写起。工具栏 Run 和代码块 Run 外观相同。代码块负责把整份源码写进编辑器再运行。

阅读时先确认文件能单独通过编译式的检查：每个导入都被用到，main 里有可见的打印。没有打印的程序即使逻辑对，测试也看不到结果。期望仍是子串，多打印的调试行要能指认是哪一次 Println。

### 读「相加」

先做这一例。代码收成一行是 `package main import "fmt" func main() { fmt.Println(19 + 23) }`。先盖住终端，用手算结果，纸上的文本里要能找到「42」。这是子串：前面可以有别的输出，后面通常有换行，不要要求整屏只有这几个字。

然后点这个代码块上的 Run，不要点工具栏。代码块会先备份草稿，再把示例写进编辑器并执行。终端里用眼睛找「42」。退出码不是 0 时，先读错误的类型和最后一行，此时不要改期望。退出码是 0 但找不到这段文字，说明打印了别的值，回到产生该值的表达式，只改一处。

改过之后再点代码块上的 Run，会把你的修改盖掉。要验证修改，点工具栏上的 Run。预测和新输出一致后，点撤销，把草稿还给自己。一次只改这一例，不要连着改两个代码块。

## 最佳实践

- 每个可运行示例都写完整的 package main。
- 不用的 import 立刻删掉。
- 和官方编译器行为不一致的写法标成只读，不放进自动测试。

## 小结

Yaegi 解释完整的 main 包。没有 go get，未使用的导入会失败，和官方编译器有差异的主题改成只读。

## 常见错误

- 漏写 package main。Yaegi 需要它作为入口。
- 留下没有使用的 import。解释器会报错。
