字典把键映射到值，查找不需要从头扫描。集合只关心「在不在」，重复元素会自动丢掉。

遍历字典时默认走键。要同时拿到值，用 `.items()`。

```python run expect="2" title="词频"
text = "to be or not to be"
counts = {}
for word in text.split():
    counts[word] = counts.get(word, 0) + 1
print(counts["to"])
print(counts["be"])
```

```python run expect="[3]" title="集合运算"
a = {1, 2, 3}
b = {3, 4}
print(sorted(a & b))
print(sorted(a | b))
```

```python run expect="[('a', 2)]" title="Counter"
from collections import Counter
print(Counter("aab").most_common(1))
```

字典把键映射到值。键必须可哈希，所以列表不能当键，元组里如果只含可哈希对象就可以。查找是均摊常数时间，比在列表里线性扫描适合「按名字找」。键不存在时，d[key] 抛 KeyError，d.get(key, default) 返回默认值。先用 in 判断再读取，和 get 是同一类意图：缺失是正常情况，不是事故。

遍历字典默认走键。items() 同时给出键和值，values() 只给值。插入顺序会被记住，但不要把「我插入的顺序」当成业务上的排序规则，需要顺序时用 sorted。更新另一个字典用 update，同名键会被覆盖。

集合里的元素唯一且可哈希。适合做去重和成员测试。| 是并集，& 是交集，- 是差集。空集合必须写 set()，{} 是空字典。集合没有下标，也不能切片。

计数字典是常见模式：counts[word] = counts.get(word, 0) + 1。collections.Counter 做同样的事，标准库里就有。本章先把 get 写熟，下一阶段再换 Counter，两种写法的结果应该一样。

字典的键比较用相等性，并且必须可哈希。数字 1 和布尔 True 在哈希上可能撞在一起，因为 True == 1。不要把 True 和 1 同时当键，否则你会以为有两个条目，其实是一个。教学例子用字符串当键，最不容易踩这个坑。

get 的默认值在键缺失时才使用，键存在但值是 None 或 0 时，get 返回那个值，不会用默认值。如果「没有这个键」和「值就是 0」需要区分，用 in，不要用 get 的返回值是否为 0 来判断。

集合的运算返回新集合，不改原来的。|= 才会原地并入。打印集合的顺序不稳定，测试时打印长度或打印排序后的列表，不要把某一次 print(my_set) 的文本写进期望。

统计词频时，先把文本拆成词再计数。大小写和标点要不要算进去，在计数前决定。本章的例子保持简单：拆空白、区分大小写。复杂的清洗会把注意力从字典上带走。

字典按键取值，查找适合「按名字找」。键必须可哈希，所以列表不能当键。键不存在时，用方括号会抛 KeyError，get 返回你给的默认值。缺失如果是正常情况，用 get 或 in，不要靠异常来分支。键存在但值是 0 或 None 时，get 返回那个值，不会换成默认值。要区分「没有这个键」和「值就是 0」，用 in。

True 和 1 在相等性上可能撞成同一个键。教学例子用字符串当键。遍历字典默认走键，items 同时给出键和值。插入顺序会被记住，但不要把插入顺序当成业务排序。需要稳定顺序时，打印排序后的键。update 会用同名键覆盖旧值。

集合保证元素唯一。并集、交集、差集返回新集合，|= 才会原地并入。空集合必须写 set()，花括号是空字典。集合没有下标，打印顺序不稳定，测试时打印长度或排序后的列表，不要把某一次 print 集合的文本写进期望。

计数字典的模式是 counts[word] = counts.get(word, 0) + 1。大小写和标点要不要算进去，在计数前决定。本章保持简单：按你给的键原样计数，不在计数函数里偷偷清洗。

## 最佳实践

- 缺失的键如果是正常情况，用 get 或 in，不要靠 KeyError 来分支。
- 空集合写 set()，花括号留给字典。
- 需要稳定顺序时排序键，不依赖遍历字典时的偶然顺序做断言。

## 小结

字典按键取值，集合保证元素唯一。缺失键用 get，空集合不要写成花括号。

## 常见错误

- 用列表当字典的键。键必须可哈希，列表不行，元组可以。
- 集合是无序的。要稳定输出，先 sorted。
