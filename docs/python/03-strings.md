字符串是不可变的字符序列。f-string 在花括号里写表达式，运行时再填上结果。`input` 读入一行并去掉末尾换行；提示文字会先写到输出。

```python run stdin="Ada\n" expect="你好，Ada！" title="问候"
name = input("名字？")
print(f"你好，{name}！")
```

```python run expect="Simple" title="切片"
word = "SimpleCode"
print(word[:6])
print(word[-4:])
print(len(word))
```

```python run expect="是回文" title="回文"
text = "abba"
print("是回文" if text == text[::-1] else "不是")
```

样例输入显示在代码块下方。取消「使用样例输入」后，程序会改从终端读取你键入的内容。
:::

字符串一旦创建就不能改其中某一个字符。s[0] = "A" 会直接报错。要「修改」就做出新字符串：切片、拼接、replace、大小写转换都返回新对象，原来的 s 不变。这让字符串可以安全地当作字典的键，也让函数收到字符串时不必担心调用方的变量被悄悄改掉。

切片写成 s[起:止:步长]。起包含在内，止不包含，和 range 的习惯一样。省略起就是从头，省略止就是直到末尾。负数从末尾数，-1 是最后一个字符。步长为 -1 时从后往前取，于是 s[::-1] 是反转后的新字符串。中文也按字符计，不是按字节。len("你好") 是 2。

f-string 在引号前写 f，花括号里放表达式。表达式先求值，再转成文本嵌进去。格式写在冒号后面，{value:.1f} 表示保留一位小数，它只影响显示，不改变 value 的类型。要输出花括号本身，就写成双花括号。f-string 里不要塞太长的逻辑，算好之后再嵌进去，读的人不用在引号里面找 if。

input 读入一整行并去掉末尾换行，返回值永远是 str。提示语会先出现在输出里，然后程序停下来等输入。文档运行时，样例输入由测试填好；你在编辑器里自己跑，就要在终端键入。计算之前记得 int 或 float，否则你是在拼接文本。

不可变的直接后果是：函数里对参数做 replace 或切片，调用方的变量不变。你如果希望调用方看见变化，就要 return 新字符串，由调用方自己赋值回去。这和列表的 append 相反，列表会在原地变。

切片的步长可以省略。s[:6] 和 s[0:6:1] 一样。写 s[-4:] 时，负数起点加上省略的终点，表示「最后四个字符」。如果字符串比 4 还短，结果就是整个字符串，不会报错。用下标 s[100] 才会越界。

f-string 的花括号里可以调用方法，例如 {name.strip()}。能工作，但花括号一多，引号就容易配错。先把 strip 的结果放进变量，再放进 f-string，报错信息会更好读。格式说明里的 .1f 只用于数字，用在字符串上会失败。

input 的提示和后面的 print 可能出现在同一行，因为提示本身通常不换行。看期望输出时，要找的是结果那一段，而不是要求终端里干干净净只有结果。样例输入里的换行写成真正的一行结束，不要把反斜杠 n 两个字符喂给程序，除非你在测试转义本身。

字符串一旦创建，就不能改其中某一个字符。对某个下标赋值会直接报错。replace、切片、大小写转换都返回新字符串，原来的名字仍指向旧的。函数里对参数做这些操作，调用方的变量不变。想让调用方看见变化，就要 return 新字符串，由调用方自己赋值回去。这和列表的 append 相反。

切片写成起、止、步长。起包含，止不包含，和 range 一样。省略起就是从头，省略止就是直到末尾。负数从末尾数，-1 是最后一个字符。步长为 -1 时得到反转后的新字符串。中文按字符计，len("你好") 是 2，不是字节数。下标越界会异常，切片越界则安静地截断。

f-string 在引号前写 f，花括号里放表达式。格式写在冒号后面，只影响显示，不改变原来的类型。要输出花括号本身，写成双花括号。花括号里可以调用方法，但逻辑一长，引号就容易配错。先把结果放进变量，再嵌进 f-string。格式说明里的小数位只用于数字。

## 最佳实践

- 循环里拼接大量片段时，先放进列表，最后用 join，避免反复复制。
- input 的结果先转换类型，再参加算术。
- 切片右端当成「到这里为止但不包括」。

## 小结

字符串不可变，切片和 f-string 都产生新文本。input 给出的是去掉换行后的一行字符串，数值运算要先转换。

## 常见错误

- 把 input 的结果直接当数字用。它永远是字符串，计算前要 float 或 int。
- 切片的右端点是开区间：word[:6] 不含下标 6。
