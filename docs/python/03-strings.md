东柜的问候先从读者的名字开始。名字不是写死在源码里的，它来自柜台前的那一次输入。输入在这个环境里不是你临时在键盘上敲，而是代码块声明好的一段标准输入。程序仍然调用 input，仍然会停下来读一行。差别只在于那一行由示例替你准备好了，所以同一块每次运行都得到同一个名字，输出才对得上。下面这一块就是本章的第一段可运行代码。提示语会先写到输出，然后读入 Ada，再印出带名字的问候。

```python run stdin="Ada" expect="你好，Ada！" title="问候"
name = input("名字？")
print(f"你好，{name}！")
```

input 的参数是提示，它被写到标准输出，而且不附加换行。接着函数从标准输入读一整行，去掉末尾的换行，把剩下的内容作为字符串交回来。Ada 这三个字母因此是字符串，不是一个特别的「名字类型」。f 写在引号前面，表示这个字符串是格式化的：花括号里的表达式先求值，再把结果嵌进周围的文字。这里的表达式就是名字 name。花括号外面的汉字和标点原样保留，所以输出里能找到「你好，Ada！」。提示「名字？」也在输出里，它排在问候前面，中间没有换行。期望不要求整行只有问候，它只要求那句问候出现。你自己核对时会看见提示和问候粘在一起，那是 input 不换行的直接后果。若你希望提示单独占一行，就在提示字符串里自己写上换行，或者先用 print 印提示，再让 input 使用空提示。空提示不会凭空消失输入功能，它只是不再多写几个字。

这里有一个立刻会绊人的事实：input 交回来的永远是字符串，哪怕读者输入的看起来像数字。借期若输入 14，你得到的是 `"14"` 而不是整数 14。把它和另一个字符串相加，是拼接；把它和整数相加，是 TypeError。两种结果都不是「把借期加上三天」。要做算术，得先用 int 转换。转换放在你确认这行字确实由数字组成之后。这一章先把「读到的是文本」刻住，算术留给后面需要天数的例子。坑就在这句看起来像数字的输入上：打印时它和整数几乎无法用眼睛分开，`print(14)` 和 `print("14")` 都是那两个字符。类型不同，能参加的运算就不同。需要分辨时，打印 `type` 的名字，不要只看终端上的形状。

f-string 的花括号里可以放更复杂的表达式，但不值得把一整段逻辑塞进去。借条上的句子应当让人在引号外面就能看见分支。先把要嵌的值算好，赋给一个名字，再嵌进 f-string。格式说明写在表达式后面的冒号之后，例如保留小数，那是显示问题，不改变原来的数。这一章的借条不需要小数。若要在输出里出现一个真正的花括号，就写成两个花括号。单个花括号会被当成表达式的开始，里面若不是合法表达式，整行会在解析时失败。

问候用过一次之后，借条还要处理索书号。索书号是一个字符串，例如 `I247.5/12`。它不是列表，你不能 append 一个字母进去，也不能替换其中某一个字符而让原对象改变。你可以按下标取出一个字符，也可以用切片取出一段。切片写成 `s[起:止]`。起的位置包含在内，止的位置不包含，和后面会见到的 range 是同一种半开区间。省略起，就从开头取；省略止，就取到末尾。位置从 0 数。负数从末尾数，`-1` 是最后一个字符。下面这一块从同一条索书号里取出分类号的前四位，以及末尾的两位序号。

```python run expect="I247" title="索书号的两段"
call = "I247.5/12"
print(call[:4])
print(call[-2:])
```

第一行是 I247，第二行是 12。点号和斜线仍留在原来的字符串里，切片没有修改 call。你打印 call 本身，它还是完整的索书号。这就是不可变在操作上的样子：每次切片都是一个新字符串，旧的那个继续被原来的名字指着。若你写 `head = call[:4]`，head 和 call 指向两个对象。随后让 call 重新绑定到别的索书号，head 仍是刚才切下来的那四位。这和上一章整数的重新绑定是同一件事，只是对象换成了字符串。

中文也按字符计，不按字节。`len("小径")` 是 2。UTF-8 里每个汉字通常占三个字节，若有人用字节长度来切书名，会把一个字从中间切开，得到非法的半截。Python 的字符串抽象把这个麻烦挡在后面：下标和切片的单位是字符。借书台的书名因此可以直接 `title[:1]` 取第一个字。代价是你不能用 len 去估计这段文字写到文件里占多少字节。本课程几乎不把字符串写进文件，这个代价暂时碰不到。若你从别处拿到的是字节串，类型名是 bytes，那是另一类对象，下标取出的是整数而不是字符。这一章的索书号和书名都是普通字符串。

步长写在第二个冒号后面。`call[::2]` 会每隔一个字符取一次。步长为 `-1` 时从后往前取，于是 `title[::-1]` 是把书名倒过来的新字符串。倒过来的书名很少真的要印在借条上，它常被用来检查回文。检查时用 `==` 比较原串和倒序串。比较区分大小写，Ada 和 ada 不是同一个字符串。读者输入的大小写若需要忽略，就先做出一个统一成小写的新串再比较，原来的输入仍保持读者写下的样子。不要为了比较去改掉唯一的那一份原文，你也改不掉，你只能让名字改指新串，而原文若还要印在问候里，就该留在原来的名字上。

借条的整句可以用 f-string 把读者和书名拼起来。书名号是普通字符，写在花括号外面。下面这一块不再读取输入，读者和书名都写在源码里，因为这一块要展示的是拼接，不是输入。每次运行仍是新进程，Ada 那个名字不会从上一块流过来。

```python run expect="林夏借《小径》" title="借条上的一句"
reader = "林夏"
title = "小径"
print(f"{reader}借《{title}》")
```

若书名本身可能含有花括号或引号，先处理书名，再放进句子。不要在 f-string 里面再写一层没有转义的同种引号来硬嵌套，引号对不齐时，失败是语法错误，整块跑不起来。双引号字符串里可以含单引号，反过来也行。书名号不是引号，它不会结束字符串。

替换同样交出新串。`replace` 找到一段文字，做成一份换过的副本。原来的字符串不变。下面这一块把架位说明从「在架」换成「借出」，旧条子仍含着「在架」两个字，新条子含着「借出」。我们把两句都印出来，证明不是同一份文本被改写。

```python run expect="在架" title="替换交出新条子"
slip = "在架：小径"
updated = slip.replace("在架", "借出")
print(slip)
print(updated)
```

第一行是原来的「在架：小径」，第二行是「借出：小径」。期望抓住「在架」，就是为了防止有人写成 `slip.replace(...)` 却不接住返回值，然后打印 slip，还以为自己已经改好了。那种写法会让两行都是旧句子。replace 和列表的 append 相反：它不就地修改，返回值才是结果。不接住返回值，调用就白做了。这个对比值得在借书台上记成一句人话：改得了里面夹页的是册子，改不了一个字的是已经印好的纸条；纸条要换说法，就另印一张。

成员测试用 `in`。`"小径" in slip` 问的是这段文字是否连续出现，不是问字符串是否「包含这个概念」。它区分精确的字符序列。前后多一个空格就对不上。大小写也要一致。`in` 的结果是布尔值。把它直接放进 if 可以，印出来则是 True 或 False。借书台的例子若要给人看，就把布尔翻译成「含有书名」或「没有书名」再打印。翻译用条件表达式即可，不必为了这么小的选择去定义函数。

字符串乘法是重复，不是算术。`"小径" * 2` 得到「小径小径」。册数若是整数 2，`title * copies` 会把书名重复两遍，这很少是你要的借条。你多半是想把册数放进句子，那用 f-string：`f"{copies}册"`。整数和字符串不能用加号相加，那会是 TypeError。这个错误其实是朋友，它阻止你把 2 和「小径」粘成一段意义不明的文本。想粘，就先把整数转成字符串，而且最好连同单位一起放进 f-string，让「2」和「册」的关系写在源码里，而不是依赖一个看不见的空格。

空字符串是一个真正的字符串，长度是 0。它不是 None。input 若读到一行空行，交回来的就是空字符串，而不是 None。问候若直接嵌进去，会印出「你好，！」，看起来像漏了名字，进程却是成功的。要不要拒绝空名字，是控制流的事：你可以用长度或后面要讲的真值来分支。字符串这一章只强调，空字符串是合法的值，replace 和切片对它都还能工作，只是切出来仍是空的。不要用空字符串表示「查询失败」。失败若和「书名就是空的」分不清，后面印借条时会把失败印成一张空白书名的条子。查询失败更适合用异常说出来，那是异常那一章的题目。这里先不要用空串去充当错误码。

编码只在你离开字符串、走向字节时才出现。`title.encode("utf-8")` 得到字节串，长度按字节算，往往大于字符数。`decode` 走回来。借条若一直留在字符串里，就不必在每一章都 encode。本环境的源码和终端都是 UTF-8，汉字可以直接写在引号里，也可以直接出现在 print 的输出里。不要把「你好」写成一串 `\u` 转义来显示你懂编码。转义能用，但它让借条难读，也容易在数字符时把一个转义序列误认成多个字符。源码里的 `\u4f60` 是一个字符「你」，不是六个字符。这个区别在切片时会咬人。能用汉字写清楚的，就用汉字。

把问候、切片和替换想成同一张借条的三道工序。第一道从输入得到名字，嵌进句子。第二道从索书号切出架上需要的那一段，原号保留。第三道另印一张更换了状态的条子，旧条子留底。三道工序都不修改已有的字符串对象。你要的变化，全部体现在新的对象和新的名字上。下一章开始用这些字符串做判断：空名字、空书名会在条件里被视为假。在那之前，先让自己习惯接住 replace 和切片的结果。

## 小结

input 读入一行并去掉换行，交回的永远是字符串，提示写在输出里且不另起一行。f-string 在花括号里求值后嵌进句子。切片用半开区间取出新串，不改原串；中文按字符计数。replace 同样交出新串，不接住返回值就等于没替换。整数和字符串不能直接相加，空字符串是合法的值，不要拿它充当「没找到」。
