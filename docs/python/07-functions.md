盖章如果每次都把步骤抄一遍，借书台的源码会越来越长，而且两处抄写很快会不一致：一处记得写日期，另一处忘了。函数把一套步骤收成一个名字。调用就是按这个名字把步骤再执行一遍，参数是这一次的书和这一次的名单。听起来每一次都该是干净的。默认参数却有一个例外。默认值在函数定义时就算好，并且只算这一次。若默认值是列表，这个列表对象会留在函数身上，每一次你没另给名单的调用，用的都是它。第一次盖章往里 append 的书，第二次还能看见。这不是借书台希望的「今天的章」。这是一张被反复使用的旧单。

先把函数写成没有这个坑的样子，看清调用在做什么。def 后面是名字，括号里是参数，冒号下面缩进的是函数体。函数体在定义时不执行。执行发生在调用。调用写成 `stamp("小径")`。参数 book 在这次调用里指向字符串小径。函数若写了 return，调用表达式的值就是返回的那个对象；若没写，值是 None。print 若放在函数里面，输出发生在调用期间；print 若放在外面，输出的是返回值。两边都可以，不要两边各印一次然后忘记自己为什么看见两行。下面这一块把书名交回去，由外面打印。默认参数还没有出现。

```python run expect="小径" title="调用才执行函数体"
def stamp(book):
    return book

print(stamp("小径"))
print(stamp("海边"))
```

两次调用互不影响，因为每次的 book 都是参数上的新绑定，函数也没有把东西存进一个活得比调用更久的列表。book 是字符串，不可变，就算函数里让 book 这个名字改指别的字符串，外面的变量也不会变。参数传递的是对象的引用，不是抄一份新书名。对字符串来说，两边暂时看见同一个对象，可谁也改不了它的字。对列表来说，函数里 append 就会改到调用者手里的那一份。这和类型那一章的标签是同一规则，只是标签出现在参数名上，调用结束参数名就消失，对象若还被外面的名字指着，就留下。

默认参数写在定义里，形如 `log=[]`。看起来像「每次没给 log 就新做一个空列表」。实际的计算时机是定义那一行被执行的时候。def 语句执行时，空列表被创建一次，放在函数的默认值槽里。之后每次调用若省略这个参数，就去用槽里的那一个对象。append 修改的是它。第二次调用因此从 1 开始而不是从 0 开始。下面故意写成这个有坑的形状，并且调用两次。第一次的返回值我们不打印，第二次的长度打印出来。长度是 2，因为小径还在里面，海边又加了进去。

```python run expect="2" title="两次盖章共用默认列表"
def stamp(book, log=[]):
    log.append(book)
    return len(log)

stamp("小径")
print(stamp("海边"))
```

若你把两次的返回值都打印，会看见 1 然后 2。期望锁定 2，就是锁定「第二次不是从头开始」。有人会说只要不看第一次就没关系。关系在对象里，不在你看不看。第三次调用会得到 3。测试若只调用一次，这个坑完全不出现，所以它能在复习单次调用的例子里潜伏。演示必须调用两次。这就是把坑写在引入默认参数的地方，而不是等写完一整章正确的函数再补一个角落。

修法是默认值改用 None。None 是不可变的，共享它没有内容可被 append。函数体里再判断：若调用者没给名单，log 是 None，这时才创建一个新列表。创建发生在调用期间，所以每次省略参数都会各自得到空列表。调用者若真的传入一个列表，就用他的那一个，函数的 append 会改到那一份，这是他选择共享，不是默认值偷偷共享。下面同样调用两次，第二次的长度应当是 1。

```python run expect="1" title="每次省略参数都新建名单"
def stamp(book, log=None):
    if log is None:
        log = []
    log.append(book)
    return len(log)

stamp("小径")
print(stamp("海边"))
```

判断要用 `is None`，不要用 `if not log`。若调用者传入了一个空列表，他的意思可能是「就用我这个空的，请往里面盖」，空列表的真值是假，`if not log` 会扔掉他的列表，另做一个新的，他在外面就看不见章。None 才表示「我没提供」。空列表表示「我提供了，它目前是空的」。真值在这里分不清这两种意图。类型和身份分得清。

调用者传入的列表会被就地修改，这应当写在函数的约定里，而不是让人从 append 猜。若约定是「不碰你的名单，交回一份新的」，函数就该复制一份再 append，返回新的，原来的长度不变。复制用切片。下面这一块展示不修改原名单的写法。外面的 log 开始是空的，调用之后外面的长度仍是 0，返回的那份长度是 1。

```python run expect="0" title="交回新名单时原名单不动"
def stamp(book, log):
    fresh = log[:]
    fresh.append(book)
    return fresh

log = []
got = stamp("小径", log)
print(len(log))
print(len(got))
```

第一行 0，第二行 1。这种写法每次都分配新列表，默认参数那个坑不会出现，因为根本没有可变的默认值。代价是多一次复制。借书台的名单若很长，而你又确定调用者就是想在原名单上盖章，就地 append 更直接。选择要写明白。不要既在文档里说「原名单不变」，又在函数里 append。

返回和打印不要叠成两套输出。函数若负责盖章并返回书名，就让调用者决定要不要印。函数里再 print，测试会看见两行，其中一行可能是调试时留下的。调试用的 print 在例子稳定之后删掉。返回 None 的函数适合只做动作，但动作若是修改了调用者看不见的默认列表，动作就藏起来了。上面那个长度为 2 的例子之所以把长度返回来，就是为了让隐藏的共享变成看得见的数。

参数可以有多个，默认值必须排在没有默认值的参数后面。`def stamp(log=[], book)` 这种顺序在语法上就不成立。这是为了让调用时的位置参数还能对上。关键字参数可以按名字传递，`stamp(book="小径")`，顺序就可以和定义不完全一致。关键字让调用点读得懂，在参数变多时比纯位置更不容易把书名传到天数上。这一章的参数还少，位置调用足够。不要为了展示关键字把借书台的函数写成十个参数。参数太多，通常是该把读者、书名、天数收成一个对象，对象那一章会接这个话题。

函数里可以再定义函数。内层函数能看见外层函数的名字，这是闭包。默认参数的坑不要和闭包搅在同一次引入里。这里只提一句：内层函数若要记住外层的某一个值，而这个值会变，绑定时机又会成为下一处惊喜。装饰器那一章会用到嵌套函数，用来包住盖章。现在先把一层函数的默认值时机记牢。

可变默认不只列表。字典当默认值，两次调用里的赋值会留在同一个字典里。集合也一样。整数、字符串、None、元组当默认值则没有这个内容累积的问题，因为你改不了它们的内部，你最多让参数名改指别的对象，而那个改指只在本次调用内有效，不会写回默认值槽。所以坑的条件有两个：默认值只在定义时创建一次，并且这个对象可以被就地修改。两个条件同时成立才要小心。只背「不要用可变默认」就够用；知道为什么，才能在看见 `log=[]` 时判断这是不是在累积盖章。

作用域再补一句，免得和默认值混在一起。函数里赋值的名字，默认属于函数本地，不会跑去改外面的同名变量。外面的 log 和参数 log 可以同名，它们是两个标签，只在调用把外面的对象传进来时才暂时指向同一对象。你在函数里写 `log = []`，是让本地的标签改指一个新列表，外面的标签不动。你在函数里写 `log.append(...)`，是修改对象，外面若还指着它，就看得见。一个是移动标签，一个是改对象。默认参数的坑属于后者，而且那个对象的标签藏在函数的默认值槽里，源码的调用处看不见。

把两次调用的对照再放在一起想。有坑的版本，第二次长度是 2。用 None 的版本，第二次长度是 1。复制后返回的版本，外面的长度是 0，返回的长度是 1。三种写法都能通过某一种测试，如果你只调用一次、只看返回的书名。要暴露共享，必须调用两次并查看累积的长度或内容。借书台的盖章函数若会在整个进程里被调用很多次，有坑的版本会把一整天的书都堆进同一张默认单，直到进程结束。进程结束这张单才消失。在我们的教程里进程很短，坑仍然会在同一块里的第二次调用出现。不要因为进程短就觉得默认列表是空的。

返回值若是那个共享列表本身，调用者还会把它留在自己的名字上。第一次 `kept = stamp("小径")`，第二次再调用，kept 里也会出现第二本书，因为 kept 和默认槽是同一个列表。调用者以为自己保存的是第一次的快照，其实保存的是还会继续生长的那张单。修复默认值之后，这个意外的生长一起消失。只修复「第二次的返回值」而不换掉默认对象，是修不到的，因为问题不在返回语句，而在槽里的对象。

位置参数和关键字参数不要让书名传到名单上。`stamp("小径", log)` 若 log 是列表，第二个位置对上 log 参数，这是对的。`stamp(log, "小径")` 会把列表当成书名去 append，再把字符串当成名单，随后调用 append 时失败，或者在有坑的版本里把字符串的方法用错。失败至少看得见。更安静的错误是两个参数都是字符串，调用成功，意义却反了。参数少，名字起成 book 和 log，调用时用关键字，能减少这种对调。关键字不会创造新的默认列表，它只是指明这一次把哪个对象传进去。传进去的若是同一次进程里早先得到的那个默认列表，共享仍然在。关键字修不了可变默认。

## 小结

函数体在调用时执行，参数名指向传入的对象。默认值在 def 执行时创建一次。默认值若是列表，两次未传该参数的调用会 append 到同一张单上，第二次的长度变成 2。用 None 当默认，在函数体内再创建列表，每次省略参数才有自己的空单。`if not log` 会把调用者传入的空列表也换成新的，判断要用 `is None`。就地 append 和先切片再返回，是两种不同的约定。
