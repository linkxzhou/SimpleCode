函数把一段计算收成名字。参数默认值在定义时求值一次，所以默认值不要用可变对象。没有 `return` 时结果是 `None`。

`*args` 把多出来的位置参数收成元组。lambda 只能写一个表达式，适合很短的变换。

```python run expect="42" title="计算器"
def apply(op, a, b):
    if op == "+":
        return a + b
    if op == "*":
        return a * b
    return None

print(apply("+", 20, 22))
print(apply("*", 6, 7))
```

```python run expect="6\n60" title="可变参数"
def total(*nums, scale=1):
    return sum(nums) * scale

print(total(1, 2, 3))
print(total(1, 2, 3, scale=10))
```

```python run expect="120" title="递归与 lambda"
def fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)

print(fact(5))
print((lambda n: n + 1)(41))
```

def 定义函数。参数是调用时传入的名字，返回值用 return 交回去。没有 return 的函数返回 None。默认参数在定义时求值一次，而不是每次调用。默认值如果是列表或字典，所有调用会共享那一个对象，往里面 append 会越积越多。可变默认值写成 None，在函数体内再创建新列表。

位置参数按顺序对应，关键字参数按名字对应，关键字必须写在位置参数后面。*args 把多出来的位置参数收成元组，**kwargs 把多出来的关键字收成字典。调用时也可以用 * 把序列拆开传进去。

函数是对象，可以放进列表、当参数传递。lambda 适合写很短的表达式，超过一行就改回 def，方便断点和名字。闭包让内层函数记住外层的变量。要在内层重新绑定外层名字，用 nonlocal，否则你只是创建了一个同名的局部变量。

递归要有明显变小的参数和停下来的条件。记忆化可以把算过的结果存进字典，避免同一题算很多遍。递归深度有限制，能写成循环时循环更稳，尤其在这个单次运行、没有调栈空间的环境里。

默认参数只计算一次，这个规则对不可变对象无害：默认的数字、字符串每次读到的都是同一个，但你无法改它们的内容。列表会被 append 改掉，所以危险。判断方法很简单：这个默认值会不会在函数里被修改？会，就换成 None。

关键字参数让调用处读得懂。add(1, 2) 看不出谁是谁，add(start=1, step=2) 看得懂。参数超过三个时，考虑用一个小字典或对象收拢，而不是继续加位置参数。

闭包记住的是变量，不是当时的值。循环里创建函数，如果函数读取循环变量，它们可能都看到最后一轮的值。修复办法是用默认参数把当前值绑进去：lambda n=n: n。本章的计数器没有这个问题，因为它不在循环里创建。

递归的斐波那契如果不记忆，调用次数会按指数涨。记忆化之后每个 n 只算一次。写记忆化时，字典要放在所有递归调用都能看见的地方，通常是外层函数的局部变量，由内层函数闭包住。

def 定义函数。参数是调用时传入的名字，return 把结果交回去。没有 return 的函数结果是 None。默认参数在定义时求值一次，不是每次调用。默认值若是列表或字典，所有调用共享那一个对象，append 会越积越多。可变默认值写成 None，在函数体内再创建新列表。数字和字符串做默认值是安全的，因为你改不了它们的内容。

位置参数按顺序对应，关键字参数按名字对应，关键字必须写在位置参数后面。星号把多出来的位置参数收成元组，双星号把多出来的关键字收成字典。调用时也可以用星号把序列拆开。拆开时元素个数要和参数对得上。

函数是对象，可以放进列表、当参数传递。lambda 只适合一行表达式。闭包记住的是变量，不是定义那一刻的拷贝。循环里创建函数并读取循环变量，它们可能都看到最后一轮的值。需要绑住当前值时，用默认参数把那一轮的值收进来。要在内层重新绑定外层名字，用 nonlocal，否则只是新建了一个局部变量。

递归要有变小的参数和停下来的条件。先写停止条件再写递推。能写成循环时，循环更稳，这个环境没有额外的栈空间给你挥霍。

## 练习

写一个函数，返回斐波那契数列的第 n 项（0, 1, 1, 2, 3, 5…），并打印第 8 项。

::: answer 参考答案：斐波那契
```python run expect="21" title="参考答案"
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a

print(fib(8))
```
:::

写一个函数，返回参数的两倍，并用 21 调用它。

::: answer 参考答案：两倍
```python run expect="42" title="参考答案"
def twice(n):
    return n * 2
print(twice(21))
```
:::

## 最佳实践

- 可变对象不要做默认参数，用 None 当作「还没有」的标记。
- 函数只做一件事，名字用动词，返回值的类型在相邻调用里保持一致。
- 递归先写停止条件，再写如何把问题变小。

## 小结

函数用参数接收输入、用 return 交回结果。默认值只求一次，函数本身也可以当普通对象传来传去。

## 常见错误

- 默认参数写成 def add(item, bag=[])。这个列表会在多次调用之间共享。
- 递归没有终止条件，最后会 RecursionError。
