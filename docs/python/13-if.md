条件为真时进入缩进的那一块。不要给条件加多余的括号。

### if 和 else

只有一个分支会执行。

```python run expect="plus" title="正数分支"
n = 4
if n > 0:
    print("plus")
else:
    print("badnum")
```

输出里能看到 `plus`。

### elif

多个门槛从上往下试，命中一个就停。

```python run expect="mid" title="分数档"
score = 70
if score >= 90:
    print("high")
elif score >= 60:
    print("mid")
else:
    print("low")
```

输出里能看到 `mid`。

### 比较不是赋值

判断相等用两个等号。一个等号是赋值，不能写进 `if` 的条件。

```python run expect="True" title="两个等号"
word = "tea"
print(word == "tea")
```

输出里能看到 `True`。
