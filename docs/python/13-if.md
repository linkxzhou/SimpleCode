条件为真时进入缩进的那一块。不要给条件加多余的括号。

### if 和 else

只有一个分支会执行。

```python run expect="正数" title="正数分支"
n = 4
if n > 0:
    print("正数")
else:
    print("非正")
```

输出里能看到 `正数`。

### elif

多个门槛从上往下试，命中一个就停。

```python run expect="中" title="分数档"
score = 70
if score >= 90:
    print("高")
elif score >= 60:
    print("中")
else:
    print("低")
```

输出里能看到 `中`。

### 比较不是赋值

判断相等用两个等号。一个等号是赋值，不能写进 `if` 的条件。

```python run expect="True" title="两个等号"
word = "茶"
print(word == "茶")
```

输出里能看到 `True`。
