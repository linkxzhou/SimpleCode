名字指向对象。`=` 是绑定，不是数学里的相等。`type` 告诉你对象属于哪一类。

整数除法 `/` 得到浮点数；只要整数商用 `//`。`int`、`float`、`str` 负责转换，转换失败会抛出异常。

```python run expect="212" title="温度换算"
celsius = 100
fahrenheit = celsius * 9 / 5 + 32
print(int(fahrenheit))
print(type(celsius).__name__)
```

```python run expect="bool" title="类型转换"
flag = True
print(type(flag).__name__)
print(int("36") + 1)
print(str(6) + "7")
```

```python run expect="3\n1" title="整除与余数"
print(7 // 2)
print(7 % 2)
```

名字是贴在对象上的标签，不是盒子里的一份拷贝。a = b 之后，两个名字先指向同一个对象；接下来给 a 重新赋值，只是把标签 a 挪走，b 仍指向原来的对象。不可变对象（数字、字符串）看起来像「改了就变」，其实是新对象换了标签。列表这类可变对象才会在原地被修改，两个名字会一起看见变化。分清这两件事，能少掉一类「我明明只改了一处」的 bug。

type(x) 返回类型对象，打印它的 __name__ 能得到 int、float、str、bool 这样的短名字。bool 是 int 的子类，True 加 True 等于 2，这是历史事实，不要在业务代码里依赖它。比较相等用 ==，比较是不是同一个对象用 is。None 这种单例才用 is，数字和字符串用 ==。

转换函数 int、float、str 会做出新对象。int("08") 得到 8，int("3.2") 会失败，因为小数点不属于整数字面量。先 float 再 int 会丢掉小数部分，而且是朝零截断，不是四舍五入。round 才负责舍入。文本和数字不能用 + 直接相加，解释器无法猜测你想拼接还是相加。

除法 / 的结果总是 float，即使整除得尽。只要整数商用 //，余数用 %。负数的余数方向和有些语言不同，初学阶段用非负数练习，避免把语言差异当成自己算错。

int 和 float 的字面量很好认：没有小数点的是 int，有小数点的是 float。1 和 1.0 用 == 比较是 True，用 type 看却不是同一种。打印前如果需要整齐的小数，用格式化，而不是指望 float 自己变短。

bool 只有两个值。条件里任何对象都会被当成真或假，但把非布尔值直接当开关会让读的人猜测：空列表为什么是假？在教学代码里，条件尽量写成比较，例如 if items，可以接受；if len(items) > 0 更直白。两者选一种，不要在相邻行换风格。

转换失败会抛异常，本章先知道这件事，捕获留到异常那一章。现在避免把用户随便打的字直接 int()。练习如果使用 input，样例输入必须是合法数字，否则文档测试会看到异常而不是你期望的那一行。

运算优先级和数学里差不多，乘除在加减前面。不肯定时加括号。括号不改变类型，只改变先算哪一步。负数取余先不要用在练习里，把注意力放在正数的商和余数。

## 最佳实践

- 数字和文本相加之前，先明确是要计算还是要拼接，并写出 int 或 str。
- 和 None 比较用 is，和普通值比较用 ==。
- 需要整数商时写 //，不要依赖 float 再取整。

## 小结

赋值是贴标签，类型决定能做哪些运算。转换要显式，除法默认得到浮点数，整除和余数分别用 // 与 %。

## 常见错误

- 用 == 给变量赋值。比较用 ==，绑定用 =。
- 把还没转换的文本和数字相加。文本 6 和数字 7 不能直接相加，先 int 或先 str。
