列表可以改。元组一旦建好就不能替换其中的项，适合当一组固定记录。两者都支持下标和切片。

推导式 `[表达式 for 变量 in 序列]` 用来生成新列表，比先建空列表再 append 更直接。

```python run expect="83.25" title="成绩统计"
scores = [80, 95, 70, 88]
print(sum(scores) / len(scores))
print(max(scores))
print(scores[:2])
```

```python run expect="[3, 1, 2]" title="去重保序"
nums = [3, 1, 3, 2, 1]
seen = []
for n in nums:
    if n not in seen:
        seen.append(n)
print(seen)
```

```python run expect="Ada:36" title="元组与推导式"
pair = ("Ada", 36)
name, age = pair
print(f"{name}:{age}")
print([n * n for n in range(1, 4)])
```

列表是有序、可变的序列。下标从 0 开始，负数从末尾数。append 在末尾加一个元素，extend 把另一个序列里的元素逐个加进来。append 一个列表，得到的是嵌套，而不是更长的一层。切片读列表时得到新列表，改切片的结果不会影响原来的列表；按下标赋值则会改原来的那一格。

元组用圆括号，创建之后不能增删元素，但可以当作字典的键（前提是里面的元素都可哈希）。一个元素的元组必须写成 (x,)，否则括号只是分组。函数返回多个值时，实际上返回的就是一个元组，调用方可以一次解开。

列表推导把「对每个元素做变换、按条件留下」写成一行。它产生新列表，不改输入。推导里可以嵌套，但超过一层就不如普通 for 清楚。排序用 sorted 得到新列表，用 list.sort 在原地排。数字会按数值排；字符串按码点排，大写字母在小写前面。

拷贝要看深度。nums2 = nums 只是第二个名字。nums2 = nums[:] 或 list(nums) 是浅拷贝，内层列表仍共享。需要完全分开时用 copy.deepcopy。初学阶段如果列表里只放数字和字符串，浅拷贝就够。

下标和切片的区别在于：下标取一个元素，类型是元素本身；切片取一段，类型仍是列表。nums[0] 可能是 int，nums[:1] 仍是列表，哪怕里面只有一个数。把后者传给需要 int 的函数会失败。

append 返回 None。写成 nums = nums.append(1) 之后，nums 变成 None，下一行就崩了。调用原地修改的方法时，不要接住返回值再赋值。sorted 和 reversed 不同：sorted 返回新列表，list.reverse 原地修改并返回 None。

元组适合当字典的键，也适合函数一次返回多个值。解开时左边的名字个数必须和元素个数一致，否则报错。不关心的位置用下划线接住。一个元素的元组写成 (item,) ，逗号才是元组的标志，括号只是为了好看。

浅拷贝之后，改外层列表互不影响，改内层仍会共享。如果元素是数字，浅拷贝就够，因为数字不能原地改。如果元素是列表，先问自己：我希望内层一起变，还是各改各的？

列表有序且可变，下标从 0 开始，负数从末尾数。append 在末尾加一个元素并返回 None。写成 nums = nums.append(1) 之后，名字会变成 None，下一行就崩。extend 把另一个序列里的元素逐个加进来。append 一个列表得到的是嵌套，不是更长的一层。调用原地修改的方法时，不要接住返回值再赋值。

下标取出的是元素本身，切片取出的仍是列表。nums[0] 可能是整数，nums[:1] 仍是只含一个整数的列表。把后者传给需要整数的函数会失败。切片得到新列表，改切片结果不影响原来的列表；按下标赋值才会改原来的那一格。

元组创建之后不能增删元素，里面的元素都可哈希时可以当字典的键。一个元素的元组必须写成 (x,)，逗号才是元组的标志，括号只是分组。函数一次返回多个值，实际返回的就是元组。解开时左边的名字个数必须对齐，不关心的位置用下划线。

列表推导产生新列表，不改输入。超过一层的嵌套推导不如普通 for 清楚。sorted 返回新列表，list.sort 原地排并返回 None。浅拷贝之后，改外层互不影响，改内层列表仍然共享。元素只是数字或字符串时，浅拷贝就够，因为它们不能原地改。

::: answer 参考答案：排序后的最小

## 最佳实践

- 要独立的一份列表时写切片或 list()，不要只多起一个名字。
- append 和 extend 的区别在调用前想清楚：加一个元素，还是加多个元素。
- 单元素元组加上逗号，避免被括号当成普通分组。

## 小结

列表可变、元组不可变。切片和推导产生新序列，多个名字指向同一列表时会一起看见修改。

## 常见错误

- 用 scores.sort() 之后还指望它返回新列表。sort 原地修改并返回 None。
- 把元组和列表的括号写反。小括号不是列表。
