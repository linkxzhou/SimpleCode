输出用 `print`，输入用 `input` 或先准备好的文本。

### 分隔符

`sep` 替换参数之间的空格。`end` 替换最后的换行。

```python run expect="tea-water" title="用横线隔开"
print("tea", "water", sep="-")
```

输出里能看到 `tea-water`。

### 拆开一行

数据已经在字符串里时，用 `split` 按空白切开，不必再读键盘。

```python run expect="18" title="第二段"
name, price = "tea 18".split()
print(price)
```

输出里能看到 `18`。

### input 读到换行

没有换行的输入会让 `input` 一直等。围栏里的标准输入要自己带上换行。

```python run stdin="finished\n" expect="finished" title="读一行"
line = input()
print(line)
```

输出里能看到 `finished`。
