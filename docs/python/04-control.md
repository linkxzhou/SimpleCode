条件后面的冒号和缩进组成一个块。`for` 常配合 `range`：`range(3)` 产生 0、1、2。`break` 立刻离开循环。

随机数只要种子相同，序列就相同。下面不打印具体骰子点数，只检查同一颗种子是否给出同一个数，这样换 Python 小版本也不会把测试绑死。

```python run expect="B" title="等级"
score = 86
if score >= 90:
    grade = "A"
elif score >= 60:
    grade = "B"
else:
    grade = "C"
print(grade)
```

```python run expect="稳定" title="固定种子"
import random
a = random.Random(1).randrange(1, 100)
b = random.Random(1).randrange(1, 100)
print("稳定" if a == b else "不稳")
print("范围内" if 1 <= a < 100 else "越界")
```

下面这个循环不会自己停。自动化测试会跳过它；你在页面上运行后，请点击停止。

```python run title="死循环" smoke="skip"
# 故意不停。运行后请按停止，否则后面的示例需要先确认才能接手。
while True:
    pass
```

```python run expect="1 2 Fizz 4 Buzz Fizz 7" title="FizzBuzz"
lines = []
for n in range(1, 8):
    if n % 15 == 0:
        lines.append("FizzBuzz")
    elif n % 3 == 0:
        lines.append("Fizz")
    elif n % 5 == 0:
        lines.append("Buzz")
    else:
        lines.append(str(n))
print(" ".join(lines))
```

if、elif、else 组成一条互斥的链：上面的条件成立，下面的分支就不再看。条件表达式的结果要是真值。空字符串、0、空列表和 None 都当作假，其余多数对象当作真。不要写 if flag == True，直接写 if flag。相等比较用 ==，一个等号是赋值，写在 if 里会成为语法错误。

for 用来遍历一个序列，range(n) 产生 0 到 n-1。range(1, 8) 才包含 1 不包含 8。while 在条件为真时重复。循环里的 break 立刻离开这一层循环，continue 跳到下一轮。else 子句可以挂在循环后面，表示循环没有被 break 打断，初学时少用，读起来容易和 if 的 else 搞混。

随机数只要种子相同，后面的序列就相同。本环境不保证和你电脑上某一次 random.random() 的具体小数一致，所以示例比较两次 Random(同一个种子) 的结果，而不是把某个点数写死。需要「看起来随机、测试仍稳定」时，都用这个办法。

死循环会占住运行时。文档里那一段 while True 被标成跳过自动测试，你在页面上点了它，就要再点停止，否则下一个示例会先问你要不要中断。写自己的循环时，先想清楚每一轮哪一个变量在靠近结束条件。

分支的缩进必须对齐。if 下面的第一行如果少了四个空格，它就不属于这个 if，可能在条件为假时也执行。这是 Python 里最常见的「逻辑看起来对、跑起来不对」。把一块代码临时注释掉时，注释整块，不要留一行没注释的语句在错误的缩进上。

range 的右端不包含。range(1, 8) 走 1 到 7。写 FizzBuzz 时如果结果少了最后一个数，先检查 range 的终点。for 循环的变量在循环结束后仍然存在，值是最后一轮的那个。不要假设它会消失。

while 适合「还不知道要走几轮」的情况，例如读到空行为止。如果你其实知道次数，用 for 更难写出死循环。死循环示例被跳过自动测试，是因为它不会自己结束，测试进程会被拖住。页面上运行它之后要按停止。

种子相同只保证同一个 Random 对象的序列相同。random.random() 用的是全局生成器，别的代码只要也调用过它，序列就会被推进。示例因此自己 new 一个 Random(种子)，不碰全局那个。

if、elif、else 是互斥的链。上面的条件成立，下面的分支就不再看。所以更具体的条件要写在前面。先写「大于等于 60」再写「大于等于 90」，90 分会掉进及格那一支，优秀永远走不到。条件里不要写 if flag == True，直接写 if flag。一个等号是赋值，写在 if 里是语法错误。

空字符串、0、空列表和 None 当作假，其余多数对象当作真。空列表是假，这和后面「列表是否存在」不是一回事。for 遍历序列，range 的右端不包含。range(1, 6) 是 1 到 5。循环变量在循环结束后仍然存在，值是最后一轮的那个，不要假设它会消失。break 离开这一层循环，continue 进入下一轮。循环上的 else 表示没有被 break 打断，初学时少用，容易和 if 的 else 搞混。

while 适合还不知道要走几轮的情况。若其实知道次数，用 for 更难写出死循环。写 while 时先说出每一轮哪一个变量在靠近结束条件。说不出来就先别运行。文档里的 while True 被标成跳过自动测试，页面上点了它就要再点停止，否则下一个示例会先问你要不要中断。

随机数只要种子相同，序列就相同。不要和某一次 random.random 的具体小数比较，这个环境和你的电脑不保证同一串小数。示例自己构造 Random(种子)，不碰全局生成器，因为别的代码只要调用过全局那个，序列就会被推进。

## 练习

用 while 打印 3 到 1，最后一行是「出发」。

::: answer 参考答案：倒计时
```python run expect="出发" title="参考答案"
n = 3
while n > 0:
    print(n)
    n -= 1
print("出发")
```
:::

用 for 把 1 到 4 的整数加起来并打印。

::: answer 参考答案：一到四的和
```python run expect="10" title="参考答案"
total = 0
for n in range(1, 5):
    total += n
print(total)
```
:::

## 最佳实践

- 循环变量每轮都要向结束条件靠近，写完先用小范围在纸上走两轮。
- 随机结果用固定种子互相比对，不把某一次的小数写进期望输出。
- 多层条件从最具体的情况写到最一般的情况，避免前面的分支把后面盖住。

## 小结

分支靠缩进和冒号组成块，for 遍历序列，while 靠条件停下来。随机数用种子固定下来，死循环要能停。

## 常见错误

- 在 if 同一行后面再写本该缩进的语句。那一行会无条件执行。
- range(1, 8) 不含 8。右端点永远到不了。
