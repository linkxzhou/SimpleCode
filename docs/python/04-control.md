东柜用三样东西决定要不要催人：逾期的天数、书名有没有写上、还在催还名单里的那些书。三样东西都可能是「什么都没有」。天数可能是 0，书名可能是空字符串，名单可能是空列表。Python 的条件不要求你写成 `if overdue != 0` 这种完整比较，它允许对象自己回答「算不算真」。这个自由省掉一些字，也把三种完全不同的「没有」收成同一种假。你若不知道收进去的有哪些，就会把「没有逾期」和「没有这本书」印成同一句提醒。这一章先把真值看清楚，再谈怎样沿名单走，以及怎样在该停的时候停。

真和假在条件里看的不是类型名。整数 0 为假，其他整数为真。空字符串为假，任何还有字符的字符串为真，包括一个空格。空列表为假，里面有元素就为真。None 也为假。布尔值 True 和 False 就是它们自己。借书台上最容易混的是 0 和空列表：0 天逾期表示「不催」，空的催还名单也表示「不催」，可一个是数，一个是容器。它们在 if 里走同一支，不代表你可以拿其中一个去代替另一个。打印时一个是 0，一个是 `[]`，句子不该只写「没有」。下面这一块只看天数。0 走进 else，印出无逾期。注意比较没有写成 `if overdue == True`。和 True 做相等比较能通过的是 True 本身，0 并不是 True，所以那种写法会把 0 和 5 都当成「不是 True」，分支就废了。你要的是对象的真值，直接把对象放进 if。

```python run expect="无逾期" title="零天不催"
overdue = 0
if overdue:
    print("有逾期")
else:
    print("无逾期")
```

把 overdue 改成 3，会印有逾期。改成 -1 也会印有逾期，因为非零即为真。负数天数在业务上没有意义，真值却不会替你排除它。真值只回答「像不像空」，不回答「合不合法」。合法的天数应当另有检查，例如小于 0 就拒绝。不要把 if overdue 理解成「逾期情况良好」。它只是「这个数不是零」。

空字符串和空列表用同一条规则，但打印的句子必须分开，否则馆员看不出是条子没写书名，还是催还名单是空的。下面这一块两种空一起出现。not 把真值取反，空因此走进分支。非空的书名「小径」不会印出「无书名」。

```python run expect="空架" title="空串与空列表"
title = ""
shelf = []
if not title:
    print("无书名")
if not shelf:
    print("空架")
filled = ["小径"]
if filled:
    print("架上有书")
```

输出三行：无书名、空架、架上有书。第三行说明列表一旦有了元素就为真，哪怕那个元素本身是空字符串。`[""]` 是真，因为它不是空列表。里面的那个空字符串若单独拿出来仍是假。容器的真值看的是有没有元素，不看元素自己真不真。这个区别在催还名单里很具体：名单里有一条空白记录，名单本身仍算「有记录」，你该去处理那条空白，而不是宣称架是空的。

空格字符串 `" "` 是真。眼睛看见的像空白，len 却是 1。读者若在输入时多敲了空格，input 不会替你去掉两端的空白，真值也不会把这行当成没填。需要时用 strip 做出去掉两端空白的新字符串，再判断。strip 不修改原串。这一章的例子用的空串是真正的长度 0，以免和空格混在一起。

条件可以接成一条链。if、elif、else 里只有一支会执行。冒号和缩进的规矩已经在输出那一章建立过，这里继续用四个空格。逾期天数若分成「无」「轻度」「重度」，要用明确的比较，不要只用真值。真值分不出 1 天和 40 天。下面按天数给出说法，0 已经在上一块处理过，这一块用 10 天，应当落在轻度。

```python run expect="轻度" title="按天数分档"
days = 10
if days <= 0:
    level = "无逾期"
elif days <= 30:
    level = "轻度"
else:
    level = "重度"
print(level)
```

elif 是「否则如果」，它只在前面的条件都为假时才被询问。把顺序写反，大于 30 的判断若放在前面，轻度那一支可能永远走不到，或者重度被轻度提前截走。写链的时候从最窄的条件想到最宽的，或者按天数从小到大排，每支都用同一套边界。边界用 `<=` 还是 `<`，要和下一支接得上，不要留下一个天数哪支都不认。10 和 30 在这套边界里属于轻度，31 属于重度，0 属于无逾期。

循环用来沿同一批书走。for 从可迭代对象里逐个取出元素。列表是可迭代的。循环变量每次指向当前那一本，块结束之后它仍留在最后一个值上，不会自动消失。这偶尔让人在循环外误用这个名字，以为它还代表「全部的书」。它不代表。它只是最后一次绑定。下面沿着三本书找小径，找到就打印并 break。break 立刻离开这一层循环，不再看后面的海边。

```python run expect="小径" title="找到就停"
books = ["夜航", "小径", "海边"]
found = False
for name in books:
    if name == "小径":
        print(name)
        found = True
        break
if not found:
    print("没有这本")
```

若名单里没有小径，found 保持 False，循环正常结束，然后印没有这本。用一个布尔记住「有没有遇到」，比在循环后面检查循环变量是不是小径更可靠。循环变量在找不到时会停在最后一本上，那一本不是你的答案，只是名单的末尾。这是 for 的一个容易忽略的残留。

while 在条件为真时重复。它适合「还没还清就继续」这种事先不知道次数的场合。次数已知时，for 通常更清楚，因为结束条件写在头部的可迭代对象上，而不是藏在块的末尾。while 的坑是条件永远为真。下面这一块就是故意写出来的死循环。它没有出口，自动化检查会跳过它，不真正启动。你若在页面上手动运行，需要自己停止，否则下一份示例要等你确认这个进程已经结束。把它放在这里，是为了让「不会停」有一个看得见的形状，而不是为了让你每天运行它。

```python run title="死循环" smoke="skip"
while True:
    pass
```

pass 在这里占住循环体。没有它，语法上就缺少一个块。True 永远为真，所以就算把 pass 换成一句 print，它也会一直印下去。真正的催还不该写成这样。应当有一个会变化的条件：名单空了，或者天数减到了 0，或者用 break 离开。下面用 while 把逾期天数从 2 减到 0，每次印当前天数。条件用的是真值：天数变成 0 时循环停止。减的方式是重新绑定，因为整数不能就地减。这一点和类型那一章接上。你若忘记写 `days = days - 1`，循环就会真的不停，和上面那个被跳过的例子成为同类。

```python run expect="2" title="天数减到零就停"
days = 2
while days:
    print(days)
    days = days - 1
print("停")
```

输出是 2、1、然后停。0 没有被印出来，因为进入循环体之前会先看条件，0 已经为假。有人希望把 0 也印出来表示「今天结清」，那要把 print 放进循环之前或之后，而不是指望 0 还能走进 while days。真值作为循环条件时，把「0 还进不进循环」先想清楚。

continue 跳过这一轮剩下的语句，直接进入下一轮。它不结束整个循环。在催还名单里，空白书名可以 continue，有书名的才打印。break 则是「书已经找到，后面的都不用看」。两个词都只作用于最内层的这一层循环。若以后出现循环套循环，内层的 break 不会直接离开外层。借书台目前的名单只有一层，不要为了提前离开外层去使用额外的标志，除非你真的有两层。

range 产生一串整数，常和 for 一起用来数次数。`range(3)` 给出 0、1、2，同样是止点不包含。它不先造出一个装了三个整数的列表再交给你，这和后面迭代器那一章的惰性是同一方向，这里先把它当成「数次数的工具」。用 range 去遍历书名是舍近求远：你已经有列表，直接 for name in books。只有在你需要下标时才用 range 配合长度，而需要下标往往是因为你要同时改列表的某一格。能不改就先不改。

嵌套的条件写在循环里时，缩进会到八个空格。那仍然是四个空格的两级台阶，不是一种新的空白。先看哪一行和 for 对齐，那一行就不在循环里。再看哪一行和 if 对齐，那一行就在循环里但在条件外。眼睛顺着台阶走，比顺着中文注释走更可靠。注释可以被写在任何一行的行尾，它不改变台阶。

最后把真值和循环的关系收成借书台的规矩。空名单不进入「逐本催还」的循环体，因为 for 在空列表上一次都不执行，while 在假条件上也不进入。这通常是你想要的。它也意味着循环后面的语句仍会执行。不要把「印出催还完毕」放在循环里面，否则空名单不会印这句，你分不清是还没跑到，还是名单是空的所以一次都没跑。完毕的句子放在循环之后。找到目标就 break 的那种循环，完毕的句子要区分「找到了」和「找完了没有」，用循环外的标志，而不是用最后一次的循环变量。

`and` 和 `or` 也吃真值，而且会短路。`overdue and shelf` 若天数已经是 0，右边的名单根本不会被看。这在避免多余工作时有用，在你以为两边都会被检查时会漏。`or` 返回的不一定是布尔，它返回第一个为真的对象本身。`title or "未填"` 在书名是空串时得到「未填」，在书名是「小径」时得到「小径」这个字符串，而不是 True。你若再把它放进 `== True`，小径会被当成假。借书台上用 `or` 填默认书名可以，用它的结果去和 True 比较不行。默认值要选一个不可能是合法书名的句子，否则读者真的借了一本叫「未填」的书时，你分不清是默认还是书名。

循环变量的残留和短路可以碰在一起。你在 for 里找到小径就 break，循环外写 `print(name or "没有")`。找到时 name 是小径，没找到时 name 是最后一本，仍然为真，`or` 不会换成「没有」。于是「没有」这句永远不出现，最后一本书冒充查找结果。标志变量仍然比循环变量诚实。短路救不了残留的名字。

天数从 2 减到 0 的那一块，打印发生在减法之前，所以 0 不出现。若你把减法放在打印前面，第一轮就会先变成 1，2 永远看不见，循环仍会停，只是催还记录少了起点。顺序是业务的一部分。while 的条件只决定进不进这一轮，不决定这一轮里先说话还是先改数。改数若写成 `days = days`，条件不变，就和那个被跳过的死循环成为同类，只是看起来没那么显眼。读 while 时先找哪一行会让条件变假。找不到那一行，就不要运行它。

## 小结

0、空字符串、空列表和 None 在条件里为假；非零数字、非空字符串、非空列表为真。真值不检验负数天数合不合法，也分不出 1 天和 40 天，分档要用比较和 elif。for 沿列表逐本取出，break 离开这一层，循环变量会残留最后一次的值。while 靠条件变假或 break 停止；条件永远为真的循环不会自己结束。

## 练习

催还名单是空列表。用它的真值决定印「需要催还」还是「今天不催」。应当印今天不催。

::: answer 参考答案：空名单
```python run expect="今天不催" title="参考答案"
due = []
if due:
    print("需要催还")
else:
    print("今天不催")
```
:::

书单是夜航、小径、海边。用 for 找出海边并打印，找到后 break。不要把三本书都印出来。

::: answer 参考答案：找到海边
```python run expect="海边" title="参考答案"
books = ["夜航", "小径", "海边"]
for name in books:
    if name == "海边":
        print(name)
        break
```
