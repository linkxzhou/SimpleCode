条件里的 0 和空字符串都是真。只有 `false` 和 `nil` 为假。

### 缺货

库存是 0 时，和 0 比较成立，走缺货。

```lua run expect="soldout" title="没有库存"
local stock = 0
if stock == 0 then
  print("soldout")
else
  print("instock")
end
```

输出里能看到 `soldout`。

### elseif

代码 2 落到第二支。

```lua run expect="second" title="第二支"
local code = 2
if code == 1 then
  print("first")
elseif code == 2 then
  print("second")
else
  print("other")
end
```

输出里能看到 `second`。

### 零仍是真

0 放进条件本身是真，所以打出 has。

```lua run expect="has" title="零为真"
local n = 0
if n then
  print("has")
else
  print("none")
end
```

输出里能看到 `has`。
