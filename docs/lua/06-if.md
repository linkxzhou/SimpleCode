条件里的 0 和空字符串都是真。只有 `false` 和 `nil` 为假。

### 缺货

库存是 0 时，和 0 比较成立，走缺货。

```lua run expect="缺货" title="没有库存"
local stock = 0
if stock == 0 then
  print("缺货")
else
  print("有货")
end
```

输出里能看到 `缺货`。

### elseif

代码 2 落到第二支。

```lua run expect="乙" title="第二支"
local code = 2
if code == 1 then
  print("甲")
elseif code == 2 then
  print("乙")
else
  print("其他")
end
```

输出里能看到 `乙`。

### 零仍是真

0 放进条件本身是真，所以打出「有」。

```lua run expect="有" title="零为真"
local n = 0
if n then
  print("有")
else
  print("无")
end
```

输出里能看到 `有`。
