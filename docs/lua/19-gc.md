回收器会清掉没有人再指着的表。具体字节数每次不同，例子不拿它做期望。

### 丢掉引用

局部变量结束之后，那张表就可以被收回。这里先打出创建时的长度。

```lua run expect="2" title="先是长度"
local t = { "tea", "pen" }
print(#t)
t = nil
print(t == nil and "none" or "has")
```

输出里能看到 `2`。

### 主动收集

`collectgarbage("collect")` 跑完后打出 taken。

```lua run expect="taken" title="收集一次"
local t = { 1, 2, 3 }
t = nil
collectgarbage("collect")
print("taken")
```

输出里能看到 `taken`。

### 计数的类型

`count` 返回数字。课程只检查类型，不固定大小。

```lua run expect="number" title="是数字"
print(type(collectgarbage("count")))
```

输出里能看到 `number`。
