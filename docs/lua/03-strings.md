字符串用 .. 拼接。数字和字符串用 .. 时，数字会转成文本。用 + 会按数字相加，文本必须能转成数。

下标从 1 开始。string.sub(s, 起, 止) 的止是包含的结束位置，不是长度。string.sub("SimpleCode", 1, 4) 得到 Simp。#s 是字节数。"Ada" 是 3。"你好" 是 6。正文里要写明这一点，示例用 print 核对。

字符串不能原地改某一个字节后还以为别的变量没变。连接会得到新字符串。

```lua run expect="你好，Ada" title="拼接"
local name = "Ada"
print("你好，" .. name)
```

```lua run expect="Simp" title="前四个"
print(string.sub("SimpleCode", 1, 4))
```

```lua run expect="3" title="字节"
print(#"Ada")
print(#"你好")
```

## 常见错误

- 下标从 0 开始取，拿到的是 nil 或错字。
- 把 #"你好" 当成 2。
- 用 + 拼接两段文本。

## 最佳实践

- 切片用 string.sub，并记住结束位置包含在内。
- 拼接用 .. 。
- 中文长度写明是字节。

## 小结

拼接用 .. 。下标从 1 开始，sub 的结束位置包含在内。# 按字节计数。
