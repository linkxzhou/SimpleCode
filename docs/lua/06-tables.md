表是 Lua 的数组和映射。数组部分从 1 开始，t[1] 是第一个。#t 是数组部分的长度，中间如果有 nil，长度会在空洞处停住。教学例子不往数组里塞 nil。

映射用字符串键，t["Ada"] 或 t.Ada。缺失的键是 nil。给默认值写成 t[name] or 0，再做加法。

ipairs 按 1、2、3 遍历直到 nil。pairs 遍历全部键，顺序不要写进期望。要稳定输出时，只 print 某一个键或一个算好的总数。

```lua run expect="10" title="求和"
local t = {1, 2, 3, 4}
local total = 0
for i = 1, #t do total = total + t[i] end
print(total)
```

```lua run expect="3" title="映射"
local scores = {}
scores.Ada = (scores.Ada or 0) + 1
scores.Ada = scores.Ada + 2
print(scores.Ada)
```

```lua run expect="3" title="长度"
local t = {"a", "b", "c"}
print(#t)
```

## 常见错误

- 数组从 0 开始放，# 和 ipairs 对不上。
- 在数组中间放 nil，# 提前结束。
- 依赖 pairs 的遍历顺序。

## 最佳实践

- 列表从 1 连续存放。
- 缺失的映射用 or 0。
- 只打印算好的一个数。

## 小结

表的数组部分从 1 开始。# 在 nil 空洞处停住。字符串键用来做映射，缺失是 nil。

## 练习

从表 {3, 1, 2} 找出最小并打印。

::: answer 参考答案：最小
```lua run expect="1" title="参考答案"
local t = {3, 1, 2}
local m = t[1]
for i = 2, #t do if t[i] < m then m = t[i] end end
print(m)
```
:::

缺失键按 0 打印。

::: answer 参考答案：默认
```lua run expect="0" title="参考答案"
local t = {}
print(t.a or 0)
```
:::
