if ... then ... elseif ... else ... end。条件只有 nil 和 false 为假。0 会走进 then。

数字 for 写成 for n = 1, 5 do。结束值包含在内。for 的循环变量是局部的。while 在条件为真时重复，每一轮都要让条件靠近结束。

循环里用 local total = 0 再累加。在循环里 print 每一次，期望就要包含每一行。能在外面打印总和就在外面打印。

```lua run expect="9" title="奇数和"
local total = 0
for n = 1, 5 do
  if n % 2 == 1 then total = total + n end
end
print(total)
```

```lua run expect="3" title="数到三"
local n = 0
while n < 3 do
  n = n + 1
end
print(n)
```

```lua run expect="yes" title="零仍为真"
local n = 0
if n then print("yes") else print("no") end
```

## 常见错误

- 把数字 for 的结束值理解成不包含。
- while 里不改变条件。
- 用 if n 判断 n 是不是 0。

## 最佳实践

- 次数清楚时用数字 for。
- 判断零用 == 0。
- 循环外打印总和。

## 小结

if 只把 nil 和 false 当假。数字 for 包含结束值。while 必须有变量靠近结束。
