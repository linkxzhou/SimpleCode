元表给表附加行为。setmetatable(表, 元表) 把它们连起来。__index 是另一张表时，原来的表没有的键会到这张表里找。已经有的键不会被遮住。

这不是把字段复制过来。改原型上的值，通过 __index 能看见新值；对象自己写入同名字段后，就不再去原型里找。

本教程只用 __index 做默认字段。不写 __add 之类的运算，避免示例变成一堆隐式规则。

```lua run expect="2" title="默认字段"
local proto = { n = 2 }
local obj = setmetatable({}, { __index = proto })
print(obj.n)
```

```lua run expect="2" title="自己的字段优先"
local proto = { n = 1 }
local obj = setmetatable({ n = 2 }, { __index = proto })
print(obj.n)
```

```lua run expect="42" title="写入后"
local proto = { n = 1 }
local obj = setmetatable({}, { __index = proto })
obj.n = 41
print(obj.n + 1)
```

## 常见错误

- 以为 setmetatable 会把字段复制一份。
- 对象已经有的键还指望原型覆盖它。
- 在元方法里再改元表，读起来无法预测。

## 最佳实践

- 默认字段放在 __index 指向的表。
- 对象自己的数据直接写在对象上。
- 这一章只演示 __index。

## 小结

__index 在键缺失时提供另一张表。对象自己的键优先。它不是复制。

## 练习

通过 __index 读到 n 为 7 并打印。

::: answer 参考答案：默认
```lua run expect="7" title="参考答案"
local proto = { n = 7 }
local obj = setmetatable({}, { __index = proto })
print(obj.n)
```
:::

对象自己的 n 是 4，打印它而不是原型的 1。

::: answer 参考答案：覆盖
```lua run expect="4" title="参考答案"
local proto = { n = 1 }
local obj = setmetatable({ n = 4 }, { __index = proto })
print(obj.n)
```
:::
