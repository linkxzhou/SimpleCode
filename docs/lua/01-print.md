print 把参数转成文本，参数之间放制表符，最后换行。只要一个参数时，没有制表符。教学里多数时候只打印一个值，期望才稳。

注释从 -- 开始直到行尾。长注释用 --[[ ]]。注释不会出现在输出里。

局部变量用 local。不写 local 的赋值会变成全局变量，容易在长脚本里互相踩到。示例一律用 local。改完用工具栏的 Run 看结果，代码块上的 Run 会把修改盖掉。预测时不要把制表符当成空格。要紧挨的两个字，先拼成一个字符串再打印。不要靠打印两个参数来拼词。

```lua run expect="Ada" title="两行"
print("Ada")
print("Lovelace")
```

```lua run expect="AB" title="一个值"
print("A" .. "B")
```

```lua run expect="可见" title="注释"
print("可见")
-- 这一行不会出现
print(2026)
```

先做这一例。把代码收成一行来记：`print("Ada") print("Lovelace")`。先盖住终端，写下你预测的输出，里面要能找到「Ada」。这是子串：前面可以有别的字，后面通常有换行。

然后点这个代码块上的 Run，不要点工具栏。代码块会备份草稿、写入示例再执行。找不到这段文字时，先看退出码。不是 0 就读错误类型，不要改期望。是 0 但内容不对，就只改产生该值的那一处。改完用工具栏的 Run，因为再点代码块会把修改盖掉。预测对了之后点撤销。

### 只改一处：两行

这一例要避开的失误是：print("A", "B") 以为得到 AB，实际中间有制表符。。对应的做法是：一次 print 一个需要核对的值。。

把代码收成一行来核对：`print("Ada") print("Lovelace")`。盖住终端，先写下预测，里面要能找到「Ada」。然后点这个代码块上的 Run。结果不同时，只改产生该值的那一行，再用工具栏的 Run 看新结果。不要把两处不相关的改动叠在一起。确认之后点撤销，下一例才会从文档里的代码开始。

## 读完再动手

本章要留下的是 「用 print 打出文本和数字」、「写出注释」、「知道多个参数之间是制表符」。合上抽屉之前，用自己的话说出每一项目标对应哪一个示例的标题。对不上标题，就还没有把目标和代码连起来，先别展开练习答案。

练习的答案默认折着。先在编辑器里自己写，再展开对照。对照时只看输出是否包含期望的那几个字。两道都过了再进入下一章。下一次运行是新进程，这次的变量不会留下。

把这一章当成一次可以反复撤销的实验。点代码块上的 Run 会用示例覆盖编辑器，原来的草稿先备份。你改过的内容如果还想留着，先复制到别处，再点下一例。工具栏的 Run 不会从文档重写编辑器，所以它用来看你改过的版本。两种按钮各做各的事。下载进度写在按钮旁边，第一次打开这种语言时要等它结束，再判断示例是不是写错了。

记录你预测错的那一次。写下你以为会打印的文字，以及实际多出来或少掉的部分。进入下一章之前，要能用一句话说清差在哪。通过只说明期望的那几个字还在，不说明你已经看懂产生它的那一行。章节标题下的目标就是这份验收清单。差两个字也不要靠改期望凑过去。

## 常见错误

- print("A", "B") 以为得到 AB，实际中间有制表符。
- 不写 local，名字泄漏成全局。
- 注释写了和代码相反的话。

## 最佳实践

- 一次 print 一个需要核对的值。
- 要连在一起的文本用 .. 。
- 变量写成 local。

## 小结

print 会换行。多个参数用制表符分开。要紧挨的文本先用 .. 拼成一个值。
