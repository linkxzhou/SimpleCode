Lua 5.4 里，/ 是浮点除法，20 / 6 得到大约 3.333。整数除法用 //，20 // 6 得到 3。余数用 %。

条件里只有 false 和 nil 为假。0 和空字符串都是真。这和 C、PHP 相反，和 Ruby 相同。不要用 if n 判断数字是不是 0。

nil 表示没有值。没有赋值的局部变量是 nil。type 返回类型名的字符串，例如 number、string、nil。比较 nil 用 == nil。

```lua run expect="3" title="整除"
print(20 // 6)
print(20 % 6)
```

```lua run expect="yes" title="零是真"
local n = 0
if n then print("yes") else print("no") end
```

```lua run expect="number" title="类型"
print(type(42))
```

## 常见错误

- 以为 / 得到整数。
- 把 0 当成假。
- 用 if s 判断空字符串。空字符串是真。

## 最佳实践

- 要整数商时用 //。
- 判断 0 用 == 0。
- 看不清时 print(type(...))。

## 小结

/ 是浮点除法，// 才是整数除法。只有 nil 和 false 为假，0 是真。
