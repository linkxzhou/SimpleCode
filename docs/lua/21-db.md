没有 `luasql`，也没有网络。一行结果就是一张表。

### 驱动不运行

连接函数不在这份解释器里。

```lua norun title="没有驱动"
local driver = require("luasql.sqlite3")
print(driver)
```

### 一行

名字和单价放在同一张表里。

```lua run expect="tea 18" title="一行"
local row = { name = "tea", price = 18 }
print(row.name .. " " .. row.price)
```

输出里能看到 `tea 18`。

### 两行

外层表按下标 1 和 2 放两行。

```lua run expect="pen" title="第二行"
local rows = {
  { name = "tea" },
  { name = "pen" },
}
print(rows[2].name)
```

输出里能看到 `pen`。
