string、math、table 是语言自带的表，不是要安装的库。string.format 用 %d 和 %s，得到一个字符串，再 print。string.sub 做切片。

math.min 和 math.max 接收多个数字。math.floor 朝更小的整数走。整数除法仍优先用 //，少绕一层。

table.sort 会改原来的表。排序后 t[1] 是最小的，如果比较函数是默认的。需要旧顺序时，先造一张新表再排序。table.concat 把字符串数组收成一行，分隔符由你指定。

```lua run expect="1" title="最小"
print(math.min(3, 1, 2))
```

```lua run expect="Ada 42" title="格式"
print(string.format("%s %d", "Ada", 42))
```

```lua run expect="1" title="排序"
local t = {3, 1, 2}
table.sort(t)
print(t[1])
```

## 常见错误

- sort 之后还以为原来的第一个元素留在原位。
- string.format 的 %d 配了字符串。
- 用 math.floor(20/6) 代替 //，却忘了负数的方向。正数示例可以用，正文仍推荐 //。

## 最佳实践

- 切片用 string.sub，格式化用 string.format。
- 要最小的数用 math.min。
- sort 之前确认可以改这张表。

## 小结

string、math 和 table 随解释器提供。sort 会改原表。格式化的结果再 print。
