前面每一块的标题都写在源码里。周衡若临时加一件事，就得改脚本。最后这一章把那一行挪到标准输入。抽屉的围栏负责在进程启动时把字节送进去，脚本用 io.read 去取。取一行的格式是 `"*l"`。它会读到换行停下，交给你的字符串里不含那个换行。若字节在换行出现之前就结束，它仍把已经读到的内容交出来。所以围栏写成买笔两个字、后面不加强行，你还是能拿到买笔。再读一次，没有更多字节，结果是 nil。nil 表示结束，不是空标题。空标题是读到了一行、里面一个字都没有，那时候结果是空字符串。

```lua run stdin="买笔" expect="买笔" title="围栏送来的一行"
local line = io.read("*l")
if line == nil then
  print("没有")
else
  print(line)
end
```

这一块的围栏就是买笔。期望也是买笔。两者写在同一处附近，是为了让你看见：输出里的词来自输入，不再来自 print 旁边的字面量。你把围栏改成浇花，源码一个字都不用动，输出会跟着变。这种跟随只发生在同一次进程。下一块若也想读买笔，必须自己再写围栏。上一块读过的标准输入不会留下来。

空的输入和空白行要分开。围栏什么都不放，第一次 read 就是 nil，纸上不该出现一条待办。围栏只放一个换行，read 得到空字符串，那是一条空标题，按前面的规则应当拒绝，而不是当成结束。结束才停止循环。空标题是循环体内的一次拒绝，然后继续读。把 nil 和空串写成同一个 if，会在第一行空白时停住，后面的交表再也进不来。

```lua run stdin="" expect="没有" title="没有字节就结束"
local line = io.read("*l")
if line == nil then
  print("没有")
else
  print(line)
end
```

```lua run stdin="\n" expect="空白行" title="只有换行是空字符串"
local line = io.read("*l")
if line == nil then
  print("没有")
elseif line == "" then
  print("空白行")
else
  print(line)
end
```

多行时用循环，直到 nil。读到的非空行追加到表的末尾，下标仍从 1 长起来。追加用 `#items + 1`，前提是我们从不往中间写 nil。空行直接跳过，不写入，于是不会制造空字符串元素，也不会制造洞。跳过用内层 if，不用 continue。循环一定能结束，因为围栏的字节有限，最后必然 nil。不要写一个没写结束条件的循环去等下一行，抽屉里没有人会再敲键盘，等待会变成超时，超时不是条数。

```lua run stdin="买笔\n\n交表\n" expect="买笔" title="跳过空白行再收下一条"
local items = {}
while true do
  local line = io.read("*l")
  if line == nil then
    break
  end
  if line ~= "" then
    items[#items + 1] = line
  end
end
print(#items)
print(items[1])
```

条数是 2，第一条是买笔。空白行没有占位置，交表在下标 2。期望锁定买笔，阅读时把 2 也看一眼。若空行被算进去，条数会变成 3，第一条仍是买笔，只靠买笔的子串就发现不了。所以改这一块时，先打印长度。长度和标题一起，才证明跳过生效。

读入的每一行都是字符串，哪怕内容看起来像数字。优先级若从输入来，要单独转换。转换失败得到 nil，不应当静默变成 0，因为 0 在条件里是真，一条坏的优先级会变成一条「有优先级」的待办。这一章的输入只当标题，不做转换，避免把类型问题混进读取。标题里的汉字按原样进入表，`#` 仍然是字节。买笔进表之后长度是 6，和写在源码里的时候一样。输入途径不改变字符串的计量。

io.read 还可以用 `"*n"` 读数字，用 `"*a"` 一次读完剩下的全部。`"*a"` 在空输入上得到空字符串，而不是 nil，这和 `"*l"` 不同。全部读完再自己切行，要处理最后一行没有换行的情况，切错会多出一条空的。`"*l"` 把这个边界已经处理好：有内容就给出内容，完全没有就给出 nil。待办一行一件事，用 `"*l"` 最贴这张纸。数字格式留给优先级真的来自输入的那次修改，到时再改格式，而不是现在就 `"*a"` 把所有字节揉成一块。

不要在读到一行之后调用 os.execute 去让外部程序处理它，也不要 io.popen。标题可能包含任何字符，送进壳会有另一类麻烦，而这个进程本来也没有壳。处理就用已经学过的东西：空串拒绝，表从 1 追加，需要排序就 table.sort，需要替换就 string.gsub 并且只取第一个结果。这些都在同一次进程里完成，做完就打印。打印仍是核对的唯一出口。

把这一章收成一份能单独抄走的小脚本时，顺序应当是：准备一张空表，循环读取，跳过空行，非空则追加，结束后打印条数和第一条。函数可以用，模块式的局部表也可以用。下面把追加收进局部函数，让循环体只剩下读取和判断。这是前面几章的汇合，不是新的机制。汇合仍然自洽，不依赖上一块的闭包。

```lua run stdin="买笔" expect="1" title="读一行并收进表"
local function add(list, title)
  if title == nil or title == "" then
    return #list
  end
  list[#list + 1] = title
  return #list
end
local items = {}
local line = io.read("*l")
print(add(items, line))
print(items[1])
```

第一行是 1，第二行是买笔。围栏没有第二行，所以不要在这一块里再读一次并假定还有交表。假定来自文章的记忆，不是来自这一次的输入。若你确实要两行，把两行写进这一块的围栏。文章可以说「通常还有交表」，脚本不能。

失败的读入不必用 pcall 去包 io.read。到达结束是 nil，是正常返回，不是 error。只有在你自己的校验里，例如禁止某种标题，才用 error，并且用 pcall 接住，避免整份脚本在最后一行输入上非零退出。正常的结束若也抛错，调用方就分不清「今天没有更多待办」和「标题不合法」。nil 留给结束，error 留给非法，空字符串留给「有一行但没字」。三种出口三种值，和开篇那张纸上的几种没有，是同一件事的最后一次出现。

围栏里的反斜杠 n 是换行。写成买笔再换行再交表，就是两件。不要在围栏里用引号把买笔又包一层，除非你真的希望引号成为标题的一部分。源码里的引号不是输入的一部分。这和 print 的期望一样：记号不要混进数据。买笔这两个字应当原样落在表的第一格。

读入之后若要排序，先把全部行放进表，循环结束再 table.sort。不要在读到一行时就插入到已排序的位置，除非你愿意自己移动后面的元素。读完再排，代码分成两段：一段只负责字节变成表，一段只负责顺序。两段分开，空白行的跳过不会和比较函数缠在一起。比较函数看不见被跳过的空行，因为空行根本没有进表。这比排序时再判断空串更干净。空串若进了表，按字节它会排在最前，第一条变成空白，期望里的买笔还在后面，子串核对仍可能通过，纸的第一行却错了。所以跳过要发生在入表之前。

io.read 的格式串写错时，会在运行中报错，而不是返回 nil。例如多写了一个不存在的模式。这种错误可以用 pcall 接住，但接住之后你仍没有行可以追加。教学示例里把格式写成固定的 "*l"，不从输入里取格式。格式若来自输入，用户一个字符就能改变读取方式，错误会变得像数据。数据是标题，格式是程序。两者分开，是这一章的边界，和「不要把标题送进壳」是同一类边界。

循环里打印每一行，还是循环外打印摘要，取决于你要证明什么。证明每一行都读到了，就在循环里打印，输出里会有买笔和交表两行。证明条数，就在外面打印一个数字。两件事放在同一次打印的两个参数里，中间会插入制表符，期望若写成「2 买笔」带空格就会失败。要一行里既有条数又有标题，用 .. 接上一个你看得见的分隔符，例如空格或冒号。分隔符写在源码里，不靠 print 的默认缝。

标准输入被读完之后，再读仍是 nil，不会重新从头。你不能先走一遍数条数，再走一遍打印，除非在第一遍时把行存进表。表就是为了这个存在的：流只能向前，表可以按 1、2、3 再看一遍。这是把输入收成待办的理由，不只是为了让 # 有地方用。若不存表，就在唯一的那一遍里把要算的都算完。一遍能做完的事不要强行两遍，两遍又没有表，第二遍一定是空的。

围栏里的中文应当和源码一样是 UTF-8。读进来的字节原样成为字符串，不会被收成另一种编码。# 对读进来的买笔仍是 6。若某一天期望里的汉字和工作台显示的汉字看起来一样、字节却不同，那是输入在到达进程前被换了编码，不是 string.sub 的规则变了。这一课的围栏和源码使用同一种编码，所以写在围栏里的买笔和写在字面量里的买笔相等。可以把读到的行和字面量比一下，相等就打印「同一句」。比相等比打印后再用眼睛看更严，眼睛会忽略看不见的空格。

最后把进程的限制再放在读入旁边。读到的标题留在内存里的表上，进程结束就消失。不要试图用临时文件把这一次的待办留给下一次点击，临时名字那条路也不可用。下一次点击若还要买笔，就再在围栏里写一次。重复写，是这门课让每一块都能单独核对的方式。纸是新的，规则已经在前面十章里练过：从 1 数，不挖洞，空串不当真值来拒绝，需要失败时再抛错并接住。读入只是把标题的来源从字面量改成了一次输入。

读到的行若在汉字后面还跟着空格，它就不会和字面量买笔相等。这一课的围栏不放那些空格。以后若输入来自手工敲击，留不留空格要在入表前决定。决定丢掉，就做成新字符串，不要指望读取会修剪。它只去掉换行。换行不属于标题，空格可能属于。属于与否是这一张纸的口味，读取保持原样，口味放在追加之前。这样读取的合同不跟着口味变。

同一行里要同时给人看条数和标题时，用连接放进同一次打印。两个参数会在中间夹上制表符，看起来像空白，按空格去对就会失败。连接符两侧都是你写的，冒号或空格都显式出现在源码里。围栏里的买笔只占数据的位置，不占格式的位置。格式在源码，数据在围栏，两边都能单独改。

## 小结

io.read("*l") 从标准输入取下一行，不含换行；什么都没有时得到 nil，只有换行时得到空字符串。循环在 nil 上停，空字符串跳过，其余追加到从 1 开始的表。围栏决定这一次的字节，买笔可以不带换行。读入不调用外部程序，结束也不是异常。打印条数和第一条，才能同时看见跳过空行之后纸上还剩什么。
