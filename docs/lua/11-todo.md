待办是一次运行里的表。没有网络，也不写文件。下次运行列表是空的。数组部分从 1 连续存放，空字符串不要放进去，否则它会占一个位置。

计数写成函数，参数是表。读入用 io.read("*l")，读到 nil 就是没有输入。空行不加。输出只打条数，或打出指定位置的那一条。位置先和 #items 比较。

示例可以不读键盘，直接构造表，让规则先被 print 核对。需要演示读入时单独写一条 stdin。

```lua run expect="1" title="非空条数"
local function count(items)
  local n = 0
  for i = 1, #items do
    if items[i] ~= "" then n = n + 1 end
  end
  return n
end
print(count({"买笔", ""}))
```

```lua run expect="买笔" title="第一条"
local items = {"买笔", "写信"}
print(items[1])
```

```lua run stdin="买笔\n" expect="1" title="读一条"
local items = {}
local line = io.read("*l")
if line == nil or line == "" then
  print("失败")
else
  items[#items + 1] = line
  print(#items)
end
```

## 常见错误

- 从 0 插入，# 和读取对不上。
- 把空字符串放进数组还指望 # 表示有效条数。
- 以为列表会留到下一次运行。

## 最佳实践

- 只把非空行插入表。
- 条数用函数算，或在插入时就排除空行后用 #。
- 只打印条数或某一条。

## 小结

待办是一次运行内从 1 开始的表。空行不加。io.read("*l") 读一条。下次运行不会还在。
