def 定义方法。参数按位置传入，也可以写默认值。默认值在没传那个参数时使用。return 可以省掉，方法会返回最后一行表达式的值。本教程需要看结果时仍然 puts，不依赖隐式返回被打印出来，因为返回值本身不会自动出现在终端。

块是传给方法的一段代码。yield 在方法里执行这块代码。带参数的块写成 { |n| ... } 或 do |n| ... end。一行时用花括号，多行时用 do end。map、each、select 接收的就是块。

块能看见外面的局部变量，并且能改它。这和「复制当时的值」不同。循环里创建块并改外层变量时，先想清楚这些块是不是共享同一个变量。

方法的参数个数不对会在调用时失败，定义时往往不报错。写完用一个具体的数调用一次，把结果打出来。不要把方法的返回值和方法有没有 puts 搞混。

```ruby run expect="42" title="默认参数"
def add(a, b = 1)
  a + b
end
puts add(41)
```

```ruby run expect="2" title="yield"
def twice
  yield
  yield
end
n = 0
twice { n += 1 }
puts n
```

```ruby run expect="12" title="map"
puts [1, 2, 3].map { |n| n * 2 }.sum
```

## 常见错误

- 以为方法最后一行会自己打印。终端只看见 puts 或 print。
- 花括号块和 do end 的优先级不同，链式调用时绑错对象。
- 默认参数写成会变的对象并在方法里修改，多次调用会共享那一份。

## 最佳实践

- 要核对的结果用 puts 打出来。
- 一行的块用花括号，多行用 do end。
- 默认值只用数字、字符串这类不会被改内容的对象。

## 小结

方法用参数接收输入，最后一行是返回值，但不会自动打印。块用 yield 或迭代方法执行，并能看见外层变量。
