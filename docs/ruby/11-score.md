小项目把前面的类型、分支、方法和哈希放进一个能读完的脚本。范围限制在一次运行和标准输出。没有网络，也不保留文件。规则用方法表达，测试只看打印出来的文本。

一条命令可以是数组里的字符串，不必真的去读键盘。先把「一行文本如何改变哈希」写成方法，再写循环。这样核心逻辑不调用 gets，你可以直接传入字符串做试验。循环只负责取行和打印。

拆分时限制成两段，名字里的空格才能留下。空行跳过。未知命令打印一句固定的提示，不用异常充当打错字。访问第二段之前看拆分结果的长度。输出用固定格式，例如只打印总分，后面的自动检查靠子串。

同一次运行里可以先加分再查总分。下一次 Run 哈希就没了，这是环境的限制，不是命令写错。

```ruby run expect="2" title="跳过空行"
lines = ["add Ada 1", "", "add Ada 2"]
puts lines.count { |line| !line.strip.empty? }
```

```ruby run expect="3" title="总分"
scores = {}
def add(scores, name, n)
  scores[name] = scores.fetch(name, 0) + n
end
add(scores, "Ada", 1)
add(scores, "Ada", 2)
puts scores["Ada"]
```

```ruby run expect="add" title="拆命令"
text = "add Ada 5"
cmd, rest = text.split(" ", 2)
puts cmd
puts rest
```

## 常见错误

- 在计分方法里直接 gets，测试必须模拟整段输入。
- 用 split 不限制次数，名字被切碎。
- 未知命令抛到顶层，用户打错一个字整次运行失败。

## 最佳实践

- 规则写成接收哈希和字符串的方法。
- 空行先 strip 再决定是否跳过。
- 只打印要核对的数字或固定短词。

## 小结

记分是一次运行内的哈希加一组纯方法。命令拆成两段，空行跳过，输出格式固定。下次运行分数不会还在。
