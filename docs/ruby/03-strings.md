字符串可以用 + 拼接，也可以在双引号里用 #{表达式} 插值。单引号里的 #{ } 不会插值，几乎按字面留下。插值先求值再转成文本。表达式太长时，先放进变量再插进去。

切片和 Python 不同。s[0, 4] 的第二个数是长度，不是结束下标。s[0...4] 用三个点，结束下标不包含。两个点 s[0..3] 则包含结束下标。刚开始只记一种：三个点的区间，右端不包含。中文按字符计，"你好".length 是 2。

gets 读入一行，末尾带着换行。算长度或拼接之前要 chomp，否则换行会躲在字符串里，打印时多出一行。文档运行时样例输入由测试填好。你自己在终端跑，就要亲手输入。

字符串可以改某一个字符，这和 Python 的不可变字符串不同。s[0] = "A" 会改原来的对象。若两个变量指向同一个字符串，一处改了另一处也看见。需要各自一份时用 dup。

```ruby run expect="你好，Ada" title="插值"
name = "Ada"
puts "你好，#{name}"
```

```ruby run expect="Simp" title="前四个"
puts "SimpleCode"[0...4]
```

```ruby run expect="Ada" title="去掉换行"
line = "Ada\n"
puts line.chomp
```

## 常见错误

- 把 s[0, 4] 理解成 Python 的结束下标。第二个数是长度。
- 在单引号里写 #{name}，以为会替换。
- gets 之后不 chomp，换行被算进字符串。

## 最佳实践

- 切片先选一种写法，三个点的右端不包含。
- 双引号才做插值。
- 从输入来的一行先 chomp 再使用。

## 小结

双引号可以插值。三个点的切片不包含右端，[起, 长度] 的第二个数是长度。gets 的换行要用 chomp 去掉。
