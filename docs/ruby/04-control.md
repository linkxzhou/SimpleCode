if、elsif、else 组成一条互斥的链。上面的条件成立，下面就不再看。更具体的条件要写在前面。条件的假只有 nil 和 false。0、空字符串、空数组都是真，所以 if items 不能用来判断「数组是空的」，要看 empty? 或 length。

times 把一段块执行固定次数。each 遍历数组或范围。1..4 包含 4，1...4 不包含 4。范围的点的个数和字符串切片一样，三个点不包含右端。while 在条件为真时重复。写 while 时先说出每一轮哪一个变量在靠近结束。说不出来就先别运行。

case 用 === 匹配。对类来说，case 能认出是不是那个类的实例；对范围来说，能认出数在不在里面。不要把它当成一串 ==。本教程的简单分支仍用 if，case 留给「一个值对多种形状」。

死循环会占住运行时。页面上如果跑了一个不会停的 while，要点停止，否则下一个示例会先问你要不要中断。

```ruby run expect="9" title="奇数和"
total = 0
(1..5).each { |n| total += n if n.odd? }
puts total
```

```ruby run expect="3" title="数到三"
n = 0
while n < 3
  n += 1
end
puts n
```

```ruby run expect="yes" title="空数组是真"
items = []
puts(items ? "yes" : "no")
puts(items.empty? ? "empty" : "full")
```

## 常见错误

- 用 if items 判断数组为空。空数组是真。
- 把 1..4 和 1...4 看成一样。三个点不包含右端。
- while 里忘记改变条件用到的变量。

## 最佳实践

- 知道次数时用 times 或 each，少写 while。
- 范围先决定右端包不包含。
- 空集合用 empty?，不要靠条件真假。

## 小结

分支只把 nil 和 false 当假。each 和 times 负责重复，三个点的范围不包含右端。while 必须有变量靠近结束。
