子查询是包在括号里的 SELECT。放在 FROM 里时它像一张临时表，要起别名。放在 WHERE 里时，若它只返回一个值，可以和列比较。返回多行却用了单个比较，语句会失败。

标量子查询放在表达式里，必须正好一行一列。没有行时它是 NULL。用它做除法或拼接之前先想清楚没有行会怎样。

能用 JOIN 写清楚的配对，不必塞进子查询。子查询适合「先算出一个总数，再和每一行比」。平均分、最大分都属于这种。

```sqlite run expect="42" title="一个数"
SELECT n FROM (SELECT 6 * 7 AS n);
```

```sqlite run expect="5" title="高于平均"
CREATE TABLE t(n INTEGER);
INSERT INTO t VALUES (1), (5), (3);
SELECT n FROM t WHERE n > (SELECT AVG(n) FROM t);
```

```sqlite run expect="42" title="两个标量"
SELECT (SELECT 19) + (SELECT 23);
```

## 常见错误

- FROM 子查询不起别名。
- 子查询返回多行，却用 = 去比。
- 没有行的标量子查询拿去当 0 使用。

## 最佳实践

- 派生表立刻写 AS 别名。
- 和单个值比较之前，确认子查询只有一列并且你接受多行会失败。
- 配对两张表优先用 JOIN。

## 小结

子查询可以当临时表，也可以当一个数。当一个数时只能有一行一列，没有行就是 NULL。

## 练习

从派生表选出 6 的平方。

::: answer 参考答案：平方
```sqlite run expect="36" title="参考答案"
SELECT n * n FROM (SELECT 6 AS n);
```
:::

选出大于最大值减 1 的数。表里是 1、2、4。

::: answer 参考答案：最大
```sqlite run expect="4" title="参考答案"
CREATE TABLE t(n INTEGER);
INSERT INTO t VALUES (1), (2), (4);
SELECT n FROM t WHERE n > (SELECT MAX(n) - 1 FROM t);
```
:::
