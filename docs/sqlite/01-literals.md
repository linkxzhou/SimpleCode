SELECT 后面可以不跟表，直接算出一个值。整数相除仍是整数，20 / 6 得到 3，余数用 %。需要小数时写成 20 / 6.0。文本用单引号。双引号在 SQL 里通常是标识符，拿来包中文句子会去找同名的列，找不到就报错。

|| 把文本接起来。数字和文本不能直接相加，SQLite 会按自己的规则转换，结果往往不是你想的拼接。先用 CAST 或直接写文本。

typeof 打出 SQLite 看到的类型名：integer、real、text、null。NULL 不是 0，也不是空字符串。1 / 0 在 SQLite 里得到 NULL，而不是让整份脚本停下来。

```sqlite run expect="3|2" title="整除"
SELECT 20 / 6, 20 % 6;
```

```sqlite run expect="AB" title="拼接"
SELECT 'A' || 'B';
```

```sqlite run expect="integer|null" title="类型"
SELECT typeof(42), typeof(NULL);
```

## 常见错误

- 用双引号包要打印的句子。
- 以为 20 / 6 会得到小数。
- 用 1 / 0 期待报错。SQLite 给出 NULL。

## 最佳实践

- 要打印的文本只用单引号。
- 要小数时写浮点字面量。
- 看不清类型时 SELECT typeof。

## 小结

SELECT 可以不带表。单引号是文本，整数相除丢掉小数，typeof 用来核对类型。除以零得到 NULL。
