if、elseif、else 组成一条链。条件的假包括 0、空字符串、空数组和 null。更具体的条件写在前面。

foreach 遍历数组。for 适合下标。while 必须有变量靠近结束。死循环会占住运行。

只打印你要核对的结果。循环里的每一次都打印，期望就得包含每一行；能在循环外打印总和，就在外面打印。

```php run expect="9" title="奇数和"
<?php
$total = 0;
foreach ([1, 2, 3, 4, 5] as $n) {
  if ($n % 2 === 1) $total += $n;
}
echo $total, "\n";
```

```php run expect="3" title="数到三"
<?php
$n = 0;
while ($n < 3) $n += 1;
echo $n, "\n";
```

```php run expect="2" title="跳过空"
<?php
$n = 0;
foreach (["Ada", "", "Grace"] as $name) {
  if ($name === "") continue;
  $n += 1;
}
echo $n, "\n";
```

## 常见错误

- while 里不改变条件。
- 用 == 比较类型不同的值，分支意外成立。
- 在循环里 echo 调试文字，把期望淹没。

## 最佳实践

- 知道元素时用 foreach。
- 空字符串用 === ""。
- 循环外打印一个总数。

## 小结

分支把 0 和空字符串当假。foreach 遍历数组。while 必须靠近结束。

把 1 到 4 加起来并打印。

::: answer 参考答案：一到四
```php run expect="10" title="参考答案"
<?php
$total = 0;

```

数出非空字符串的个数。

::: answer 参考答案：非空
```php run expect="1" title="参考答案"
<?php
$n = 0;
foreach (["a", ""] as $s) if ($s !== "") $n++;

```
