这一章只留下不需要扩展的函数。count 数元素，array_sum 加数字，implode 用分隔符把数组收成一行文本。explode 按分隔符拆开，第三个参数可以限制段数，名字里的空格才能留下。

in_array 默认用 ==。需要精确类型时把第三个参数设为 true，也就是严格比较。找不到时它返回 false。

这些函数不访问网络。字符串函数用 strlen、trim、str_replace，前面已经见过，这里用来组合。

```php run expect="a,b" title="收成一行"
<?php
echo implode(",", ["a", "b"]), "\n";
```

```php run expect="add" title="限制拆分"
<?php
$parts = explode(" ", "add Ada Lovelace", 2);
echo $parts[0], "\n";
echo $parts[1], "\n";
```

```php run expect="yes" title="有没有"
<?php
echo in_array(2, [1, 2, 3], true) ? "yes" : "no", "\n";
```

## 常见错误

- explode 不限制段数，名字被切碎。
- in_array 不写严格比较，0 和 "0" 被当成同一个。
- implode 的参数顺序写成先数组后分隔符的旧习惯，在新版本里会出问题。先写分隔符。

## 最佳实践

- 命令拆成两段时给 explode 上限 2。
- 数字查找用严格的 in_array。
- implode 先写分隔符。

## 小结

count、array_sum、implode、explode 和 in_array 覆盖列表上的常见操作。拆分命令时限制段数。
