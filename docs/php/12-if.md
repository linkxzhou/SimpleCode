条件决定哪一段会执行。

### 缺货

库存是 0 时走缺货那一句。

```php run expect="soldout" title="没有库存"
<?php
$stock = 0;
if ($stock === 0) {
    echo "soldout\n";
} else {
    echo "instock\n";
}
```

输出里能看到 `soldout`。

### 有货

库存大于 0 时走另一支。

```php run expect="instock" title="还有库存"
<?php
$stock = 2;
if ($stock === 0) {
    echo "soldout\n";
} else {
    echo "instock\n";
}
```

输出里能看到 `instock`。

### 空字符串

空字符串是假，所以打出 none。

```php run expect="none" title="空为假"
<?php
$name = "";
echo $name ? "has" : "none", "\n";
```

输出里能看到 `none`。
