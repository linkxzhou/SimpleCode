巷口纸品店的柜台后面有一台小票打印机。顾客看见的是纸上的店名和金额，店员阿禾看见的是终端里的同一行字。这门课用 PHP 把这台打印机写成一串可以单独运行的脚本。后面每一章都还印这张小票：品名、数量、以分计的单价，以及最后的合计。换一套商品会把注意力从语言机制上挪走，所以铅笔、橡皮和直尺会反复出现。

点 Run 之后，抽屉用 `php -q` 启动 php-cgi 8.2。`-q` 让这次启动保持安静，正文前面不加 CGI 响应头。没有这面旗，终端开头会先冒出 `X-Powered-By` 和 `Content-type`，期望里的店名仍然能对上，小票的第一行却不再是店名。顾客要看的是货，不是服务器的自我介绍。运行参数里因此带着 `-q`。你在自己的机器上若用另一支 `php` 命令，头可能本来就不会出现；课程按抽屉里真实的启动方式来写。

这个可执行文件报出来的 SAPI 名字是 `cgi-fcgi`。名字来自编译时走的那一支。CGI 原本是网页服务器按请求拉起的接口：服务器把方法、路径和表单放进环境，程序读完再退出。这个抽屉里没有网页服务器，也没有一次 HTTP 请求。进程被当成命令拉起，读完你给出的那一份源码，把结果写到标准输出，然后退出。名字和用法之间有一道缝。看见 cgi，并不等于这次运行携带了一张订单。手册里那些读取请求的例子，默认你站在一次真正的网页调用里。把它们原样抄进小票，读到的不是顾客刚说的话。

超全局变量是为那种请求准备的。`$_GET`、`$_POST`、`$_COOKIE` 在进程里可以被提到，因为 PHP 启动时就会准备这些数组，它们不是未定义的名字。没有浏览器把表单送进来时，`$_POST` 是空的，`$_COOKIE` 也是空的。`$_GET` 里却可能出现脚本路径那样的键，值是空字符串。那是命令行参数被 CGI 的习惯解读之后留下的痕迹，不是顾客点的铅笔。`$_SERVER` 里有参数个数、脚本路径和一块时间戳，没有顾客的会话。用这些数组当小票的数据来源，你会把运行时的边角当成订单。

这门课因此定下一条硬约定：商品和价格写在脚本里。后面几章会把它们放进字符串、数组和对象，仍然不从超全局变量读。选择这条约定，是为了让同一次点击永远打出同一行。超全局变量的内容取决于进程怎样被拉起，环境里多一个字段，键就可能多一个。把店名写进 `echo`，输出只跟源码走。代价是这一章不能演示「从表单收一个品名」。那件事属于有请求体的 PHP。这里的打印机没有请求体。会话函数即使存在，也没有一份会跨请求保留的存储可写。小票不调用 `session_start`。

每一次运行都是新进程。上一块里赋值的名字不会活到下一块。这不是 PHP 把变量设计成会失忆，是抽屉为了让一块能单独点 Run，每次都从那一块的源码重新启动。好处是某一块写错不会污染后面的期望。代价是店名、单价、数量在每一块里都要再写一遍。后面你会觉得重复。重复是示例的边界。你以后在一个文件里写完整的打印机时，店名放在文件靠前的位置写一次就够了。课程把边界说在前面，免得你对着第二块找第一块的变量，找到的是未定义。

源码要被当成 PHP 执行，就得从 `<?php` 开始。这五个字符是模式开关。在它之前，引擎把字节当成要原样送出的模板文本；从它开始，才进入语句。漏掉开头时，你写的 `echo` 会变成终端里的源码文字，金额不会被计算。网页时代留下这个开关，是为了让同一个文件里既能排 HTML 又能写代码。小票打印机用不到模板那一半。可运行的块第一行就是 `<?php`，后面不写闭合的 `?>`。闭合标签右边若跟着换行或空格，那些字节会进入输出。省掉闭合标签，纸上就只剩下你明确送出的内容。

短标签 `<?` 依赖配置项是否打开。这份运行不把课程押在那个开关上。写成完整的 `<?php`，同一份小票换一台机器仍然是代码。`<?=` 是打印表达式的简写，它同样依赖短标签或另一项单独的开关，而且它鼓励你把逻辑嵌进模板。打印机的脚本是命令，不是一张夹着语句的网页。HTML 片段、文档类型声明、手写的 `<br>` 都不要写进示例。php-cgi 在警告时自己会吐出带标签的错误格式，那是失败的样子，不是我们的版式。成功的例子应当让终端里只有店员想印的字。

看结果的通道是 `echo`。计算可以在内存里发生，进程结束之后留下的只有写到标准输出的字节。没有 `echo`，进程可以以退出码 0 结束，终端仍是空白。空白要分成两种时刻来看。第一次打开这种语言时，运行时要加载一小会儿，按钮旁边的进度还没走完，那时的空白是还没开始。加载完成之后的空白，是脚本没有把字送出。期望写成输出里的子串。多出来的说明行通常不让核对失败，少了那个子串才会失败。读示例时仍要看完整的纸面，不要把测试的宽容当成版式已经正确。

这台打印机不连网，不查库，不画图。`curl` 和 `mysqli` 在这份运行时里没有装上，调用它们会失败，失败信息不是一行金额。课程也不调用 `gd` 去画店标。小票要的是文字行。把标记交给图像库，核对就从「这一行是不是五百五十分」变成「这一块像素对不对」，抽屉里的期望对不上。网络和数据库还有一层运行上的理由：一次点击应当自己结束。等一个远程接口，或等一个没有准备好的库，会让 Run 停住。商品和价格写在源码里，进程算完就退出。做不到的调用不要放进可运行的块里试，试的结果是进程失败，不是一条有用的小票。

标准输入在这份 `php -q` 里同样接不上，这件事留到后面的专章展开，这里先把边界说死，免得你从别的教程抄来一行就以为能读键盘。常量 `STDIN` 没有定义，`fgets(STDIN)` 会在运行到那一行时致命退出。`fopen("php://stdin")` 和 `fopen("php://fd/0")` 得到 `false`，不能再交给读取函数。`php://input` 也看不到抽屉送进标准输入的字节。可运行的例子因此都不读键盘。需要一行文本时，把那一行放进字符串。小票的解析可以测，又不会撞上还没接好的管道。专章会把不能运行的写法单独留着对照。

警告和致命错误都会出现在终端里，而且这一支引擎常常把它们包成 HTML。成功示例若触发了未定义的变量，纸上会先脏掉，你要的数字也许还跟在后面。核对通过只说明子串还在。课程让成功路径不制造这种警告：要用的名字先赋值，要读的键先放进数组。语法错误和未捕获的失败会让退出码不是 0，你期望的那一行可能根本没印出来。改期望文字救不了这种失败。先看错误类型的名字，再回到产生它的那一行。

日期若去问系统时钟，同一份脚本明天就会印出另一个日子，期望没法写死。这一章把日期写成字面量 `2026-10-15`。代价是它不会自动变成今天。店里的正式打印机以后可以读时钟，课程的核对不要跟日历赛跑。金额用整数的分，不用带小数的元。三百五十分就是 `350`。为什么避开小数，类型那一章会把浮点除法摊开看。这里先让两件商品的分相加，确认整数运算的结果能送上纸面。

下面三块都是完整脚本。第一块只印店名，确认通道是通的。第二块把铅笔和橡皮的单价相加。第三块把店名和日期分成两行。三块都不读超全局变量，都不访问网络，也都不依赖上一块留下的名字。

```php run expect="巷口纸品" title="店名"
<?php
echo "巷口纸品\n";
```

终端上是巷口纸品四个字，然后换行。引号留在源码里，不会跟着出现在纸上。进程随后退出。这一块没有定义函数，没有读取输入，也没有留下文件。下一块即使还想谈同一家店，也要把要用的数再写一遍。

```php run expect="550" title="两件商品的分"
<?php
echo 350 + 200, "\n";
```

`350 + 200` 先算出 `550`，`echo` 再把这个整数的文字写出去。逗号后面的 `"\n"` 是第二个参数，负责换行。这一章先不展开逗号会不会插入空格。这里两个参数一个是数字、一个是换行，中间没有需要被人看见的间隔。下一章会让品名和金额挨在一起，那时空格就必须自己写进字符串。加法用的是整数。若有人把单价写成带小数点的元，再累加很多行，纸面上会出现一长串不易核对的小数。分把这个问题推迟到格式化的那一刻，推迟是有意的。

```php run expect="2026-10-15" title="店名和日期"
<?php
echo "巷口纸品\n";
echo "2026-10-15\n";
```

两句 `echo` 是两行，因为每一句的字符串里都带了换行。日期是八位数字加两个连字符的文本，不是一次时钟查询。你把第二句删掉，纸上就只剩店名，期望里的日期会对不上。你把两句并成一句、又忘了换行，两段文字会粘在同一行。粘连本身下一章会当作主题来看。这里只要建立起一个习惯：纸上的行，来自你放进字符串的换行，不来自 `echo` 的次数自动决定。两句都写了换行，所以是两行。一句里写两个换行，也可以得到两行。选择哪一种，取决于你要不要在源码里把两段分开，方便下一班店员单独改日期。

把这一章收成打印机的开机检查。文件以 `<?php` 进入代码模式，`-q` 压住响应头，`echo` 把字送出。SAPI 的名字带着 cgi，这次运行却没有网页请求。超全局变量里没有顾客的订单。商品写在脚本里，金额用分，日期写死，键盘留到后面。下一章只看 `echo` 怎样把几个参数铺到同一行上。

## 小结

这门课的 PHP 是一次 `php -q` 命令，不是一次网页请求。SAPI 名字是 `cgi-fcgi`，进程里却没有浏览器送来的表单。超全局变量不能当成小票的数据来源。每份可运行脚本从 `<?php` 开始，不写闭合标签，用 `echo` 把结果送到标准输出，换行写在字符串里。不调用 `curl`、`mysqli` 和 `gd`，也不读标准输入。店名、金额和日期都写在这一份源码里，下一次运行是新进程。
