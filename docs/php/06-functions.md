function 定义函数。参数按位置传入，也可以写默认值。默认值在没传那个参数时使用。return 交回结果，但不会自动打印。main 这一层就是脚本本身，调用后 echo。

函数里给参数赋值，不会改调用者的变量，除非参数是对象并且你改的是对象里面的字段。这一章的函数只接收数字和字符串，用 return 交回新值。

函数名用小写字母和下划线，和示例里的变量一样好读。写完用一个具体的数调用一次。

```php run expect="42" title="默认参数"
<?php
function add($a, $b = 1) { return $a + $b; }
echo add(41), "\n";
```

```php run expect="42" title="两倍"
<?php
function twice($n) { return $n * 2; }
echo twice(21), "\n";
```

```php run expect="9" title="奇数和"
<?php
function odd_sum($nums) {
  $total = 0;
  foreach ($nums as $n) if ($n % 2 === 1) $total += $n;
  return $total;
}
echo odd_sum([1, 2, 3, 4, 5]), "\n";
```

## 常见错误

- 以为 return 的值会自己出现在终端。
- 默认参数写成会变的数组并在函数里修改，多次调用共享那一份。
- 函数里 echo，调用者又 echo 返回值，输出重复。

## 最佳实践

- 计算函数只 return，由调用者 echo。
- 默认值用数字或字符串。
- 用一个具体参数调用并打印。

## 小结

函数用 return 交回结果，echo 留在调用处。默认参数在省略时启用。

## 练习

写函数返回平方，打印 6 的平方。

::: answer 参考答案：平方
```php run expect="36" title="参考答案"
<?php
function sq($n) { return $n * $n; }
echo sq(6), "\n";
```
:::

返回两个数里较大的一个并打印。

::: answer 参考答案：较大
```php run expect="9" title="参考答案"
<?php
function larger($a, $b) { return $a > $b ? $a : $b; }
echo larger(3, 9), "\n";
```
:::
