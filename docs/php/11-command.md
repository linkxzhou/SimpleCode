小项目在一次运行里用关联数组保存分数。没有网络，也不写文件。下次运行分数是空的。规则写成函数：给一个名字加上一个数，或读出总分。

命令文本用 explode 限制成两段。第一段是命令，第二段再拆出名字和数字。空行跳过。未知命令打印「失败」，不用未捕获的异常终止整份脚本。

示例可以直接调用函数，也可以从一行文本出发。输出只打一个数字或固定的词。

```php run expect="3" title="总分"
<?php
function add_score(&$scores, $name, $n) {
  $scores[$name] = ($scores[$name] ?? 0) + $n;
}
$scores = [];
add_score($scores, "Ada", 1);
add_score($scores, "Ada", 2);
echo $scores["Ada"], "\n";
```

```php run expect="2" title="跳过空行"
<?php
$n = 0;
foreach (["add Ada 1", "", "add Ada 2"] as $line) {
  if (trim($line) === "") continue;
  $n++;
}
echo $n, "\n";
```

```php run expect="add" title="拆命令"
<?php
$parts = explode(" ", "add Ada 5", 2);
echo $parts[0], "\n";
```

## 常见错误

- 分数存在静态属性里，测试之间互相看见。这里每次运行虽然是新进程，写法仍然不要共享。
- explode 不限次数，名字被切开。
- 未知命令抛到顶层，整次运行失败。

## 最佳实践

- 分数放在函数收到的数组里。
- 空行先 trim。
- 只打印总分或固定短词。

## 小结

命令小项目是一次运行内的关联数组。命令拆成两段，空行跳过。下次运行分数不会还在。
