字符串用 . 拼接。双引号里的 $变量 会被替换，单引号里不会。要在双引号里写字面 $，用反斜杠。

strlen 数字节。 "Ada" 是 3。"你好" 在 UTF-8 里是 6。这里不依赖 mbstring。讲中文长度时写明是字节，或者改用英文示例。

trim 去掉两端空白，rtrim 去掉右端。fgets 读到的换行要用 rtrim 去掉，否则它会躲在字符串里。str_replace 适合替换一个固定的字符。

```php run expect="你好，Ada" title="插值"
<?php
$name = "Ada";
echo "你好，{$name}\n";
```

```php run expect="2026/10/15" title="替换"
<?php
echo str_replace("-", "/", "2026-10-15"), "\n";
```

```php run expect="3" title="字节"
<?php
echo strlen("Ada"), "\n";
echo strlen("你好"), "\n";
```

## 常见错误

- 在单引号里写 $name，以为会被替换。
- 把 strlen("你好") 当成 2。
- 用 + 拼接字符串，数字会被相加。

## 最佳实践

- 拼接用 . 。
- 双引号才插值，复杂表达式写成 {$name}。
- 中文长度要说明是字节。

## 小结

双引号会替换变量，单引号不会。拼接用点号。strlen 按字节计数。
