小票的一行在送出之前，最好先是一个字符串。有了这个字符串，你才能决定把它印出来、放进数组，或因为数量为零把它丢掉。`echo` 的逗号只在纸上拼接，拼完不留下值。字符串这一章给巷口纸品的每一行一个可以拿在手里的值。拼接用点号。引号决定美元符号开头的变量会不会被替换。长度函数量的是字节，中文品名会因此比你数的字数更长。

点号把两个字符串连成一个新字符串。`"铅笔" . " " . "350"` 的结果是 `铅笔 350`。原来的两段还在，点号不修改它们。整数遇到点号时会被转成文字再连接，所以 `"铅笔 " . 350` 同样得到 `铅笔 350`。这个转换方便，也很安静。你以为自己还在做加法，其实点号从来不是加号。加号在两个字符串之间，在 PHP 8 里会抛出 `TypeError`，脚本停住，纸上没有小票。两个整数之间的加号才是金额相加。品名旁边一旦出现点号，就进入了文字。把单价先加完，再和品名连接，顺序不要反。`(350 + 200) . "分"` 是合计的文字。`350 + 200 . "分"` 会因为点号的优先级，先把 `200` 和 `"分"` 连成 `"200分"`，再拿整数去加这串文字，从而失败。括号把加法圈起来，是优先级的问题，不只是好看。

选择点号而不是逗号，是因为你要的是值。逗号留在 `echo` 的参数列表里，适合最后一步送出。点号适合中间步骤：先做成一行，检查长度，再送出。代价是多一个运算符要记，而且它和加号长得都不像，从别的语言过来的人会伸手去按加号。按加号的结果不是粘连的品名，是一次类型错误。错误比静默的错误金额更吵，吵在这里是有益的：纸品店宁可让这一行失败，也不要让两个价格被意外地接成文字还继续累加。

双引号会替换变量，单引号不会。`$name = "铅笔"` 之后，`"品名{$name}"` 得到 `品名铅笔`，`'品名{$name}'` 得到的是含有花括号和美元符号的原文，变量不会被读。花括号在双引号里把变量名圈起来。圈起来是必须的，不只是风格。PHP 的变量名可以包含汉字。`"$name支"` 会被看成一个名叫 `name支` 的变量，而不是 `$name` 后面跟着「支」。那个更长的名字没有赋值，引擎发出未定义变量的警告，纸上的数量会消失，php-cgi 还会先吐出一段 HTML。写成 `"{$name}支"`，名字在花括号处结束，后面的「支」是普通文字。小票的单位、量词、标点，只要紧跟在变量后面，就放在花括号之外。

单引号适合不需要替换的固定词，例如表头「巷口纸品」。双引号适合要嵌入数量和金额的那一行。两种引号可以嵌套：外面用双引号时，里面的单引号不必转义。选择哪一种当外层，取决于这一行有没有变量。全都用双引号也能工作，固定词里没有美元符号时，双引号不会改写它们。全都用单引号则必须用点号把变量接进去。点号的写法更长，变量和字面量的边界也更醒目。插值更短，边界靠花括号维持。花括号一旦漏掉，边界就吞进变量名。这门课在变量紧挨中文时一律写花括号。单独一个变量、后面就是引号时，`"{$name}"` 和 `"$name"` 结果相同。仍写花括号，是为了让每一行的习惯一致，下一班不用猜这一处能不能省。

反斜杠在双引号里开始转义。`\n` 是换行，`\\` 是一个反斜杠，`\$` 是一个美元符号的字面量。若店名的模板里要印出「单价 $price 尚未填」这种说明，美元符号要转义，否则它会去读变量。单引号里大多数转义没有意义，`\n` 就是反斜杠和一个字母 n，换行不会发生。想在单引号字符串里换行，用点号接一个双引号的 `"\n"`，或者改用双引号。小票的行尾统一用双引号里的 `\n`，避免半套转义。

`strlen` 数字节，不数字。`"Ada"` 是 3。`"铅笔"` 在 UTF-8 里是 6，因为每个汉字通常占三个字节。纸面上你看见两个字，长度函数回答六。这个数字对存储和某些底层接口是诚实的，对「这一行有多长、会不会超出小票纸宽」却不是直接答案。纸宽按字数估计时，6 会让你以为品名很长，从而过早换行。这份运行时带有 `mbstring`，`mb_strlen("铅笔")` 在默认编码下给出 `2`。它可以用来估计字数。依赖它的代价是：另一台没有加载这个扩展的 PHP 会在调用处失败，而且你必须确认字符串真的是 UTF-8。巷口纸品的源码是 UTF-8，示例里的中文因此能被 `mb_strlen` 数对。课程仍把 `strlen` 的结果称为字节。需要字数时才调用 `mb_strlen`，两个数不要混进同一个判断。用字节数去卡「最多四个汉字」会把两个汉字的铅笔判成超长。用字数去分配固定宽度的字节缓冲区会写爆。小票这一课只把两个数印出来对照，不拿它们去切纸。

`trim` 去掉两端的空白，`rtrim` 只去掉右端。空白包括空格、换行和制表符。从一行文本来的品名，末尾常常粘着换行。印之前若不去掉，纸上会多出一行空白，看起来像 `echo` 又写了一次换行。`rtrim("铅笔\n")` 得到 `铅笔`。左端的空格 `rtrim` 会留下。店员手写的品名若前面多了空格，要用 `trim` 才两边都干净。去掉空白之后，原来靠空格对齐的格式会变紧。若空格是有意的栏宽，不要对整行 `trim`，只去掉你知道是行尾的那个换行。专章会把这件事做成「处理一行」的入口。这里先看到函数本身。

`str_replace` 适合替换固定的一段字符。日期 `"2026-10-15"` 要印成斜杠，就把 `"-"` 换成 `"/"`。它替换所有出现，不只第一处。两个连字符都会变成斜杠。若你只想换第一处，这个函数的默认不适合，需要别的办法，这一章的日期恰好希望两处都换。替换不修改原来的字符串，它返回新的。你要把返回值交给 `echo` 或赋回去。写了 `str_replace` 却不接收返回值，旧日期还在，纸上不会变。这和整数运算一样：字符串在 PHP 里是值，函数给你一个新值。

下面的块把这些事分开演示。每一块重新写下品名，不依赖上一块的变量。

```php run expect="铅笔 350" title="点号拼出一行"
<?php
$name = "铅笔";
$cents = 350;
$line = $name . " " . $cents;
echo $line, "\n";
```

`$line` 在打印之前已经是完整的一行，里面没有换行。换行只加在 `echo` 的第二个参数里，这样 `$line` 以后还可以放进数组，不会把行尾的换行带进合计。若把 `\n` 放进 `$line`，数组里的每个元素都拖着一个换行，再拼接时行距会乱。值的内容和纸上的行尾分开，是这一章的一个小结构。

```php run expect="铅笔2支" title="花括号结束变量名"
<?php
$name = "铅笔";
$qty = 2;
echo "{$name}{$qty}支\n";
echo '品名{$name}', "\n";
```

第一行是 `铅笔2支`。两个变量都用花括号圈住，后面的「支」不会被吃进名字。第二行因为单引号，纸上仍是 `品名{$name}` 这几个字符。期望锁定的是第一行。第二行用来提醒你：看见花括号，不等于一定会替换，外层引号说了算。若你希望两行都替换，第二行也要改成双引号。单引号那一行故意留在示例里，是为了让失败的插值有一个可见的样子。它没有警告，因为单引号根本不去读变量。没有警告的原文，有时比警告更难发现，顾客会看见花括号。核对时不要只看第一行。

```php run expect="6" title="铅笔的字节和字数"
<?php
echo strlen("铅笔"), "\n";
echo mb_strlen("铅笔"), "\n";
echo strlen("Ada"), "\n";
```

三行是 `6`、`2`、`3`。`Ada` 的字节和字数相同，所以英文例子会把 `strlen` 伪装成字数。中文把伪装拆开。`mb_strlen` 在这台机器上可用，不表示每台 PHP 都加载了它。要随身带着的长度是 `strlen` 的字节。要给顾客看的「两个字」来自 `mb_strlen`，或者来自你自己对固定品名的了解。不要写一个判断说「长度小于 4 就印」，除非你说清这个 4 是字节还是字。

```php run expect="2026/10/15" title="替换日期里的连字符"
<?php
echo str_replace("-", "/", "2026-10-15"), "\n";
echo trim("  铅笔  "), "\n";
```

第一行是斜杠日期，第二行是去掉两端空格的铅笔。`trim` 的参数里没有换行，两端是空格。若字符串是 `"  铅笔  \n"`，`trim` 会把换行一起去掉，结果仍是 `铅笔`。`rtrim` 则会留下左端的空格。下一班若发现品名前面有空白，先看用的是哪一个函数，再看空白是不是栏宽的一部分。

字符串可以用下标取出字节，`$name[0]` 是第一个字节，不一定是第一个汉字。对 `"铅笔"` 取下标 0，得到的是一个不完整的字节，印出来不是「铅」。课程不靠下标去切中文品名。要截断一行时，先想编码。这一章不截断。品名整段拼接，整段打印。切字节会把纸上的字打成乱码，乱码里可能仍含有你期望的数字，核对会放过乱码。保持整段，是小票可读的底线。

把一行的构造顺序固定下来，后面几章就省事。先取品名字符串，再取已经算好的整数金额，用点号和空格拼成 `$line`，最后 `echo` 并换行。插值适合句子，点号适合你要在中间停下检查的值。`strlen` 回答字节，`mb_strlen` 在这份运行时回答字数。空格和换行都是字符，它们占用 `strlen` 的计数。一个空格是 1 个字节。你在长度里看见比品名更大的数，先别怀疑汉字算错，先数你自己拼进去的空格。

一行的最大宽度还可以从字节再想一层。热敏纸的宽度通常按字符格子估，汉字约占两个格子，ASCII 约占一个。`strlen` 给出的 6 既不是格子数 4，也不是字数 2。格子数要自己按编码累加，这一课不写那个循环。知道三个数字各不相同，就不会用字节数去决定「这一行还够不够印单价」。单价被挤到下一行时，顾客会把它看成另一件货。宁可让品名短一点，也不要靠截断字节来硬塞。截断六个字节可能正好落在汉字边界上，截断五个字节就会劈开一个字。边界不在 `strlen` 的返回值里。它只告诉你一共有多少字节，不告诉你哪里是字的边缘。

引号的选择还影响以后把小票嵌进别的文本。若这一行要放进一段仍使用双引号的说明，里面的双引号就要转义成 `\"`。转义多了，行会变得难读。那时把这一行先放进变量，外层用点号接上，内部的引号就不必再逃。变量是边界。点号是边界。花括号也是边界。三种边界都在，是因为 PHP 的字符串同时承担模板和数据。小票只借用模板的插值，不把整个文件写成网页模板。借用的部分用花括号写完整，省下的部分用点号写完整。

## 小结

点号连接字符串并返回新值，整数会先变成文字。加号不是拼接，两个字符串相加会得到类型错误。双引号替换变量，变量名用花括号收住，免得汉字被吃进名字。单引号保持原文。`strlen` 数字节，`"铅笔"` 是 6，`mb_strlen` 在这份运行时给出字数 2。`trim` 和 `str_replace` 都返回新字符串，不改原来的值。
