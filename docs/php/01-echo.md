echo 把参数送到标准输出，参数之间不加空格。echo "A", "B" 得到 AB。换行是字符串里的 \n，不是 echo 自动添加的。

注释用 // 直到行尾，或用 /* */。注释不会出现在输出里。变量以 $ 开头。echo 一个变量时，它会被转成文本。

这一章的脚本都很短。每份仍然以 <?php 开头，并且最后有换行，方便和期望对照。改示例时只改引号里的字，再点工具栏的 Run。代码块上的 Run 会把你的修改盖掉。预测时把换行也算进去。若终端里多了一个空格，先看 echo 的参数是不是被你用逗号隔开后又自己加了空格。逗号不会插入空格。

```php run expect="Ada" title="两行"
<?php
echo "Ada\n";
echo "Lovelace\n";
```

```php run expect="AB" title="连在一起"
<?php
echo "A", "B", "\n";
```

```php run expect="可见" title="注释"
<?php
echo "可见\n";
// 这一行不会出现
echo 2026, "\n";
```

### 读「两行」

先做这一例。把代码收成一行来记：`<?php echo "Ada\n"; echo "Lovelace\n";`。先盖住终端，写下你预测的输出，里面要能找到「Ada」。这是子串：前面可以有别的字，后面通常有换行。

然后点这个代码块上的 Run，不要点工具栏。代码块会备份草稿、写入示例再执行。找不到这段文字时，先看退出码。不是 0 就读错误类型，不要改期望。是 0 但内容不对，就只改产生该值的那一处。改完用工具栏的 Run，因为再点代码块会把修改盖掉。预测对了之后点撤销。

### 只改一处：两行

这一例要避开的失误是：以为 echo 的多个参数会用空格隔开。。对应的做法是：一次需要的换行写进字符串。。

把代码收成一行来核对：`<?php echo "Ada\n"; echo "Lovelace\n";`。盖住终端，先写下预测，里面要能找到「Ada」。然后点这个代码块上的 Run。结果不同时，只改产生该值的那一行，再用工具栏的 Run 看新结果。不要把两处不相关的改动叠在一起。确认之后点撤销，下一例才会从文档里的代码开始。

若出现报错，先看错误类型的名字，再回到本章的常见错误。期望是子串，多出来的说明行不算失败，缺了「Ada」才算失败。

## 读完再动手

本章要留下的是 「用 echo 打出文本和数字」、「写出注释」、「知道 echo 的多个参数连在一起」。合上抽屉之前，用自己的话说出每一项目标对应哪一个示例的标题。对不上标题，就还没有把目标和代码连起来，先别展开练习答案。

练习的答案默认折着。先在编辑器里自己写，再展开对照。对照时只看输出是否包含期望的那几个字。两道都过了再进入下一章。下一次运行是新进程，这次的变量不会留下。

把这一章当成一次可以反复撤销的实验。点代码块上的 Run 会用示例覆盖编辑器，原来的草稿先备份。你改过的内容如果还想留着，先复制到别处，再点下一例。工具栏的 Run 不会从文档重写编辑器，所以它用来看你改过的版本。两种按钮各做各的事。下载进度写在按钮旁边，第一次打开这种语言时要等它结束，再判断示例是不是写错了。

记录你预测错的那一次。写下你以为会打印的文字，以及实际多出来或少掉的部分。进入下一章之前，要能用一句话说清差在哪。通过只说明期望的那几个字还在，不说明你已经看懂产生它的那一行。章节标题下的目标就是这份验收清单。差两个字也不要靠改期望凑过去。

## 常见错误

- 以为 echo 的多个参数会用空格隔开。
- 把换行寄托在 echo 自己身上。
- 注释写成了和代码相反的说明。

## 最佳实践

- 一次需要的换行写进字符串。
- 多个参数只在你确实想紧挨着时使用。
- 数字和文本都可以 echo。

## 小结

echo 原样拼接参数。换行要写 \n。注释不会进入输出。
