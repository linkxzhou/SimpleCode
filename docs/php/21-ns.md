`namespace` 要写在文件靠前的位置。调用时加上前缀。

### 限定名

`\Shop\price` 指向这个名字空间里的函数。

```php run expect="18" title="限定名"
<?php
namespace Shop;
function price() {
    return 18;
}
echo \Shop\price(), "\n";
```

输出里能看到 `18`。

### 另一个名字空间

两个函数可以同名，前缀把它们分开。

```php run expect="7" title="墨水的价格"
<?php
namespace Ink;
function price() {
    return 7;
}
echo \Ink\price(), "\n";
```

输出里能看到 `7`。

### 当前空间

文件已经在 `Shop` 里时，可以直接写函数名。

```php run expect="18" title="当前空间"
<?php
namespace Shop;
function rate() {
    return 2;
}
echo rate() * 9, "\n";
```

输出里能看到 `18`。
