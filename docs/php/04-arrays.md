PHP 的数组是有序映射。列表写成 [1, 2, 3]，下标从 0 开始。键值写成 ["n" => 2]。取缺失的键会警告，教学例子用 ?? 给默认值，避免警告打断输出。

foreach 遍历值，或同时遍历键和值。count 数元素。array_sum 把数字加起来。空数组在条件里为假，所以 if ($items) 不能区分「没这个变量」和「空列表」以外的更多情况；空列表会走进假分支。要明确数个数时用 count。

不要把数组 echo 出去。echo 数组会得到 Array 这个词，不是内容。打印某一个元素，或先 implode。

```php run expect="10" title="求和"
<?php
echo array_sum([1, 2, 3, 4]), "\n";
```

```php run expect="0" title="默认"
<?php
$box = ["a" => 1];
echo $box["b"] ?? 0, "\n";
```

```php run expect="no" title="空数组"
<?php
$items = [];
echo $items ? "yes" : "no", "\n";
```

## 常见错误

- 读取不存在的键，终端里先出现警告。
- echo 整个数组，只看到 Array。
- 用 if ($items) 表示「有元素」。空数组是假，但你可能想要 count。

## 最佳实践

- 缺失键用 ??。
- 只 echo 元素、个数或 implode 的结果。
- 列表和关联数组不要在同一次下标里混用得自己也忘了。

## 小结

数组是有序映射。?? 给缺失键默认值。空数组为假。不要 echo 整个数组。
