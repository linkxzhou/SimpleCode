变量第一次赋值就诞生。20 / 6 在 PHP 里得到浮点数。要整数商用 intdiv(20, 6)，结果是 3。余数用 %。

条件里的假包括 false、0、0.0、空字符串、空数组和 null。这和 Ruby 不同，和 C 更接近。非空字符串 "0" 也是假，这是 PHP 特有的坑。本教程判断「有没有文本」时用 === "" 或 strlen，不把字符串丢进 if。

== 会转换类型，0 == "0" 为真。=== 同时比较类型。教学例子需要精确时用 ===。

```php run expect="3" title="整除"
<?php
echo intdiv(20, 6), "\n";
echo 20 % 6, "\n";
```

```php run expect="no" title="零是假"
<?php
$n = 0;
echo $n ? "yes" : "no", "\n";
```

```php run expect="no" title="严格相等"
<?php
echo (0 === "0") ? "yes" : "no", "\n";
```

## 常见错误

- 以为 20 / 6 的结果可以直接当整数个数。
- 用 if ($name) 判断名字，"0" 会被当成没有。
- 用 == 比较数字和字符串，类型不同也通过。

## 最佳实践

- 要整数商时用 intdiv。
- 精确比较用 ===。
- 空字符串用 === "" 判断。

## 小结

intdiv 才是整数除法。0、空字符串和 "0" 在条件里为假。=== 不转换类型。
