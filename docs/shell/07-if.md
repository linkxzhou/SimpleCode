`if` 在条件的退出码为 0 时执行 `then`。`fi` 把结构收住。

### 成立

物品是 pen 时走第一支。

```sh run expect="pen" title="第一支"
item=pen
if [ "$item" = pen ]; then
  printf '%s\n' pen
else
  printf '%s\n' other
fi
```

输出里能看到 `pen`。

### elif

cup 落到中间那一支。

```sh run expect="cup" title="中间一支"
item=cup
if [ "$item" = pen ]; then
  printf '%s\n' pen
elif [ "$item" = cup ]; then
  printf '%s\n' cup
else
  printf '%s\n' other
fi
```

输出里能看到 `cup`。

### else

ticket 对不上前两支。

```sh run expect="ticket" title="最后一支"
item=ticket
if [ "$item" = pen ]; then
  printf '%s\n' pen
elif [ "$item" = cup ]; then
  printf '%s\n' cup
else
  printf '%s\n' ticket
fi
```

输出里能看到 `ticket`。
