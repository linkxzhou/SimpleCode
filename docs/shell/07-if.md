`if` 在条件的退出码为 0 时执行 `then`。`fi` 把结构收住。

### 成立

物品是笔时走第一支。

```sh run expect="笔" title="第一支"
item=笔
if [ "$item" = 笔 ]; then
  printf '%s\n' 笔
else
  printf '%s\n' 其他
fi
```

输出里能看到 `笔`。

### elif

水杯落到中间那一支。

```sh run expect="水杯" title="中间一支"
item=水杯
if [ "$item" = 笔 ]; then
  printf '%s\n' 笔
elif [ "$item" = 水杯 ]; then
  printf '%s\n' 水杯
else
  printf '%s\n' 其他
fi
```

输出里能看到 `水杯`。

### else

车票对不上前两支。

```sh run expect="车票" title="最后一支"
item=车票
if [ "$item" = 笔 ]; then
  printf '%s\n' 笔
elif [ "$item" = 水杯 ]; then
  printf '%s\n' 水杯
else
  printf '%s\n' 车票
fi
```

输出里能看到 `车票`。
