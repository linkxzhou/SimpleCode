没有函数，也没有 `source` 能装进另一份定义。要重复的命令就再写一遍，或者放进 `for`。

### 函数不运行

花括号定义的函数这里无法声明。

```sh norun title="没有函数"
hello() {
  echo 你好
}
hello
```

### 直接写

需要打出两次时，把 `printf` 写两遍。

```sh run expect="你好" title="第一行"
printf '%s\n' 你好
printf '%s\n' 你好
```

输出里能看到 `你好`。

### 用变量传递

先赋值，再让下一条命令去读。这就是这里的「参数」。

```sh run expect="笔" title="传给 printf"
item=笔
printf '%s\n' "$item"
```

输出里能看到 `笔`。
