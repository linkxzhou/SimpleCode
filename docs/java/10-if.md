条件两边是布尔值。if 只在条件为真时进入花括号，否则走 else。

### if 和 else 二选一

票价大于 10 时走贵的那一支，否则走便宜的那一支。两边只会打印一句。

```java run expect="low" title="二分支"
public class Main {
    public static void main(String[] args) {
        // 小于等于 10 走 else
        int fare = 8;
        if (fare > 10) {
            System.out.println("high");
        } else {
            System.out.println("low");
        }
    }
}
```

8 走 else。

### else if 再分一档

先看是否超过 20，再看是否超过 10。两个条件都失败才进最后的 else。

```java run expect="mid" title="三档"
public class Main {
    public static void main(String[] args) {
        // 中间一档
        int fare = 15;
        if (fare > 20) {
            System.out.println("top");
        } else if (fare > 10) {
            System.out.println("mid");
        } else {
            System.out.println("low");
        }
    }
}
```

15 落在中间一档。

### 条件可以组合

&& 要求座位还有空，并且票价不超过上限。两边都真才打印 open。

```java run expect="open" title="组合条件"
public class Main {
    public static void main(String[] args) {
        // 座位和票价同时满足
        int seats = 2;
        int fare = 9;
        if (seats > 0 && fare <= 10) {
            System.out.println("open");
        } else {
            System.out.println("shut");
        }
    }
}
```

这里两个条件都成立。
