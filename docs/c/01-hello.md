程序从 main 进入。写成 int main(void)，表示不读取参数，结束时返回一个 int。return 0 表示这次按我们的约定成功。

printf 的第一个参数是格式串。%d 配 int，%s 配以空字符结尾的字符串。格式串里的 \n 是换行。普通字符会原样打出。参数个数必须和格式说明一样多，否则编译失败。

注释用 /* */。注释不会出现在输出里。注释写错不会让编译失败，却会让你按错误的说明去改对的代码。

```c run expect="Ada" title="两行"
#include <stdio.h>
int main(void) {
  printf("%s\n", "Ada");
  printf("%s\n", "Lovelace");
  return 0;
}
```

```c run expect="AB" title="同一行"
#include <stdio.h>
int main(void) {
  printf("%s", "A");
  printf("%s\n", "B");
  return 0;
}
```

```c run expect="可见" title="注释"
#include <stdio.h>
int main(void) {
  printf("%s\n", "可见");
  /* 这一行不会出现 */
  printf("%d\n", 2026);
  return 0;
}
```

## 读完再动手

本章要留下的是 「用 printf 打出文本和数字」、「写出注释」、「让 main 返回 0」。合上抽屉之前，用自己的话说出每一项目标对应哪一个示例的标题。对不上标题，就还没有把目标和代码连起来，先别展开练习答案。

练习的答案默认折着。先在编辑器里自己写，再展开对照。对照时只看输出是否包含期望的那几个字。两道都过了再进入下一章。下一次运行是新进程，这次的变量不会留下。

把这一章当成一次可以反复撤销的实验。点代码块上的 Run 会用示例覆盖编辑器，原来的草稿先备份。你改过的内容如果还想留着，先复制到别处，再点下一例。工具栏的 Run 不会从文档重写编辑器，所以它用来看你改过的版本。两种按钮各做各的事。下载进度写在按钮旁边，第一次打开这种语言时要等它结束，再判断示例是不是写错了。

记录你预测错的那一次。写下你以为会打印的文字，以及实际多出来或少掉的部分。进入下一章之前，要能用一句话说清差在哪。通过只说明期望的那几个字还在，不说明你已经看懂产生它的那一行。章节标题下的目标就是这份验收清单。差两个字也不要靠改期望凑过去。

## 常见错误

- 把 %d 配给字符串，或把 %s 配给 int。
- 格式串里少写一个说明，多传了一个参数。
- 注释里写了和代码相反的话。

## 最佳实践

- 一次 printf 对应一行需要核对的输出。
- 格式串保持字面量。
- main 的每条路径都 return。

## 小结

main 返回 int。printf 用格式串决定怎么打印。\n 负责换行，注释不会进入输出。
