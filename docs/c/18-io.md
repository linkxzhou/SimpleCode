`scanf` 需要调用方提供标准输入。返回值是成功转换的项数。

### 格式

`%d` 打印整数，`%s` 打印字符串。

```c run expect="茶 18" title="两项"
#include <stdio.h>
int main(void) {
  printf("%s %d\n", "茶", 18);
  return 0;
}
```

输出里能看到 `茶 18`。

### 读整数

标准输入里是一行数字。读成功才打印。

```c run stdin="12\n" expect="12" title="读入"
#include <stdio.h>
int main(void) {
  int n = 0;
  if (scanf("%d", &n) == 1) printf("%d\n", n);
  return 0;
}
```

输出里能看到 `12`。

### 失败时不使用结果

输入不是数字时，`scanf` 返回 0，程序改打印失败。

```c run stdin="no\n" expect="失败" title="不是数字"
#include <stdio.h>
int main(void) {
  int n = 0;
  if (scanf("%d", &n) == 1) printf("%d\n", n);
  else printf("失败\n");
  return 0;
}
```

输出里能看到 `失败`。
