整数相除仍是整数，小数部分直接丢掉。20 / 6 得到 3，余数用 %，20 % 6 得到 2。需要小数时用 double，并在 printf 里用 %f 或先把结果收成你能核对的整数。

变量要先声明再使用。声明了却从不用，编译会失败。所以示例里每个变量都参与 printf 或运算。int 够放下本教程的小整数。不要为了「以后可能用」先声明一串。

字符串字面量的类型是以空字符结尾的字符序列。strlen 数的是字节，不是你看到的字数。英文 "Ada" 是 3。中文「你好」在 UTF-8 里是 6 个字节。打印长度时用 %d，并把 strlen 的结果转成 int，避免格式警告。

```c run expect="3" title="整除"
#include <stdio.h>
int main(void) {
  printf("%d\n", 20 / 6);
  printf("%d\n", 20 % 6);
  return 0;
}
```

```c run expect="3" title="长度"
#include <stdio.h>
#include <string.h>
int main(void) {
  printf("%d\n", (int)strlen("Ada"));
  printf("%d\n", (int)strlen("你好"));
  return 0;
}
```

```c run expect="42" title="相加"
#include <stdio.h>
int main(void) {
  int a = 20;
  int b = 22;
  printf("%d\n", a + b);
  return 0;
}
```

## 常见错误

- 以为 20 / 6 会得到带小数的结果。
- 把 strlen("你好") 理解成 2。它数的是字节。
- 声明了变量却没用，被警告拦住。

## 最佳实践

- 要整数商时确认两边都是整数。
- 讲中文长度时写明是字节。
- 每个局部变量都参与结果。

## 小结

整数相除丢掉小数，余数用 %。strlen 按字节计数。没用到的变量不能留在 -Werror 的程序里。
