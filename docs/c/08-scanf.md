scanf 从标准输入按格式读。%d 读一个 int，参数必须是 int *，所以写 &n。返回值是成功转换的项数。读一个数时期望返回 1。返回 0 或 EOF 时，n 里的值不能拿来当用户输入。

示例在文档里带上标准输入，测试会把这几个字符送进去并结束输入。你自己在终端跑，就要亲手键入。格式串里不要随便加空格和多余的文字，否则输入必须逐字匹配。

读完再计算。不要在 scanf 没成功时 printf 一个碰巧的旧值。先把 n 设成 0，失败时打印固定的词「失败」，成功时打印算好的数。

```c run stdin="41\n" expect="42" title="加一"
#include <stdio.h>
int main(void) {
  int n = 0;
  if (scanf("%d", &n) != 1) {
    printf("%s\n", "失败");
    return 0;
  }
  printf("%d\n", n + 1);
  return 0;
}
```

```c run stdin="20 22\n" expect="42" title="两个数"
#include <stdio.h>
int main(void) {
  int a = 0;
  int b = 0;
  if (scanf("%d %d", &a, &b) != 2) {
    printf("%s\n", "失败");
    return 0;
  }
  printf("%d\n", a + b);
  return 0;
}
```

```c run stdin="no\n" expect="失败" title="不是数字"
#include <stdio.h>
int main(void) {
  int n = 0;
  if (scanf("%d", &n) != 1) printf("%s\n", "失败");
  else printf("%d\n", n);
  return 0;
}
```

## 常见错误

- scanf 的参数写成 n 而不是 &n。
- 不看返回值，输入不是数字时仍打印 n。
- 格式串里多写了必须匹配的文字。

## 最佳实践

- 每个要读的数都检查转换个数。
- 失败时打印固定的短词。
- 文档示例写上 stdin，让结果可重复。

## 小结

scanf 需要地址，并用返回值说明读入了几项。没读到就不要使用那个变量。

## 练习

读入一个整数，打印它的两倍。输入是 21。

::: answer 参考答案：两倍
```c run stdin="21\n" expect="42" title="参考答案"
#include <stdio.h>
int main(void) {
  int n = 0;
  if (scanf("%d", &n) != 1) return 1;
  printf("%d\n", n * 2);
  return 0;
}
```
:::

读入失败时打印失败。输入是 x。

#include <stdio.h>
