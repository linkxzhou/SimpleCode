数组的下标从 0 开始。元素个数不会存在数组里，循环的上限要你自己写对。多走一格是越界，本教程的循环上限写成初始化时的个数。

字符数组如果要当字符串用，最后要有 '\0'。字面量 "Ada" 已经带上。自己逐个填字符时，别忘了结尾。strlen 停在第一个空字符，不会数出你分配的容量。

数组作为参数时，函数只拿到指向第一个元素的指针，仍然不知道长度。把长度用另一个 int 传进去。

```c run expect="10" title="求和"
#include <stdio.h>
int main(void) {
  int a[] = {1, 2, 3, 4};
  int total = 0;
  for (int i = 0; i < 4; i++) total += a[i];
  printf("%d\n", total);
  return 0;
}
```

```c run expect="Simp" title="前四个"
#include <stdio.h>
int main(void) {
  const char *s = "SimpleCode";
  printf("%c%c%c%c\n", s[0], s[1], s[2], s[3]);
  return 0;
}
```

```c run expect="6" title="带长度"
#include <stdio.h>
int sum(const int *a, int n) {
  int total = 0;
  for (int i = 0; i < n; i++) total += a[i];
  return total;
}
int main(void) {
  int a[] = {1, 2, 3};
  printf("%d\n", sum(a, 3));
  return 0;
}
```

## 常见错误

- 用一个不存在的 length 字段当上限。
- 字符数组忘了 '\0'，strlen 一直读下去。
- 函数参数写成数组，却以为能在函数里得到元素个数。

## 最佳实践

- 循环上限写成你初始化的个数。
- 把数组交给函数时同时交长度。
- 字符串字面量优先，少手写结尾。

## 小结

数组下标从 0 开始，长度要另记。字符串停在空字符。函数参数里的数组只是指针加你传入的长度。

## 练习

把 {3, 1, 2} 里的最小值打印出来。

::: answer 参考答案：三个
```c run expect="1" title="参考答案"
#include <stdio.h>
int main(void) {
  int a[] = {3, 1, 2};
  int m = a[0];
  for (int i = 1; i < 3; i++) if (a[i] < m) m = a[i];
  printf("%d\n", m);
  return 0;
}
```
:::

打印 Simple 的字节数。

::: answer 参考答案：字节
```c run expect="6" title="参考答案"
#include <stdio.h>
#include <string.h>
int main(void) {
  printf("%d\n", (int)strlen("Simple"));
  return 0;
}
```
:::
