指针保存地址。& 取一个对象的地址，* 顺着地址读或写那个对象。类型写成 int *p，表示 p 指向 int。

函数要修改调用者的 int，就接收 int *。调用时传入 &变量。函数里写 *p = ...。这是输出参数。返回值仍然可以同时用来表示成功或失败，这一章只演示修改。

没有指向有效对象的指针不能解引用。示例里的指针都来自 &局部变量，或者指向数组元素。不写空指针解引用。

```c run expect="42" title="读"
#include <stdio.h>
int main(void) {
  int n = 42;
  int *p = &n;
  printf("%d\n", *p);
  return 0;
}
```

```c run expect="42" title="改"
#include <stdio.h>
void inc(int *p) { *p += 1; }
int main(void) {
  int n = 41;
  inc(&n);
  printf("%d\n", n);
  return 0;
}
```

```c run expect="2" title="交换"
#include <stdio.h>
void swap(int *a, int *b) {
  int t = *a;
  *a = *b;
  *b = t;
}
int main(void) {
  int x = 1;
  int y = 2;
  swap(&x, &y);
  printf("%d\n", x);
  return 0;
}
```

## 常见错误

- 调用 inc(n) 却忘了 &，类型对不上。
- 解引用一个没有赋值的指针。
- 把 * 只理解成乘法，写 *p += 1 时看错。

## 最佳实践

- 指针在解引用之前指向一个还活着的对象。
- 要改调用者的变量就传地址。
- 局部变量的地址不要从函数里返回。本教程不返回指向局部变量的指针。

## 小结

& 取地址，* 访问那个对象。通过指针，函数可以改调用者的变量。指针必须指向还有效的对象。

## 练习

通过指针把 41 加一后打印。

::: answer 参考答案：加一
```c run expect="42" title="参考答案"

int main(void) {

}
```

::: answer 参考答案：写入
```c run expect="7" title="参考答案"

  int n = 0;
  set7(&n);
  printf("%d\n", n);
  return 0;
}
```
