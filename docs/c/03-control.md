if 的条件为 0 时走 else，其他值都走 if。这和 Ruby 相反：在 C 里 0 是假。比较用 ==，赋值用 =。写成 if (n = 0) 是赋值，值是 0，分支总走 else，而且常常不是你想做的事。

for 适合次数清楚的循环。先写出每一轮哪一个变量在靠近结束。while 也一样。说不出靠近结束的量，就先别运行。死循环会占住运行，页面上需要停止之后才能跑下一例。

循环里累加时，把总和初始化为 0。忘了初始化就去读，是未定义行为，本教程不写。

```c run expect="9" title="奇数和"
#include <stdio.h>
int main(void) {
  int total = 0;
  for (int n = 1; n <= 5; n++) {
    if (n % 2 == 1) total += n;
  }
  printf("%d\n", total);
  return 0;
}
```

```c run expect="3" title="数到三"
#include <stdio.h>
int main(void) {
  int n = 0;
  while (n < 3) n += 1;
  printf("%d\n", n);
  return 0;
}
```

```c run expect="no" title="零是假"
#include <stdio.h>
int main(void) {
  int n = 0;
  if (n) printf("%s\n", "yes");
  else printf("%s\n", "no");
  return 0;
}
```

## 常见错误

- 把 == 写成 =。
- 循环里不改变条件用到的变量。
- 总和没有先写成 0 就累加。

## 最佳实践

- 知道次数时用 for。
- 条件里需要比较时写 ==。
- 循环变量的结束条件写在循环头上。

## 小结

0 是假，其余数字是真。for 和 while 都必须有变量靠近结束。比较用 ==。

## 练习

把 1 到 4 加起来并打印。包含 4。

::: answer 参考答案：一到四
```c run expect="10" title="参考答案"
#include <stdio.h>
int main(void) {
  int total = 0;
  for (int n = 1; n <= 4; n++) total += n;
  printf("%d\n", total);
  return 0;
}
```
:::

从 0 开始加三次，打印结果。

::: answer 参考答案：三次
```c run expect="3" title="参考答案"
#include <stdio.h>
int main(void) {
  int n = 0;
  for (int i = 0; i < 3; i++) n += 1;
  printf("%d\n", n);
  return 0;
}
```
