未定义行为是标准不规定结果的写法。它可能打出某个数，也可能让这次运行中断，所以不能拿来当示例的期望输出。能写清楚的检查就写在运行的程序里；溢出和释放之后再使用只保留形状。

### 空指针不读

`p` 是空的。先判断，再决定要不要解引用。这一次走的是跳过的分支，打印 `skip`。

```c run expect="skip" title="先判断空"
#include <stdio.h>
int main(void) {
  int *p = NULL;
  if (!p) {
    printf("skip\n");
    return 0;
  }
  printf("%d\n", *p);
  return 0;
}
```

空指针被跳过，输出 `skip`。

### 下标先看范围

数组只有三格，合法下标是 0、1、2。`i` 是 1，落在范围内，读到 5。若 `i` 是 3，这个分支不会去读。

```c run expect="5" title="下标合法"
#include <stdio.h>
int main(void) {
  int a[3] = {4, 5, 6};
  int i = 1;
  if (i < 0 || i >= 3) {
    printf("out\n");
    return 0;
  }
  printf("%d\n", a[i]);
  return 0;
}
```

下标 1 对应 5。

### 溢出只阅读

`INT_MAX + 1` 对有符号 `int` 是未定义行为。下面的程序不运行。不要用某一次碰巧打印出来的数当作规定结果。

```c norun title="有符号溢出"
#include <limits.h>
#include <stdio.h>
int main(void) {
  int x = INT_MAX;
  printf("%d\n", x + 1);
  return 0;
}
```

这份清单只说明形状，按钮不会编译它。

### 练习：先抄再释放

堆上的 4 先抄进 `saved`，再 `free`。之后只打印副本，不再碰原来的指针。释放之后使用也是未定义行为，所以这里不写那一行。

```c run expect="4" title="释放前抄出"
#include <stdio.h>
#include <stdlib.h>
int main(void) {
  int *p = malloc(sizeof *p);
  int saved;
  if (!p) return 1;
  *p = 4;
  saved = *p;
  free(p);
  printf("%d\n", saved);
  return 0;
}
```

副本是 4。
