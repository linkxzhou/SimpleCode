Standard input for a sample is written on the fence, and it must end with a newline. `cout` writes to standard output. `getline` and `cin` read from that prepared input.

### Output

`cout` sends the string to standard output. The characters are `茶`, followed by a newline.

```cpp run expect="茶" title="Print tea"
#include <iostream>
int main() {
  std::cout << "茶\n";
  return 0;
}
```

Standard output shows `茶`.

### Read one line

`getline` stops at the newline and does not keep that newline in the string. The input line is `Ada`, and the greeting prints `你好，Ada`.

```cpp run stdin="Ada\n" expect="你好，Ada" title="One name"
#include <iostream>
#include <string>
int main() {
  std::string name;
  std::getline(std::cin, name);
  std::cout << "你好，" << name << "\n";
  return 0;
}
```

Standard output shows `你好，Ada`.

### Read one integer

`>>` skips whitespace and then reads one integer. The supplied input is 12, and the program prints twice that value.

```cpp run stdin="12\n" expect="24" title="Times two"
#include <iostream>
int main() {
  int n = 0;
  std::cin >> n;
  std::cout << (n * 2) << "\n";
  return 0;
}
```

Standard output shows `24`.
