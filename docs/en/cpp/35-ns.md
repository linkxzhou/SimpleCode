A namespace keeps identical names in different regions from colliding. You either qualify the name, import it, or give the namespace a shorter alias.

### A qualified name

`shop::price` says which region the variable belongs to. Its value is 18.

```cpp run expect="18" title="Qualified name"
#include <iostream>
namespace shop {
int price = 18;
}
int main() {
  std::cout << shop::price << "\n";
  return 0;
}
```

The qualified value is `18`.

### using

After `using shop::rate`, the name `rate` can be written without a qualifier. Nine times that rate is 18.

```cpp run expect="18" title="Import one name"
#include <iostream>
namespace shop {
int rate = 2;
}
int main() {
  using shop::rate;
  std::cout << (9 * rate) << "\n";
  return 0;
}
```

Nine times the imported rate prints `18`.

### An alias

`namespace s = shop` is only a shorter name. `s::price` is still the original variable, whose value is 7.

```cpp run expect="7" title="Short name"
#include <iostream>
namespace shop {
int price = 7;
}
namespace s = shop;
int main() {
  std::cout << s::price << "\n";
  return 0;
}
```

The qualified value is `7`.
