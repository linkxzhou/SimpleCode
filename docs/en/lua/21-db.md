This interpreter loads no `luasql` driver, and it has no network. One result row is one table.

### The driver does not run

The SQLite driver is not part of this interpreter.

```lua norun title="No driver"
local driver = require("luasql.sqlite3")
print(driver)
```

This block is not run. `luasql.sqlite3` cannot be loaded here.

### One row

The name and the price share a single table.

```lua run expect="茶 18" title="One row"
local row = { name = "茶", price = 18 }
print(row.name .. " " .. row.price)
```

The output shows `茶 18`.

### Two rows

The outer table stores one row at index 1 and another at index 2. The print reads the name on the second row.

```lua run expect="笔" title="The second row"
local rows = {
  { name = "茶" },
  { name = "笔" },
}
print(rows[2].name)
```

The output shows `笔`.
