The collector can reclaim a table once nothing points at it. The byte count changes from run to run, so these examples do not expect a fixed size.

### Drop the reference

The script prints the length while `t` still refers to the table. Setting `t` to `nil` drops that reference.

```lua run expect="2" title="The length first"
local t = { "茶", "笔" }
print(#t)
t = nil
print(t == nil and "无" or "有")
```

The output shows `2`. The next line is `无`.

### Collect on purpose

`collectgarbage("collect")` runs a collection cycle. The script then prints a fixed word, so the check does not depend on the heap size.

```lua run expect="收过" title="Collect once"
local t = { 1, 2, 3 }
t = nil
collectgarbage("collect")
print("收过")
```

The output shows `收过`.

### The type of the count

`collectgarbage("count")` returns a number. The lesson checks that type and leaves the magnitude alone.

```lua run expect="number" title="It is a number"
print(type(collectgarbage("count")))
```

The output shows `number`.
