In a condition, both 0 and the empty string count as true. The false values are `false` and `nil`.

### Out of stock

`stock` equals 0, so the comparison succeeds. The first branch runs.

```lua run expect="缺货" title="No stock"
local stock = 0
if stock == 0 then
  print("缺货")
else
  print("有货")
end
```

The output shows `缺货`.

### elseif

The value 2 fails the first test and matches the `elseif` branch. That branch prints the second label.

```lua run expect="乙" title="The second branch"
local code = 2
if code == 1 then
  print("甲")
elseif code == 2 then
  print("乙")
else
  print("其他")
end
```

The output shows `乙`.

### Zero is still true

On its own, 0 counts as true. The `else` branch does not run.

```lua run expect="有" title="Zero is true"
local n = 0
if n then
  print("有")
else
  print("无")
end
```

The output shows `有`.
