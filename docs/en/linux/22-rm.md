rm unlinks a directory entry at once. This guest has no trash folder. Deleted bytes are not moved into a wastebasket.

### Delete one file

Once the file is gone, ls exits nonzero. Chain missing with || so the script still succeeds overall, and the expectation can lock that fixed word.

```linux run expect="missing" title="The file is already gone"
echo hi > /tmp/gone && rm /tmp/gone && ls /tmp/gone || echo missing
```

The script prints `missing`.

### Removing a directory requires -r

Without -r, rm refuses a directory. With -r it walks in and unlinks the files inside. Afterward, listing the old path fails, and || prints gone-dir.

```linux run expect="gone-dir" title="Remove a directory recursively"
mkdir -p /tmp/rmdir/inner && rm -r /tmp/rmdir && ls /tmp/rmdir || echo gone-dir
```

The script prints `gone-dir`.

### Removed files do not land in a trash folder

There is no desktop path such as ~/.local/share/Trash. If you want a spare copy, cp it first and rm the original afterward.

```linux run expect="keep" title="The spare copy remains"
echo keep > /tmp/keep && cp /tmp/keep /tmp/keep2 && rm /tmp/keep && cat /tmp/keep2
```

The spare file still reads `keep`.
