ls is a BusyBox applet. Its columns do not line up the way GNU ls does. Expectations mention only names that are sure to appear, and color is switched off.

### With no arguments, list the working directory

Change into /tmp before listing, so the long root roster stays out of the way. -1 puts a single name on each line.

```linux run expect="box" title="One name per line"
mkdir -p /tmp/box && cd /tmp && ls --color=never -1
```

`box` appears in the list.

### -l prints the long listing

The first field is the mode, followed by the link count, the owner, and the size. The date changes between runs, so the expectation locks only the mode string.

```linux run expect="-rw-r--r--" title="Mode in the long listing"
mkdir -p /tmp/box && echo hi > /tmp/box/item && ls --color=never -l /tmp/box/item
```

The mode field is `-rw-r--r--`.

### -a reveals names that begin with a dot

The entries `.` and `..` are always present. An ordinary file whose name starts with a dot stays hidden until -a is added.

```linux run expect=".hidden" title="A hidden file"
mkdir -p /tmp/dotdir && echo x > /tmp/dotdir/.hidden && ls --color=never -1 -a /tmp/dotdir
```

`.hidden` is listed.
