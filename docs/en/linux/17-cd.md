cd is a builtin of ash. Home is /root. If a docs block contains only a bare cd, the run ends before you can see the working directory.

### With no argument, cd returns home

Visit /tmp first, then run cd with an empty argument list. pwd should answer /root. The tilde in the prompt names that same path.

```linux run expect="/root" title="Back in /root"
cd /tmp && cd && pwd
```

The printed path is `/root`.

### cd - returns to the previous directory

The minus sign means OLDPWD. After moving from /tmp to the root, cd - prints the old path and lands back in /tmp.

```linux run expect="/tmp" title="Back in the earlier /tmp"
cd /tmp && cd / && cd - && pwd
```

Both the dash form and pwd report `/tmp`.

### A script's cd does not move the caller

main.sh runs inside a subshell. When that script exits, the interactive prompt is still the home directory saved in the snapshot, unless you typed cd yourself in the terminal. A lone directory change prints nothing observable, so the sample is read-only.

```linux norun title="A lone cd shows nothing"
cd /tmp
```
