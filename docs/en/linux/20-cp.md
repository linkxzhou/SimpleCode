cp duplicates content. Without -r it accepts files only. A directory needs an explicit recursive copy, or BusyBox refuses the request.

### Copy a file onto a new path

Write the source and the target as absolute paths. The new file matches the source. Check the bytes with cat.

```linux run expect="hi" title="Bytes after the copy"
echo hi > /tmp/one && cp /tmp/one /tmp/two && cat /tmp/two
```

The copy contains `hi`.

### A directory target keeps the original basename

When the destination is a directory, the filename stays as it was. Listing that directory should show the old name.

```linux run expect="one" title="The original name inside the directory"
echo hi > /tmp/one && mkdir -p /tmp/cpdest && cp /tmp/one /tmp/cpdest && ls --color=never -1 /tmp/cpdest
```

The directory lists `one`.

### A directory copy has to be recursive

-r carries files that live in subdirectories. Reading f inside the copy should match the z written into the source.

```linux run expect="z" title="The recursive copy"
mkdir -p /tmp/src/sub && echo z > /tmp/src/sub/f && cp -r /tmp/src /tmp/dst && cat /tmp/dst/sub/f
```

The nested file contains `z`.
