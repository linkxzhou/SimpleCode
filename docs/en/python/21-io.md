Send output with `print`. Take input with `input`, or start from text you prepared ahead of time.

### The separator

`sep` replaces the space that normally sits between arguments. `end` replaces the final newline.

```python run expect="tea-water" title="Separate with a hyphen"
print("tea", "water", sep="-")
```

The joined line is `tea-water`.

### Split one line

If the data already lives in a string, `split` cuts it on whitespace. There is no need to read the keyboard.

```python run expect="18" title="The second field"
name, price = "tea 18".split()
print(price)
```

The second field is `18`.

### input reads until a newline

Without a newline, `input` waits and does not return. The standard input attached to a fence must carry that newline.

```python run stdin="finished\n" expect="finished" title="Read one line"
line = input()
print(line)
```

The line that was read is `finished`.
