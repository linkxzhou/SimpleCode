When the condition is true, execution enters the indented block. Do not wrap that condition in extra parentheses.

### if and else

Only one of the two branches runs.

```python run expect="正数" title="The positive branch"
n = 4
if n > 0:
    print("正数")
else:
    print("非正")
```

The chosen word is `正数`.

### elif

Several thresholds are tried from the top downward. The first success stops the chain.

```python run expect="中" title="Score bands"
score = 70
if score >= 90:
    print("高")
elif score >= 60:
    print("中")
else:
    print("低")
```

A score of 70 prints `中`.

### Comparison is not assignment

Test equality with two equals signs. One equals sign assigns, and that form cannot stand in an `if` condition.

```python run expect="True" title="Two equals signs"
word = "茶"
print(word == "茶")
```

The comparison prints `True`.
