This shell has no functions, and `source` cannot load a definition from another file. Repeat the command where you need it, or place the words in `for`.

### A brace function is unread

A name, parentheses, and a brace body cannot be declared. `hello` never becomes a command.

```sh norun title="No functions"
hello() {
  echo 你好
}
hello
```

Run does not start this sample. Function syntax is outside this shell.

### Write the line twice

Two `printf` commands produce the greeting twice. Each call writes one line.

```sh run expect="你好" title="The first line"
printf '%s\n' 你好
printf '%s\n' 你好
```

Each line shows `你好`.

### Hand the next command a variable

Store the word first. The following command reads that variable, which is the parameter here.

```sh run expect="笔" title="Pass it to printf"
item=笔
printf '%s\n' "$item"
```

The line shows `笔`.
