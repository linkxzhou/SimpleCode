`if` runs the `then` list when the condition exits with 0. `fi` closes the statement.

### The matching branch

The item is pen, so the first branch runs. The `else` list is skipped.

```sh run expect="pen" title="The first branch"
item=pen
if [ "$item" = pen ]; then
  printf '%s\n' pen
else
  printf '%s\n' other
fi
```

The line shows `pen`.

### elif

cup fails the first test and matches the middle one. That middle branch prints the word.

```sh run expect="cup" title="The middle branch"
item=cup
if [ "$item" = pen ]; then
  printf '%s\n' pen
elif [ "$item" = cup ]; then
  printf '%s\n' cup
else
  printf '%s\n' other
fi
```

The line shows `cup`.

### else

ticket matches neither of the tests above it. The `else` branch prints that word.

```sh run expect="ticket" title="The last branch"
item=ticket
if [ "$item" = pen ]; then
  printf '%s\n' pen
elif [ "$item" = cup ]; then
  printf '%s\n' cup
else
  printf '%s\n' ticket
fi
```

The line shows `ticket`.
