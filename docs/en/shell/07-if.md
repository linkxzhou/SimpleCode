`if` runs the `then` list when the condition exits with 0. `fi` closes the statement.

### The matching branch

The item is 笔, so the first branch runs. The `else` list is skipped.

```sh run expect="笔" title="The first branch"
item=笔
if [ "$item" = 笔 ]; then
  printf '%s\n' 笔
else
  printf '%s\n' 其他
fi
```

The line shows `笔`.

### elif

水杯 fails the first test and matches the middle one. That middle branch prints the word.

```sh run expect="水杯" title="The middle branch"
item=水杯
if [ "$item" = 笔 ]; then
  printf '%s\n' 笔
elif [ "$item" = 水杯 ]; then
  printf '%s\n' 水杯
else
  printf '%s\n' 其他
fi
```

The line shows `水杯`.

### else

车票 matches neither of the tests above it. The `else` branch prints that word.

```sh run expect="车票" title="The last branch"
item=车票
if [ "$item" = 笔 ]; then
  printf '%s\n' 笔
elif [ "$item" = 水杯 ]; then
  printf '%s\n' 水杯
else
  printf '%s\n' 车票
fi
```

The line shows `车票`.
