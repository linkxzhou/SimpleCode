Braces run only while the condition holds. Both numeric zero and an empty string count as false.

### One branch or the other

A positive number selects the opening branch. The alternate branch is left alone.

```js run expect="plus" title="Positive case"
const n = 4;
if (n > 0) {
  console.log("plus");
} else {
  console.log("badnum");
}
```

The selected label is `plus`.

### Empty text is false

An empty string does not enter the opening branch.

```js run expect="empty" title="Empty string"
const word = "";
if (word) {
  console.log("has");
} else {
  console.log("empty");
}
```

The alternate label is `empty`.

### Further tests

Each condition is examined from the top. The first true condition logs, and later conditions are ignored. A score of seventy falls in the middle band.

```js run expect="mid" title="Score band"
const score = 70;
if (score >= 90) {
  console.log("high");
} else if (score >= 60) {
  console.log("mid");
} else {
  console.log("low");
}
```

The middle label is `mid`.
