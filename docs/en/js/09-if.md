Braces run only while the condition holds. Both numeric zero and an empty string count as false.

### One branch or the other

A positive number selects the opening branch. The alternate branch is left alone.

```js run expect="正数" title="Positive case"
const n = 4;
if (n > 0) {
  console.log("正数");
} else {
  console.log("非正");
}
```

The selected label is `正数`.

### Empty text is false

An empty string does not enter the opening branch.

```js run expect="空" title="Empty string"
const word = "";
if (word) {
  console.log("有");
} else {
  console.log("空");
}
```

The alternate label is `空`.

### Further tests

Each condition is examined from the top. The first true condition logs, and later conditions are ignored. A score of seventy falls in the middle band.

```js run expect="中" title="Score band"
const score = 70;
if (score >= 90) {
  console.log("高");
} else if (score >= 60) {
  console.log("中");
} else {
  console.log("低");
}
```

The middle label is `中`.
