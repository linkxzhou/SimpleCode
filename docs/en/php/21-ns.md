Put `namespace` near the top of the file. Callers outside that namespace add a prefix.

### A fully qualified call

`\Shop\price` names the function declared in the `Shop` namespace.

```php run expect="18" title="A qualified name"
<?php
namespace Shop;
function price() {
    return 18;
}
echo \Shop\price(), "\n";
```

The qualified call returns `18`.

### A second namespace

A second namespace can declare its own `price`. The prefix `\Ink` names the function in that namespace.

```php run expect="7" title="The ink price"
<?php
namespace Ink;
function price() {
    return 7;
}
echo \Ink\price(), "\n";
```

The ink function returns `7`.

### A call inside the namespace

Inside `Shop`, the short name `rate` resolves without a prefix.

```php run expect="18" title="The current namespace"
<?php
namespace Shop;
function rate() {
    return 2;
}
echo rate() * 9, "\n";
```

Multiplying the rate by 9 prints `18`.
