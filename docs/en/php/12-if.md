A condition picks which block runs. The samples use a stock count and an empty name.

### Stock is zero

A stock of 0 matches `=== 0`, so the out-of-stock message runs.

```php run expect="缺货" title="No stock"
<?php
$stock = 0;
if ($stock === 0) {
    echo "缺货\n";
} else {
    echo "有货\n";
}
```

That branch prints `缺货`.

### Stock is above zero

A stock of 2 fails the `=== 0` test, so the `else` branch runs.

```php run expect="有货" title="Stock left"
<?php
$stock = 2;
if ($stock === 0) {
    echo "缺货\n";
} else {
    echo "有货\n";
}
```

The else branch prints `有货`.

### An empty string

An empty string is false in a condition, so the script writes `无`.

```php run expect="无" title="Empty is false"
<?php
$name = "";
echo $name ? "有" : "无", "\n";
```

The false side prints `无`.
