A condition picks which block runs. The samples use a stock count and an empty name.

### Stock is zero

A stock of 0 matches `=== 0`, so the out-of-stock message runs.

```php run expect="soldout" title="No stock"
<?php
$stock = 0;
if ($stock === 0) {
    echo "soldout\n";
} else {
    echo "instock\n";
}
```

That branch prints `soldout`.

### Stock is above zero

A stock of 2 fails the `=== 0` test, so the `else` branch runs.

```php run expect="instock" title="Stock left"
<?php
$stock = 2;
if ($stock === 0) {
    echo "soldout\n";
} else {
    echo "instock\n";
}
```

The else branch prints `instock`.

### An empty string

An empty string is false in a condition, so the script writes `none`.

```php run expect="none" title="Empty is false"
<?php
$name = "";
echo $name ? "has" : "none", "\n";
```

The false side prints `none`.
