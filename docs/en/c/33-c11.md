This clang compiles C as C11. A failing `_Static_assert` stops the build. A passing one emits no runtime test. `_Generic` selects by the type of the controlling expression at compile time. It is not a runtime `switch`. Each listing below compiles and prints one line.

### A compile-time assert

`sizeof(int)` is at least 2. The message string is for the compiler when the assert fails. On success the program prints `ok`.

```c run expect="ok" title="Assert passes"
#include <stdio.h>
int main(void) {
  _Static_assert(sizeof(int) >= 2, "int is wide enough");
  printf("ok\n");
  return 0;
}
```

The assert passes and the line is `ok`.

### Pick a name by type

The controlling expression of `kind(1)` has type `int`, so the selection is `"i"`. A `double` would select `"d"`. This call does not pass a floating value. `default` covers every other type.

```c run expect="i" title="Marker for int"
#include <stdio.h>
#define kind(x) _Generic((x), int: "i", double: "d", default: "?")
int main(void) {
  printf("%s\n", kind(1));
  return 0;
}
```

The marker is `i`.

### An anonymous member

The outer struct contains a struct with no name, and member `a` is lifted to the outer type. The initializer still needs a brace pair for the inner struct. `pack.a` is 3, with no middle name to spell.

```c run expect="3" title="Lifted member"
#include <stdio.h>
struct Pack {
  struct { int a; };
  int b;
};
int main(void) {
  struct Pack pack = {{3}, 4};
  printf("%d\n", pack.a);
  return 0;
}
```

The anonymous member holds 3.

### Exercise: alignment in bytes

`_Alignof(int)` is the alignment requirement of `int`. On this wasm32 target it is 4. The value is cast to `int` and printed with `%d`, so the format is not tied to the width of `size_t`.

C Primer Plus also lists C11 later in the book. The sentences are not copied: https://book.douban.com/subject/26792521 .

```c run expect="4" title="Alignment of int"
#include <stdio.h>
int main(void) {
  printf("%d\n", (int)_Alignof(int));
  return 0;
}
```

The alignment is 4 bytes.
