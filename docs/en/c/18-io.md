`scanf` reads standard input supplied for the run. Its return value is the number of items it converted successfully.

### A format string

`%d` converts an `int`, and `%s` converts a string. A space in the format separates those two converted values.

```c run expect="茶 18" title="Two fields"
#include <stdio.h>
int main(void) {
  printf("%s %d\n", "茶", 18);
  return 0;
}
```

The output contains `茶 18`.

### Read an integer

The standard input for this run is a line containing 12. `printf` runs only when `scanf` reports that one conversion succeeded.

```c run stdin="12\n" expect="12" title="Read input"
#include <stdio.h>
int main(void) {
  int n = 0;
  if (scanf("%d", &n) == 1) printf("%d\n", n);
  return 0;
}
```

The output contains `12`.

### Skip the result on failure

If the input is not a number, `scanf` returns 0. The `else` branch prints a failure message and leaves the unread `n` unused.

```c run stdin="no\n" expect="失败" title="Not a number"
#include <stdio.h>
int main(void) {
  int n = 0;
  if (scanf("%d", &n) == 1) printf("%d\n", n);
  else printf("失败\n");
  return 0;
}
```

The output contains `失败`.
