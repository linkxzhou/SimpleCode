A condition is a boolean. if enters its braces only when the condition is true. Otherwise control goes to else.

### if and else pick one branch

A fare above 10 takes the expensive branch. Otherwise the cheap branch runs. Only one line prints.

```java run expect="low" title="Two branches"
public class Main {
    public static void main(String[] args) {
        // 10 or below takes else
        int fare = 8;
        if (fare > 10) {
            System.out.println("high");
        } else {
            System.out.println("low");
        }
    }
}
```

8 takes else.

### else if adds another band

Check above 20 first, then above 10. The final else runs only when both tests fail.

```java run expect="mid" title="Three bands"
public class Main {
    public static void main(String[] args) {
        // The middle band
        int fare = 15;
        if (fare > 20) {
            System.out.println("top");
        } else if (fare > 10) {
            System.out.println("mid");
        } else {
            System.out.println("low");
        }
    }
}
```

15 lands in the middle band.

### Conditions can combine

&& requires a free seat and a fare within the cap. Both sides must be true before open prints.

```java run expect="open" title="Combined condition"
public class Main {
    public static void main(String[] args) {
        // Seats and fare both qualify
        int seats = 2;
        int fare = 9;
        if (seats > 0 && fare <= 10) {
            System.out.println("open");
        } else {
            System.out.println("shut");
        }
    }
}
```

Both conditions hold here.
