rm 直接卸掉目录项。这台客户机没有回收站，删掉的字节不会进某个废纸篓。

### 删除文件

文件消失后，ls 以非零退出。用 || 接一句 missing，脚本整体仍成功，期望锁定这句固定文本。

```linux run expect="missing" title="已经不在"
echo hi > /tmp/gone && rm /tmp/gone && ls /tmp/gone || echo missing
```

### 删目录要加递归

不带 -r 时，rm 拒绝目录。-r 会走进去删掉里面的文件。删完后再 ls 父目录，名字应当消失，于是用 || 打出 gone-dir。

```linux run expect="gone-dir" title="递归删目录"
mkdir -p /tmp/rmdir/inner && rm -r /tmp/rmdir && ls /tmp/rmdir || echo gone-dir
```

### 删掉的文件不会进回收站

没有 ~/.local/share/Trash 这种桌面约定。要留底就先 cp，再 rm。

```linux run expect="keep" title="副本还在"
echo keep > /tmp/keep && cp /tmp/keep /tmp/keep2 && rm /tmp/keep && cat /tmp/keep2
```
