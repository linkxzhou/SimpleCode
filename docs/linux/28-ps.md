ps 读的是客户机里的进程表。浏览器、编辑器都在宿主上，不会出现在这张表里。

### ps 列出当前进程

表头第一列是 PID。init 是 1 号进程，脚本自己的 sh 也在表里。

```linux run expect="PID" title="表头"
ps | head -n 1
```

### BusyBox 的列和 procps 不一样

列是 PID、USER、COMMAND，没有 GNU 那一长串 STAT 和 TIME。期望锁住 COMMAND 这个词。

```linux run expect="COMMAND" title="命令列"
ps | head -n 1
```

### 看不到宿主机上的浏览器进程

能看到的是 init、内核线程和当前的 sh。宿主的标签页不在这张表里。

```linux run expect="init" title="一号进程"
ps | grep init
```
