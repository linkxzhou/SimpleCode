mv 在同一文件系统上多半是改名。这颗镜像的 /tmp 是一块 tmpfs，改名不会复制字节。

### 改名是同一文件系统上的移动

旧路径消失，新路径出现。cat 新路径应读到移动前写入的内容。

```linux run expect="hi" title="新名字上的内容"
echo hi > /tmp/old && mv /tmp/old /tmp/new && cat /tmp/new
```

### 目标已存在时会被换掉

若 /tmp/new 已经有别的内容，再次 mv 会盖掉它。BusyBox 默认不询问。

```linux run expect="fresh" title="覆盖后的文本"
echo old > /tmp/new && echo fresh > /tmp/fresh && mv /tmp/fresh /tmp/new && cat /tmp/new
```

### 移到别的目录要写完整目标

只写目录名时，文件名留在那个目录里。ls 应列出 leaf。

```linux run expect="leaf" title="目录中的文件名"
mkdir -p /tmp/mvdir && echo hi > /tmp/leaf && mv /tmp/leaf /tmp/mvdir && ls --color=never -1 /tmp/mvdir
```
