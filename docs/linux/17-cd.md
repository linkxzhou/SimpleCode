cd 是 ash 的内建。家目录是 /root。文档块若只有一行 cd，跑完就结束，工作目录看不出来。

### 不带参数时回到家目录

先去 /tmp，再执行不带参数的 cd，pwd 应打出 /root。波浪号提示符和这个路径是一回事。

```linux run expect="/root" title="回到 /root"
cd /tmp && cd && pwd
```

### cd - 回到上一个目录

减号表示 OLDPWD。从 /tmp 再到根，然后 cd - 会打印并回到 /tmp。

```linux run expect="/tmp" title="回到先前的 /tmp"
cd /tmp && cd / && cd - && pwd
```

### 脚本里的 cd 不改变调用者

main.sh 是子 shell 在跑。它退掉之后，交互提示符仍在快照里的家目录，除非你在终端里另外敲过 cd。单独一行切换没有可观察输出，所以标成只读。

```linux norun title="单独的 cd 看不出结果"
cd /tmp
```
