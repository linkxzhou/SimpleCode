cp 复制内容。不带 -r 时只处理文件；目录要显式递归，否则 BusyBox 会拒绝。

### 把文件复制到新路径

源和目标都写绝对路径。复制后的文件内容和源一致，用 cat 核对。

```linux run expect="hi" title="复制出的内容"
echo hi > /tmp/one && cp /tmp/one /tmp/two && cat /tmp/two
```

### 目标是目录时保留原名

把文件抄进一个目录时，basename 保持不变。ls 那个目录应列出原来的名字。

```linux run expect="one" title="目录里的原名"
echo hi > /tmp/one && mkdir -p /tmp/cpdest && cp /tmp/one /tmp/cpdest && ls --color=never -1 /tmp/cpdest
```

### 复制目录需要递归

-r 会带上子目录里的文件。读副本里的 f，应和源里写入的 z 相同。

```linux run expect="z" title="递归副本"
mkdir -p /tmp/src/sub && echo z > /tmp/src/sub/f && cp -r /tmp/src /tmp/dst && cat /tmp/dst/sub/f
```
