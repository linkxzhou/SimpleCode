ls 是 BusyBox 小程序。列对齐和 GNU 不同，期望只写肯定会出现的名字，并关掉颜色。

### 不带参数时列出当前目录

先 cd 到 /tmp 再列出，避免和根目录的长名单缠在一起。-1 让一行只有一个名字。

```linux run expect="box" title="一行一个名字"
mkdir -p /tmp/box && cd /tmp && ls --color=never -1
```

### -l 显示长格式

第一列是模式，其后是链接数、属主、大小。日期会变，期望只锁住模式串。

```linux run expect="-rw-r--r--" title="长格式里的模式"
echo hi > /tmp/box/item && ls --color=never -l /tmp/box/item
```

### -a 带出以点开头的名字

点自己和点点总会在。以点开头的普通文件默认被藏起来，-a 才列出来。

```linux run expect=".hidden" title="隐藏文件"
mkdir -p /tmp/dotdir && echo x > /tmp/dotdir/.hidden && ls --color=never -1 -a /tmp/dotdir
```
