## 每章结构

frontmatter（见 plan/LEARN.md §6）之后：

1. 讲解（2–5 个 `##` 小节）。「本章目标」由 `goals` 自动渲染，正文不要再写一遍。
2. 至少 3 个可运行代码块，带 `expect`。
3. `## 常见错误`
4. `## 练习`（2 题，答案放在 `::: answer` 里，答案代码同样用 `run` + `expect`）
5. `## 延伸阅读` 与 `## 参考与致谢`

## 代码块

````markdown
```python run stdin="Ada\n" expect="你好，Ada！" title="问候"
name = input("名字？")
print(f"你好，{name}！")
```
````

- 可运行语言默认显示运行按钮；只读块写 `norun`。
- 输出必须稳定：固定随机种子，不打印当前时间、内存地址。
- 单文件、无网络、无第三方包。需要输入时必须给 `stdin`。
- 会停住的示例（死循环）加 `smoke="skip"`，避免冒烟测试挂起。
- 多文件示例不要标成可运行（`file` / `group` 只会提供复制）。
