条件为真才进入花括号。数字 0 和空串都是假。

### if else

只走一个分支。

```js run expect="plus" title="正数分支"
const n = 4;
if (n > 0) {
  console.log("plus");
} else {
  console.log("badnum");
}
```

输出里能看到 `plus`。

### 空串为假

空串不会进入 `if` 的第一支。

```js run expect="empty" title="空串"
const word = "";
if (word) {
  console.log("has");
} else {
  console.log("empty");
}
```

输出里能看到 `empty`。

### else if

从上往下试，命中就停。

```js run expect="mid" title="分数档"
const score = 70;
if (score >= 90) {
  console.log("high");
} else if (score >= 60) {
  console.log("mid");
} else {
  console.log("low");
}
```

输出里能看到 `mid`。
