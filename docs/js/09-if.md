条件为真才进入花括号。数字 0 和空串都是假。

### if else

只走一个分支。

```js run expect="正数" title="正数分支"
const n = 4;
if (n > 0) {
  console.log("正数");
} else {
  console.log("非正");
}
```

输出里能看到 `正数`。

### 空串为假

空串不会进入 `if` 的第一支。

```js run expect="空" title="空串"
const word = "";
if (word) {
  console.log("有");
} else {
  console.log("空");
}
```

输出里能看到 `空`。

### else if

从上往下试，命中就停。

```js run expect="中" title="分数档"
const score = 70;
if (score >= 90) {
  console.log("高");
} else if (score >= 60) {
  console.log("中");
} else {
  console.log("低");
}
```

输出里能看到 `中`。
