`map` 产生新数组，`filter` 留下通过测试的项，`reduce` 收成一个值。它们都不改原数组；`sort` 会改。

数字排序必须给比较函数，否则会按文本排，`10` 会排在 `2` 前面。

```js run expect="85" title="及格平均"
const scores = [40, 80, 90];
const passed = scores.filter((n) => n >= 60);
const avg = passed.reduce((s, n) => s + n, 0) / passed.length;
console.log(avg);
```

```js run expect="1,2,10" title="数字排序"
const nums = [10, 2, 1];
console.log(nums.slice().sort((a, b) => a - b).join(","));
```

```js run expect="1,2,3" title="摊平一层"
const nested = [[1], [2, 3]];
const flat = [];
for (const row of nested) flat.push(...row);
console.log(flat.join(","));
```

map、filter、reduce 都返回新值，不改原数组。map 一对一变换，filter 按条件留下，reduce 收成一个值。reduce 如果数组可能为空，一定给初始值，否则会抛错。

sort 会改原数组，而且默认按字符串比较。数字要传 (a, b) => a - b。想保留原数组就先 slice 再 sort。返回的是同一个数组，所以可以接着 join。

展开运算符可以把数组拆进另一个数组。[...a, ...b] 是浅拷贝拼接。嵌套的数组仍是原来的引用。flat 只摊开一层，除非你给深度。本章用循环展开一层，避免依赖较新的默认行为讨论。

链式调用读起来像流水。每一段都短的时候很好，一段里塞进复杂 if 时就改回中间变量。中间变量也方便你 console.log 半成品。

回调里的参数名字随便起，但同一条链上保持 n 或 item 一种风格。读者靠名字知道这是元素还是下标。map 的回调可以接收下标作为第二个参数，不需要时不要写它，避免被人以为你用到了位置。

sort 的比较函数返回负数、0、正数。a - b 是升序。写反了就是降序。返回 true 或 false 是错的，布尔值会被转成 1 或 0，排序结果不稳定到你看不出规律。

复制数组用 slice 或展开。两者都是浅的。元素如果是对象，复制数组之后改对象字段，两条数组都看得到。

数组按下标取值，从 0 开始。map、filter、reduce 产生新结果，不改原数组。map 的回调返回新元素，filter 的回调返回要不要留下，reduce 把元素收成一个值。reduce 一定要给初始值。空数组没有初始值时会抛异常；给了 0，空数组的和就是 0。

sort 修改原数组，并且默认按字符串比较。数字排序必须给比较函数，否则 10 会排在 2 前面。若调用方还要原来的顺序，先 slice 再 sort。比较函数返回负数、0 或正数，不要返回布尔。

回调的参数名字保持一种风格。同一条链上用 n 表示元素，不要一会儿用下标一会儿用元素。map 可以接收下标作为第二个参数，不需要时不要写它。链式调用每一步的结果类型要清楚：filter 之后仍是数组，reduce 之后可能是数字。

下标赋值会改原数组。和 map 混在同一次实验里时，先问「我要的是新数组还是改原来的」。测试期望如果只写了新结果，你仍要检查原数组有没有被悄悄改掉。

map 出平方，打印 `1,4,9`。

```js run expect="1,4,9" title="参考答案"
console.log([1, 2, 3].map((n) => n * n).join(","));
```

用 filter 留下大于 2 的数，打印个数。数组是 [1, 2, 3, 4]。

::: answer 参考答案：大于 2
```js run expect="2" title="参考答案"
console.log([1, 2, 3, 4].filter((n) => n > 2).length);
```
:::

## 最佳实践

- reduce 总是传入初始值。
- 数字排序提供比较函数，并且在需要时先复制再排序。
- 链式调用里一旦不好读，就拆成中间变量。

## 小结

map、filter、reduce 产生新结果，sort 修改原数组。数字排序必须给比较函数，reduce 要有初始值。

## 常见错误

- sort() 不带比较函数就排序数字。
- reduce 忘记初始值，空数组会抛错。
