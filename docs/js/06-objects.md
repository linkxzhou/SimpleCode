对象是键值集合。展开 `{ ...a, ...b }` 后者覆盖前者的同名键。可选链 `?.` 在左边是 null 或 undefined 时短路。

`JSON.stringify` 只保留可序列化的数据，函数和 `undefined` 会被丢掉。

```js run expect="light 14" title="合并配置"
const base = { theme: "light", size: 12 };
const extra = { size: 14 };
const cfg = { ...base, ...extra };
console.log(cfg.theme, cfg.size);
```

```js run expect="未知" title="可选链与 JSON"
const user = { name: "Ada" };
console.log(user.city?.name ?? "未知");
console.log(JSON.stringify({ name: user.name, n: 1 }));
```

```js run expect="3" title="解构"
const { a, b = 2 } = { a: 1 };
console.log(a + b);
```

对象字面量的键是字符串或 Symbol。数字键会被转成字符串，所以 obj[1] 和 obj["1"] 是同一格。展开 { ...a, ...b } 是浅合并，b 的同名键覆盖 a。嵌套对象仍共享。

可选链 ?. 在左边是 null 或 undefined 时短路并得到 undefined。再配合 ?? 可以给默认值。?? 只在 null 或 undefined 时取右边，0 和空字符串会保留。不要用 || 给数字默认值，否则 0 会被换成默认值。

解构可以给默认值，并且可以改名。const { a: width = 1 } = obj 把 a 读进 width。模式对不上时，从 undefined 上解构会抛错，先确认对象存在。

JSON.stringify 丢掉函数、undefined 和 Symbol。日期会变成字符串。parse 得到的是普通对象，没有方法。环状引用会抛错。用户输入的 JSON 要放进 try。

可选链不要接在你确定存在的东西后面，那会让人以为这里可能缺失。只在「也许没有」的字段上用。连续的 a?.b?.c 读起来费劲时，先把中间结果取出来判断。

JSON 的文本必须是双引号字符串。单引号的类似 JSON 会解析失败。练习里的样例因此写成双引号，并在 JS 字符串里把引号转义好。

展开合并时，后面的对象赢。想保留旧值又填上新值，把新的放在后面，并且不要意外地展开 undefined。展开 null 或 undefined 在对象字面量里会被忽略，这是有用的，但不要依赖太隐晦的写法。

对象是字符串键到值的映射。数字键会被转成字符串，所以 obj[1] 和 obj["1"] 是同一个键。键的顺序对教学断言不重要，测试打印具体字段，不依赖遍历顺序。展开做浅合并，后面的同名键覆盖前面的。嵌套对象仍共享，改内层两边都看见。

点号和方括号都能读字段。键来自变量时必须用方括号。可选链在中间是 null 或 undefined 时停下来，结果是 undefined，不会抛异常。不要在你确定存在的字段上用可选链，那会让人以为这里可能缺失。连续两三层时，先把中间结果取出来。

?? 只在左边是 null 或 undefined 时才取右边。0 和空字符串会保留。|| 会把 0、空字符串和 false 都换成右边，给数字做默认值时不要用它。需要区分「没有这个字段」和「值是 0」时，用 in 或和 undefined 比较。

删除字段用 delete。把它设成 undefined 后，键可能还在。打印之前先想清楚你要的是键不存在，还是值空。

## 练习

把 JSON 文本 `{"n":41}` 解析后加 1。

::: answer 参考答案

```js run expect="42" title="参考答案"
const data = JSON.parse('{"n":41}');
console.log(data.n + 1);
```

合并 {a:1, b:1} 和 {b:2}，打印 b。

::: answer 参考答案：后者覆盖
```js run expect="2" title="参考答案"
const cfg = { a: 1, b: 1, ...{ b: 2 } };
console.log(cfg.b);
```
:::

## 最佳实践

- 数字默认值用 ??，不用 ||，避免把 0 吃掉。
- 展开只做浅合并，嵌套对象要单独复制。
- JSON 只拿来存数据，不拿来存函数。

## 小结

对象按字符串键存值，展开做浅合并。可选链和 ?? 处理缺失，不要用 || 给 0 做默认值。

## 常见错误

- 用展开做深拷贝。嵌套对象仍然是同一份。
- JSON.parse 用户输入却不 try。坏文本会抛 SyntaxError。
