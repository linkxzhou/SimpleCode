### 读「相加」

先做这一例。代码收成一行是 `console.log(19 + 23)`。先盖住终端，用手算结果，纸上的文本里要能找到「42」。这是子串：前面可以有别的输出，后面通常有换行，不要要求整屏只有这几个字。

然后点这个代码块上的 Run，不要点工具栏。代码块会先备份草稿，再把示例写进编辑器并执行。终端里用眼睛找「42」。退出码不是 0 时，先读错误的类型和最后一行，此时不要改期望。退出码是 0 但找不到这段文字，说明打印了别的值，回到产生该值的表达式，只改一处。

改过之后再点代码块上的 Run，会把你的修改盖掉。要验证修改，点工具栏上的 Run。预测和新输出一致后，点撤销，把草稿还给自己。一次只改这一例，不要连着改两个代码块。

## 最佳实践

- 不写 document、fetch、import。这个引擎没有页面，也没有模块加载。
- 需要先后顺序时用已完成的 Promise，不用 setTimeout。
- 从文档运行 TypeScript 后，编辑器里应看到转译注释和 JavaScript。

## 小结

QuickJS 只跑单文件脚本。浏览器 API 和计时器不在范围内，TypeScript 只去掉类型再执行。

## 常见错误

- 把教程里的浏览器示例原样贴进来。document 在这里是未定义的。
- 用 import 或 export。程序必须是单个文件。
