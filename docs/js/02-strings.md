`===` 不转换类型，`==` 会。`"6" + 7` 是拼接，`"6" * 7` 才变成数字运算。教学示例一律用 `===`。

模板字符串能插值，但为了少一层转义，示例用加号拼接，效果一样。

```js run expect="67" title="转换"
console.log("6" + 7);
console.log(Number("6") + 7);
console.log(1 === 1);
```

```js run expect="你好，Ada" title="拼接"
const name = "Ada";
console.log("你好，" + name);
```

```js run expect="two one" title="反转单词"
const words = "one two".split(" ");
console.log(words.reverse().join(" "));
```

== 会先转换类型再比较，=== 不会。0 == "0" 为真，0 === "0" 为假。教学和业务代码都用 ===，只在你故意讨论转换时才写 ==。

+ 两边只要有字符串，就变成拼接。"6" + 7 是 "67"，不是 13。减号、乘号会把字符串转成数字，"6" * 7 是 42。这种不一致是坑，算术前用 Number() 写清楚。

字符串的 slice 和 Python 类似，结束下标不包含。split 按分隔符切开，join 再拼回去。reverse 会改原数组，要保留顺序就先 slice() 复制。

模板字符串里的表达式写在美元符号和花括号里。文档源码为了少一层反引号，示例更多使用加号。你在编辑器里可以改成模板字符串，输出应该相同。

类型转换最容易混在 + 上。看到加号，先问两边是不是都是数字。有一个是字符串，就当成拼接来读。乘法没有拼接的含义，所以它会转数字，转不了就得到 NaN。

NaN 和谁比较都是 false，包括它自己。判断用 Number.isNaN。本章例子避开 NaN，真的出现时不要用 === 去找它。

slice 的右端不包含。和 Python 一样，这是为了让长度等于止减去起。记不住时，用一个六个字母的单词试前三个，输出应该是三个字符。

字符串按 UTF-16 码元索引，教学里用的英文和常见汉字，切片位置和你数的字符一致。slice 的右端不包含。slice(0, 6) 取前六个码元。负数从末尾数。和 Python 一样，越界的切片会截断，越界的单个下标则得到 undefined，而不是抛异常。

加号只要有一边是字符串就会拼接，另一边会被转成文本。乘法没有拼接的含义，字符串数字会先转成数字。转不了就得到 NaN，NaN 和任何值都不相等，包括它自己。看到加号，先问两边是不是都是数字。看到乘号，确认两边都能成数。

比较用 ===。如果你在演示类型转换，把转换写出来，不要藏在 == 里。长度用 length。空字符串的长度是 0，它在条件里是假，但非空字符串都是真，哪怕内容是 "0"。不要用字符串本身当开关，改成比较长度或比较具体的值。

trim 去掉两端空白，不改中间。replace 默认只换第一处，要全换需要全局正则或 split 再 join。本章的例子保持一次替换，避免正则把注意力带走。

## 最佳实践

- 相等比较写 ===。需要数字时先 Number，再运算。
- reverse 之前如果还要原数组，就先复制。
- 拼接用加号或模板字符串都可以，同一段代码里不要混用到难以阅读。

## 小结

+ 遇到字符串会拼接，其他算术运算符会把字符串转成数字。比较用 ===，切片不包含右端。

## 常见错误

- 用 == 比较用户输入。类型一转换，空字符串和 0 会变成同一件事。
- reverse 会改原数组。要保留原顺序就先 slice。
