名字空间避免不同段落里的同名变量撞在一起。

### 限定名

`shop::price` 指出它属于哪一段。

```cpp run expect="18" title="限定名"
#include <iostream>
namespace shop {
int price = 18;
}
int main() {
  std::cout << shop::price << "\n";
  return 0;
}
```

输出里能看到 `18`。

### using

`using` 之后可以直接写 `rate`。

```cpp run expect="18" title="引入一个名字"
#include <iostream>
namespace shop {
int rate = 2;
}
int main() {
  using shop::rate;
  std::cout << (9 * rate) << "\n";
  return 0;
}
```

输出里能看到 `18`。

### 别名

`namespace s = shop` 只是短名字，值仍是原来的。

```cpp run expect="7" title="短名字"
#include <iostream>
namespace shop {
int price = 7;
}
namespace s = shop;
int main() {
  std::cout << s::price << "\n";
  return 0;
}
```

输出里能看到 `7`。
