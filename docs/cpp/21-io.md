标准输入要在围栏上写好，并且以换行结束。

### 输出

`cout` 把字符串送到标准输出。

```cpp run expect="茶" title="打出茶"
#include <iostream>
int main() {
  std::cout << "茶\n";
  return 0;
}
```

输出里能看到 `茶`。

### 读一行

`getline` 读到换行，换行本身不留在字符串里。

```cpp run stdin="Ada\n" expect="你好，Ada" title="一行名字"
#include <iostream>
#include <string>
int main() {
  std::string name;
  std::getline(std::cin, name);
  std::cout << "你好，" << name << "\n";
  return 0;
}
```

输出里能看到 `你好，Ada`。

### 读一个整数

`>>` 跳过空白，读到一个整数为止。

```cpp run stdin="12\n" expect="24" title="乘二"
#include <iostream>
int main() {
  int n = 0;
  std::cin >> n;
  std::cout << (n * 2) << "\n";
  return 0;
}
```

输出里能看到 `24`。
