程序从 main 进入。返回 0 表示按我们的约定成功。std::cout 用 << 把值送出去。数字和字符串都可以送。换行写成 "\n"，不要依赖刷新去制造换行。

注释用 // 直到行尾，或用 /* */。注释不会出现在输出里。名字都写 std:: 前缀，避免 using 把后来的名字悄悄引进来。

一次只核对一行时，让这一行以换行结束。需要接在同一行时，前一次不要写换行。

```cpp run expect="Ada" title="两行"
#include <iostream>
int main() {
  std::cout << "Ada\n";
  std::cout << "Lovelace\n";
  return 0;
}
```

```cpp run expect="AB" title="同一行"
#include <iostream>
int main() {
  std::cout << "A";
  std::cout << "B\n";
  return 0;
}
```

```cpp run expect="可见" title="注释"
#include <iostream>
int main() {
  std::cout << "可见\n";
  // 这一行不会出现
  std::cout << 2026 << "\n";
  return 0;
}
```

## 读完再动手

本章要留下的是 「用 cout 打出文本和数字」、「写出注释」、「让 main 返回 0」。合上抽屉之前，用自己的话说出每一项目标对应哪一个示例的标题。对不上标题，就还没有把目标和代码连起来，先别展开练习答案。

练习的答案默认折着。先在编辑器里自己写，再展开对照。对照时只看输出是否包含期望的那几个字。两道都过了再进入下一章。下一次运行是新进程，这次的变量不会留下。

把这一章当成一次可以反复撤销的实验。点代码块上的 Run 会用示例覆盖编辑器，原来的草稿先备份。你改过的内容如果还想留着，先复制到别处，再点下一例。工具栏的 Run 不会从文档重写编辑器，所以它用来看你改过的版本。两种按钮各做各的事。下载进度写在按钮旁边，第一次打开这种语言时要等它结束，再判断示例是不是写错了。

记录你预测错的那一次。写下你以为会打印的文字，以及实际多出来或少掉的部分。进入下一章之前，要能用一句话说清差在哪。通过只说明期望的那几个字还在，不说明你已经看懂产生它的那一行。章节标题下的目标就是这份验收清单。差两个字也不要靠改期望凑过去。

## 常见错误

- 把 << 写成 >>。
- 注释写了和代码相反的说明。
- 用 endl 的刷新代替你真正想要的换行，读代码时看不清。

## 最佳实践

- 换行用 "\n"。
- 名字加上 std::。
- main 返回 0。

## 小结

cout 用 << 输出。换行写在字符串里。注释不会进入终端。
