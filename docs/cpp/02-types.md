整数相除仍是整数。20 / 6 得到 3，余数用 %。变量要声明并使用，否则编译失败。

引用是对象的另一个名字。int &r = n 之后，改 r 就是改 n。引用必须在诞生时绑定，不能改去绑另一个对象。要修改调用者的变量时，引用比指针少写一个星号。

条件里 0 是假，其余数字是真。这和 Ruby 不同。bool 的 false 也是假。

```cpp run expect="3" title="整除"
#include <iostream>
int main() {
  std::cout << (20 / 6) << "\n";
  std::cout << (20 % 6) << "\n";
  return 0;
}
```

```cpp run expect="42" title="引用"
#include <iostream>
int main() {
  int n = 41;
  int &r = n;
  r += 1;
  std::cout << n << "\n";
  return 0;
}
```

```cpp run expect="no" title="零是假"
#include <iostream>
int main() {
  int n = 0;
  std::cout << (n ? "yes" : "no") << "\n";
  return 0;
}
```

## 常见错误

- 以为 20 / 6 得到小数。
- 引用没有一开始就绑定。
- 把 0 当成真。

## 最佳实践

- 要改同一个对象时用引用。
- 整数运算先确认两边的类型。
- 每个变量都参与输出或运算。
