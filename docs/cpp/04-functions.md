函数把计算命名。按值传递时，函数里的赋值不影响调用者。引用参数是调用者对象的别名，函数里的修改会留下。

被调用的函数写在 main 上面。返回值不会自己出现在终端，main 里要用 cout 打出来。

一个函数只做一件事。需要同时给出「是否成功」和「结果」时，这一章仍返回结果，失败留到后面的返回值约定。

```cpp run expect="42" title="相加"
#include <iostream>
int add(int a, int b) { return a + b; }
int main() {
  std::cout << add(41, 1) << "\n";
  return 0;
}
```

```cpp run expect="42" title="引用参数"
#include <iostream>
void inc(int &n) { n += 1; }
int main() {
  int n = 41;
  inc(n);
  std::cout << n << "\n";
  return 0;
}
```

```cpp run expect="42" title="两倍"
#include <iostream>
int twice(int n) { return n * 2; }
int main() {
  std::cout << twice(21) << "\n";
  return 0;
}
```

## 常见错误

- 想修改调用者却按值传递。
- 返回值没有打印。
- 在定义之前调用，又没有声明。

## 最佳实践

- 只读参数按值，要改的参数用引用。
- 函数定义放在 main 前。
- cout 打印返回值。

## 小结

返回值交回结果，引用参数修改调用者。终端只看见 cout。

## 练习

写函数返回平方，打印 6 的平方。

::: answer 参考答案：平方
```cpp run expect="36" title="参考答案"
#include <iostream>
int sq(int n) { return n * n; }
int main() {
  std::cout << sq(6) << "\n";
  return 0;
}
```
:::

用引用参数把 5 加 2 后打印。

::: answer 参考答案：加二
```cpp run expect="7" title="参考答案"
#include <iostream>
void add2(int &n) { n += 2; }
int main() {
  int n = 5;
  add2(n);
  std::cout << n << "\n";
  return 0;
}
```
