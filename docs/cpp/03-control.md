if 在条件为假时走 else。比较用 ==。写成 = 是赋值，值若为 0 就总走另一支。

范围 for 可以遍历 vector，这一章先用经典 for，次数写在循环头上。while 也要有一个变量靠近结束。说不出来就先别运行。

累加之前把总和设为 0。分支只打印你要核对的词，避免两支都打印让期望对不上。

```cpp run expect="9" title="奇数和"
#include <iostream>
int main() {
  int total = 0;
  for (int n = 1; n <= 5; n++) {
    if (n % 2 == 1) total += n;
  }
  std::cout << total << "\n";
  return 0;
}
```

```cpp run expect="3" title="数到三"
#include <iostream>
int main() {
  int n = 0;
  while (n < 3) n += 1;
  std::cout << n << "\n";
  return 0;
}
```

```cpp run expect="9" title="较大"
#include <iostream>
int main() {
  int a = 3;
  int b = 9;
  std::cout << (a > b ? a : b) << "\n";
  return 0;
}
```

## 读完再动手

本章要留下的是 「用 if 和 else 分支」、「用 for 做有限次数」、「写出能停下来的循环」。合上抽屉之前，用自己的话说出每一项目标对应哪一个示例的标题。对不上标题，就还没有把目标和代码连起来，先别展开练习答案。

练习的答案默认折着。先在编辑器里自己写，再展开对照。对照时只看输出是否包含期望的那几个字。两道都过了再进入下一章。下一次运行是新进程，这次的变量不会留下。

把这一章当成一次可以反复撤销的实验。点代码块上的 Run 会用示例覆盖编辑器，原来的草稿先备份。你改过的内容如果还想留着，先复制到别处，再点下一例。工具栏的 Run 不会从文档重写编辑器，所以它用来看你改过的版本。两种按钮各做各的事。下载进度写在按钮旁边，第一次打开这种语言时要等它结束，再判断示例是不是写错了。

记录你预测错的那一次。写下你以为会打印的文字，以及实际多出来或少掉的部分。进入下一章之前，要能用一句话说清差在哪。通过只说明期望的那几个字还在，不说明你已经看懂产生它的那一行。章节标题下的目标就是这份验收清单。差两个字也不要靠改期望凑过去。

## 常见错误

- 把 == 写成 =。
- 循环不改变条件。
- 总和没有初始化。

## 最佳实践

- 次数清楚时用 for。
- 比较写成 ==。
- 每条路径的输出都是你能预测的短词或数字。

## 小结

分支看条件的真假，0 为假。循环必须靠近结束。比较不要写成赋值。
